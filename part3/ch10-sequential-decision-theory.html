Part III · 第 10 章

序贯决策论 Sequential Decision Theory

第 9 章暂时离开了规划，只讨论「在不确定性下做一次决策」。这一章回到规划：把第 2 章的离散规划和第 9 章的「自然」结合起来，得到一连串的决策问题。新的决策者——自然 nature——在计划执行的每一步都会干扰状态转移，所以未来的状态无法预测，计划必须是反馈 feedback 形式的：根据当前状态选动作，而不是一串事先排好的动作。

本章导读

贯穿全章的一个关键假设：当前状态总是已知的。唯一的不确定性在于预测未来的状态。第 11、12 章会处理更难的情形——连当前状态都不知道，只能靠传感器去测，规划于是发生在信息空间 information space 里而不是状态空间里；本章的大部分想法都能推广过去。

和第 9 章一样，不确定性有两种建模方式：

模型对自然的了解计划的目标
非确定 nondeterministic只知道自然会从集合 \(\Theta(x,u)\) 里挑一个动作不管自然怎么做都保证到达目标；可以进一步要求最坏情况代价最优
概率 probabilistic知道 \(P(\theta\mid x,u)\)使期望代价最优：一次执行的结果不可预测，但同一问题执行很多次时平均代价最小

这些问题适用面很广：大部分想法源自随机控制理论 stochastic control theory；在移动机器人里，未来状态通常不可预测，可以用概率或最坏情况来建模；此外还有工程、运筹、经济中的大量应用，比如生产调度、赌博策略和投资规划。

10.1 引入与自然的序贯博弈 Introducing Sequential Games Against Nature

这一节把第 2 章的许多想法推广到「自然干扰动作结果」的情形：10.1.1 定义规划问题（它是 2.1 节的直接推广）；由于不可预测，10.1.2 引入前向投影 forward projection 与反向投影 backprojection，分别刻画可能的未来状态和过去状态——第 2 章不需要前向投影，因为从计划和初始状态总能推出未来的状态序列；10.1.3 定义计划，并用前向投影说明同一个计划每次执行的结果为何不同。

10.1.1 模型定义

这是在 Formulation 2.3 上加入「每个阶段都有自然」的推广。\(X\) 是离散状态空间，\(U(x)\) 是决策者（机器人）在 \(x\) 处可用的动作集合。在每个阶段 \(k\)，自然从集合 \(\Theta(x_k,u_k)\) 中选一个自然动作 nature action \(\theta_k\)。这可以看成 Formulation 9.4（那里是 \(\Theta(u)\)）的多阶段推广；现在 \(\Theta\) 还可以依赖状态，因为 \(x_k\) 和 \(u_k\) 在当前阶段都是已知的——这意味着自然在知道决策者所选动作的情况下行动。决策者永远不知道自然在阶段 \(k\) 会选哪个动作，但知道集合 \(\Theta(x_k,u_k)\)。

和 9.2 节一样有两种自然模型。非确定：只知道自然会从 \(\Theta(x_k,u_k)\) 里选一个，适合做最坏情况分析。概率：模型里给出 \(\Theta(x_k,u_k)\) 上的概率分布。这时要牢记一个重要假设：自然是Markov 的 Markovian——概率只依赖于局部的信息。在大多数应用里「局部」是对时间而言的；在我们的表述里，它意味着 \(\Theta(x_k,u_k)\) 上的分布只依赖于当前阶段得到的信息（在别的场合，Markov 也可以指依赖少数几个阶段，或者空间上的局部依赖，例如 Markov 随机场 Markov random field）。

为了把 Markov 假设说清楚，沿用 8.2.1 节的状态历史与动作历史：

$$\tilde{x}_k = (x_1,x_2,\ldots,x_k) \tag{10.1}$$
$$\tilde{u}_k = (u_1,u_2,\ldots,u_k). \tag{10.2}$$

它们代表到阶段 \(k\) 为止可用的全部信息。没有 Markov 假设，自然的分布可能依赖于全部历史，即 \(P(\theta_k\mid\tilde{x}_k,\tilde{u}_k)\)。Markov 假设声明对所有 \(\theta_k\in\Theta(x_k,u_k)\)：

$$P(\theta_k\mid\tilde{x}_k,\tilde{u}_k) = P(\theta_k\mid x_k,u_k), \tag{10.3}$$

也就是说，一旦知道当前状态和动作，历史中的任何部分都不再提供关于自然动作的额外信息。自然的作用体现在状态转移方程里：

$$x_{k+1} = f(x_k,u_k,\theta_k). \tag{10.4}$$

从决策者的角度看 \(\theta_k\) 是未知的，所以只能推断施加 \(u_k\) 之后可能出现的状态集合：

$$X_{k+1}(x_k,u_k) = \{x_{k+1}\in X \mid \exists\theta_k\in\Theta(x_k,u_k) \text{ 使得 } x_{k+1} = f(x_k,u_k,\theta_k)\}. \tag{10.5}$$

记号 \(X_k(\cdot)\) 一般表示「由括号里的信息能推出的 \(x_k\) 的可能取值」。在概率情形下，给定 \(P(\theta_k\mid x_k,u_k)\) 和 (10.4)，可以推出阶段 \(k+1\) 上的分布：

$$P(x_{k+1}\mid x_k,u_k) = \sum_{\theta_k\in\Theta'} P(\theta_k\mid x_k,u_k), \tag{10.6}$$
$$\Theta' = \{\theta_k\in\Theta(x_k,u_k) \mid x_{k+1} = f(x_k,u_k,\theta_k)\}. \tag{10.7}$$

就是把所有能把状态带到 \(x_{k+1}\) 的自然动作的概率加起来。

Formulation 10.1（带自然的离散规划 Discrete Planning with Nature）
  1. 非空的状态空间 \(X\)：有限或可数无穷个状态。
  2. 对每个 \(x\in X\)，有限非空的动作空间 \(U(x)\)。假设 \(U\) 含有一个特殊的终止动作 termination action \(u_T\)，作用与 Formulation 2.3 中相同。
  3. 对每个 \(x\in X\)、\(u\in U(x)\)，有限非空的自然动作空间 \(\Theta(x,u)\)。
  4. 状态转移函数 \(f\)：对每个 \(x\)、\(u\in U\)、\(\theta\in\Theta(x,u)\) 给出 \(f(x,u,\theta)\)。
  5. 一组阶段，从 \(k=1\) 开始无限延续；或者有一个固定的最大阶段 \(k = K+1 = F\)。
  6. 初始状态 \(x_I\in X\)。有的问题不指定它，这时要找一个对所有初始状态都适用的计划。
  7. 目标集 \(X_G\subset X\)。
  8. 阶段可加的代价泛函 \(L\)。记 \(\tilde\theta_K\) 为到阶段 \(K\) 为止的自然动作历史，
    $$L(\tilde{x}_F,\tilde{u}_K,\tilde\theta_K) = \sum_{k=1}^{K} l(x_k,u_k,\theta_k) + l_F(x_F), \tag{10.8}$$
    其中 \(F = K+1\)。若在某个阶段 \(k\) 施加了 \(u_T\)，则对所有 \(i\ge k\)：\(u_i = u_T\)、\(x_i = x_k\)、\(l(x_i,u_T,\theta_i) = 0\)。

用 Formulation 10.1 可以定义可行规划问题，也可以定义最优规划问题。可行问题：令所有 \(l(x_k,u_k,\theta_k) = 0\)，并且

$$l_F(x_F) = \begin{cases} 0 & x_F\in X_G \\ \infty & \text{否则}. \end{cases} \tag{10.9}$$

最优问题：\(x_k\notin X_G\) 时 \(l(x_k,u_k,\theta_k)\) 可以取任何非负有限值。对概率不确定性，有时让 \(l_F(x_F)\) 在 \(x_F\notin X_G\) 时取一个很大的有限值比取 \(\infty\) 更合适（下面的值迭代实验室会看到为什么）。注意每个阶段的代价项一般可以依赖自然动作 \(\theta_k\)。

术语：用概率不确定性时，Formulation 10.1 常被称为受控 Markov 过程 controlled Markov process 或 Markov 决策过程 Markov decision process（MDP）；去掉动作就只是 Markov 过程。统计文献里离散阶段的情形多叫 Markov 链 Markov chain，所以「受控 Markov 链」「Markov 决策链」也许更贴切。

不显式写出自然：若 \(l(x_k,u_k,\theta_k) = l(x_k,u_k)\)，非确定情形可以直接给出 \(X_{k+1}(x_k,u_k)\) 代替状态转移方程——施加 \(u_k\) 就直接落到 \(X\) 的一个指定子集；概率情形则直接给出 \(P(x_{k+1}\mid x_k,u_k)\)。本书大多数时候用带自然的状态转移方程，但这两种写法在很多书和论文里都会出现。

图表示：和 2.1 节一样可以画有向状态转移图，顶点集是 \(X\)，只是边的定义要反映自然：若存在 \(u\in U(x)\) 和 \(\theta\in\Theta(x,u)\) 使 \(x' = f(x,u,\theta)\)，就有一条 \(x\to x'\) 的边；边上可以标代价 \(l(x,u,\theta)\)，概率模型下还可以标转移概率。决策者和自然共同决定到达哪个顶点：决策者选定 \(u\) 时，从 \(x\) 出发会有好几条出边；换一个动作，这组出边就变了；自然再从中选一条——这不完全由决策者控制。

例 10.1（在数轴上移动 Traversing the Number Line）：\(X = \mathbb{Z}\)，\(U = \{-2, 2, u_T\}\)，\(\Theta = \{-1, 0, 1\}\)，所有状态的动作集都相同。状态转移方程 \(x_{k+1} = x_k + u_k + \theta_k\)。每个阶段代价 1（\(u\ne u_T\) 时 \(l(x,u,\theta) = 1\)），\(x_I = 100\)，\(X_G = \{-1,0,1\}\)。在非确定模型下连续执行 \(-2\)：第一次之后可能的状态是 \(\{97,98,99\}\)——自然可能把前进拖慢到每阶段 1 格，也可能加速到每阶段 3 格。100 个阶段之后一定能到达目标；一到达就施加 \(u_T\)。如果把目标改成 \(X_G = \{0\}\)，就无法保证到达，因为自然可能让机器人冲过头。

再换一个模型：\(U = \{-1, 1, u_T\}\)，\(\Theta = \{-2,-1,0,1,2\}\)。非确定模型下问题无解：自然强大到足以在最坏情况下把状态完全往反方向推。但可以定义并求解一个合理的概率版本：设 \(P(\theta) = 1/5\)，例如 \(x_k = 100\)、\(u_k = -1\) 时，\(97\le x_{k+1}\le 101\) 的概率各为 \(1/5\)。到达 \(X_G\) 的概率不为零，尽管最坏情况下不能保证。

例 10.2（在网格上移动 Moving on a Grid）：图 10.1 是一个 \(15\times15\) 的网格，状态 \((i,j)\)，\(1\le i,j\le15\)，中间的 \(5\times5\) 区域不属于 \(X\)；\(x_I = (1,1)\)，\(X_G\) 是右上角的 \(5\times5\)。令 \(A = \{0,1,2,3,4\}\) 分别表示「停、右、上、左、下」，\(U = A\cup\{u_T\}\)，\(U(x)\) 只含在 \(x\) 处可用的动作（边界上有些方向不可用）。\(\Theta(x,u)\) 是执行 \(u\) 之后可用的 \(A\) 中动作的集合：例如 \(x = (2,2)\)、\(u = 3\)，机器人想移到 \((1,2)\)，那里有三个相邻状态，各对应一个自然动作，于是 \(\Theta(x,u) = \{0,1,2,4\}\)——没有 3，因为 \((1,2)\) 左边没有状态。用概率模型时每个自然动作等可能。\(f\) 把 \(u_k\) 和 \(\theta_k\) 的效果相加：\(x_k = (i,j)\)、\(u_k = 1\)、\(\theta_k = 2\) 时 \(x_{k+1} = (i+1,j+1)\)；若 \(\theta_k = 3\)，两者抵消，\(x_{k+1} = (i,j)\)；没有自然时就是 \(\theta_k = 0\)。一旦施加 \(u_T\)，不论自然怎样状态都不再变。代价 \(l(x_k,u_k) = 1\)（\(u_T\) 时为 0），\(l_F\) 按 (10.9)。合理的任务是以最少的期望阶段数在 \(X_G\) 中终止——这需要 10.1.3 节的反馈计划，最优计划可以用 10.2.1 节的方法高效算出。这个例子很容易推广到二维或更高维的复杂迷宫；网格分辨率高时就得到运动规划的近似；若想允许任意方向而不只是四个方向，就要用 10.6 节的连续状态空间。

  • 点不同的格子：内部格子 |Θ| = 5，贴着墙或障碍时变成 4 或 3——自然只能「推进去」不能「推出去」，这在后面会让期望代价比无自然时还略小。

10.1.2 前向投影与反向投影 Forward Projections and Backprojections

前向投影刻画计划执行时的行为。在引入不确定性之前，计划总是严格按预期执行：一串动作施加在初始状态上，得到的状态序列可以用状态转移方程算出来。现在状态转移不可预测了，我们想象几个阶段之后可能处在哪些状态：非确定情形是给定当前状态和计划后可能的未来状态集合；概率情形则是状态上的分布。

非确定的前向投影

为了记号简单，暂且假设所有 \(x\) 都有 \(U(x) = U\)（10.1.3 节会去掉这个假设）。设初始状态 \(x_1 = x_I\) 已知，施加 \(u_1\in U\) 后可能的下一状态是

$$X_2(x_1,u_1) = \{x_2\in X \mid \exists\theta_1\in\Theta(x_1,u_1) \text{ 使得 } x_2 = f(x_1,u_1,\theta_1)\}, \tag{10.10}$$

这是 (10.5) 的特例。接着施加 \(u_2\)：

$$\begin{aligned}X_3(x_1,u_1,u_2) = \{x_3\in X \mid\ &\exists\theta_1\in\Theta(x_1,u_1) \text{ 且 } \exists\theta_2\in\Theta(x_2,u_2) \\ &\text{使得 } x_2 = f(x_1,u_1,\theta_1) \text{ 且 } x_3 = f(x_2,u_2,\theta_2)\}.\end{aligned} \tag{10.11}$$

这样写下去很快就繁琐了，递归地写更好。设动作历史 \(\tilde{u}_k\) 固定，\(X_{k+1}(X_k,u_k)\) 表示已知阶段 \(k\) 的前向投影为 \(X_k\) 时阶段 \(k+1\) 的前向投影：

$$X_{k+1}(X_k,u_k) = \{x_{k+1}\in X \mid \exists x_k\in X_k \text{ 且 } \exists\theta_k\in\Theta(x_k,u_k) \text{ 使得 } x_{k+1} = f(x_k,u_k,\theta_k)\}. \tag{10.12}$$

从 \(X_1 = \{x_1\}\) 出发反复使用即可。例 10.3（非确定前向投影）：用例 10.1 的第一个模型，\(x_1 = 0\)，施加 \(u = 2\)：一步前向投影 \(X_2(0,2) = \{1,2,3\}\)；再施加一次，\(X_3(0,2,2) = \{2,3,4,5,6\}\)；如此重复，\(k\) 步前向投影是 \(\{k,\ldots,3k\}\)。

概率的前向投影

动作一旦给定，「决策」部分就消失了，概率前向投影可以看成一个 Markov 过程。已知 \(x_k\)、施加 \(u_k\)，一步前向投影就是 (10.6)。两步前向投影 \(P(x_{k+2}\mid x_k,u_k,u_{k+1})\) 用边缘化计算：

$$P(x_{k+2}\mid x_k,u_k,u_{k+1}) = \sum_{x_{k+1}\in X} P(x_{k+2}\mid x_{k+1},u_{k+1})\,P(x_{k+1}\mid x_k,u_k). \tag{10.13}$$

更多步要嵌套求和，把中间状态都边缘化掉，例如三步：

$$P(x_{k+3}\mid x_k,u_k,u_{k+1},u_{k+2}) = \sum_{x_{k+1}\in X}\sum_{x_{k+2}\in X} P(x_{k+3}\mid x_{k+2},u_{k+2})P(x_{k+2}\mid x_{k+1},u_{k+1})P(x_{k+1}\mid x_k,u_k). \tag{10.14}$$

借用线性代数可以写得很简洁。对每个动作 \(u\)，定义它的 \(n\times n\)（\(n = |X|\)）状态转移矩阵 state transition matrix \(M_u\)：

$$M_u = \begin{pmatrix} m_{1,1} & m_{1,2} & \cdots & m_{1,n} \\ m_{2,1} & m_{2,2} & \cdots & m_{2,n} \\ \vdots & \vdots & & \vdots \\ m_{n,1} & m_{n,2} & \cdots & m_{n,n} \end{pmatrix}, \tag{10.15}$$
$$m_{i,j} = P(x_{k+1} = i \mid x_k = j,\ u). \tag{10.16}$$

第 \(j\) 列之和为 1，可以理解为「从 \(x_k = j\) 施加 \(u_k\) 后在 \(X\) 上的分布」（注意是列随机矩阵）。设列向量 \(v\) 是 \(X\) 上任一分布，\(M_u v\) 就是从 \(v\) 出发施加 \(u\) 后的分布：矩阵乘法做了 \(n\) 次内积，每次都是 (10.13) 那样的边缘化。若 \(\tilde{u}_{k-1}\) 固定、\(v = [0\ 0\cdots 0\ 1\ 0\cdots 0]\) 表示 \(x_1\) 确定已知，则

$$v' = M_{u_{k-1}} M_{u_{k-2}}\cdots M_{u_2} M_{u_1} v, \tag{10.17}$$

\(v'\) 的第 \(i\) 个元素就是 \(P(x_k = i\mid x_1,\tilde{u}_{k-1})\)。例 10.4（概率前向投影）：仍用例 10.1 的第一个模型，但每个自然动作的概率是 \(1/3\)。\(x_1 = 0\)，每个阶段都施加 \(u = 2\)。一步前向投影在状态 \((1,2,3)\) 上的概率是

$$[1/3\ \ 1/3\ \ 1/3], \tag{10.18}$$

两步前向投影在 \((2,3,4,5,6)\) 上的概率是

$$[1/9\ \ 2/9\ \ 3/9\ \ 2/9\ \ 1/9]. \tag{10.19}$$

反向投影

有时需要定义可能的过去状态——哪些状态能导致当前的一个或多个状态。10.2.3 节的图搜索算法就要用到它。这需要维护一个与前向投影方向相反的反向投影。8.5.2 节在连续状态空间上用反向投影记录类 Dijkstra 算法里的活跃状态；现在反向投影还要处理不确定性。

考虑非确定情形。给定状态 \(x\in X\) 和固定动作 \(u\)，哪些先前状态 \(x'\) 可能导致 \(x\)？这只依赖于自然可能的选择：

$$\mathrm{WB}(x,u) = \{x'\in X \mid \exists\theta\in\Theta(x',u) \text{ 使得 } x = f(x',u,\theta)\}. \tag{10.20}$$

\(\mathrm{WB}(x,u)\) 称为 \(x\) 在 \(u\) 下的弱反向投影 weak backprojection：在一个阶段内可能到达 \(x\) 的所有状态。说「弱」，是因为它不保证到达 \(x\)。保证到达 \(x\) 是更强的条件，定义强反向投影 strong backprojection：

$$\mathrm{SB}(x,u) = \{x'\in X \mid \forall\theta\in\Theta(x',u),\ x = f(x',u,\theta)\}. \tag{10.21}$$

两者的区别在于「存在一个自然动作能到 \(x\)」与「所有自然动作都到 \(x\)」。显然 \(\mathrm{SB}(x,u)\subseteq\mathrm{WB}(x,u)\)。很多时候 \(\mathrm{SB}(x,u) = \emptyset\)，而 \(\mathrm{WB}(x,u)\) 很少为空。8.5.2 节 (8.66) 的反向投影不涉及不确定性，所以那里没有强弱之分。

两个有用的推广：1）从一个状态集合出发；2）动作不必固定。给定 \(S\subseteq X\)，在 \(u\) 下一步可能到达 \(S\) 中某个元素的状态是 \(S\) 在 \(u\) 下的弱反向投影：

$$\mathrm{WB}(S,u) = \{x'\in X \mid \exists\theta\in\Theta(x',u) \text{ 使得 } f(x',u,\theta)\in S\}, \tag{10.22}$$
$$\mathrm{WB}(S,u) = \bigcup_{x\in S}\mathrm{WB}(x,u). \tag{10.23}$$

类似地，\(S\) 在 \(u\) 下的强反向投影是

$$\mathrm{SB}(S,u) = \{x'\in X \mid \forall\theta\in\Theta(x',u),\ f(x',u,\theta)\in S\}. \tag{10.24}$$

注意 \(\mathrm{SB}(S,u)\) 不能由 \(\mathrm{SB}(x,u)\) 对 \(x\in S\) 取并得到（习题 1）。另一个观察：对每个 \(x_k\in\mathrm{SB}(S,u_k)\) 都有 \(X_{k+1}(x_k,u_k)\subseteq S\)。再去掉对 \(u\) 的依赖，得到「存在某个动作可能到达 \(S\)」的状态——\(S\) 的弱反向投影和强反向投影：

$$\mathrm{WB}(S) = \{x'\in X \mid \exists u\in U(x') \text{ 使得 } x'\in\mathrm{WB}(S,u)\}, \tag{10.25}$$
$$\mathrm{SB}(S) = \{x'\in X \mid \exists u\in U(x') \text{ 使得 } x'\in\mathrm{SB}(S,u)\}. \tag{10.26}$$

同样 \(\mathrm{SB}(S)\subseteq\mathrm{WB}(S)\)。（原书 (10.25)(10.26) 把这里的 \(x'\) 写成了 \(x\)：「\(\exists u\in U(x)\) 使得 \(x\in\mathrm{WB}(S,u)\)」，按上下文应为 \(x'\)，本页按 \(x'\) 写。）

例 10.5（反向投影）：仍是例 10.1 的第一个模型。\(\mathrm{WB}(0,2)\) 是能施加 \(u = 2\) 且可能到达 \(x = 0\) 的状态：\(\{-3,-2,-1\}\)；但从其中任何一个都不能确保到达 0，所以 \(\mathrm{SB}(0,2) = \emptyset\)。再看目标 \(X_G = \{-1,0,1\}\) 在 \(u = 2\) 下的反向投影：

$$\mathrm{WB}(X_G,2) = \mathrm{WB}(-1,2)\cup\mathrm{WB}(0,2)\cup\mathrm{WB}(1,2) = \{-4,-3,-2,-1,0\}. \tag{10.27}$$

强反向投影是 \(\mathrm{SB}(X_G,2) = \{-2\}\)：从 \(\mathrm{WB}(X_G,2)\) 里的其它状态出发，自然都可能让目标落空。注意 \(\mathrm{SB}(X_G,2)\) 不能由各个 \(\mathrm{SB}(x,2)\) 取并得到。最后看不依赖动作的反向投影：\(\mathrm{WB}(X_G) = \{-4,-3,\ldots,4\}\)，\(\mathrm{SB}(X_G) = X_G\)——后者里 \(X_G\) 的所有状态都在，因为可以施加 \(u_T\)；不允许 \(u_T\) 的话 \(\mathrm{SB}(X_G) = \{-2,2\}\)。

还可以定义别的反向投影，书中不展开：一种是像前向投影那样做多阶段反向投影（习题 3）；另一种是为概率情形定义反向投影——复杂得多，例如求「以至少 \(p\) 的概率到达 \(S\) 中某个状态」的所有状态。

10.1.3 计划及其执行 A Plan and Its Execution

第 2 章的计划是一串动作，因为动作的效果完全可预测；Part II 的大部分地方，计划是一条路径——动作序列的连续阶段版本。8.2.1 节引入了定义在状态空间上的函数形式的计划，但那是可选的，因为当时没有显式地建模不确定性（初始状态除外）。现在由于自然带来的不可预测性，必须把计划的定义与计划的执行分开：同一个计划可以从同一个初始状态执行很多次，但由于自然，每次得到的未来状态都不同。这就需要反馈：计划把状态映射到动作。

定义计划：Formulation 10.1 的一个（反馈）计划 (feedback) plan 是函数 \(\pi : X\to U\)，对每个 \(x\in X\) 给出 \(\pi(x)\in U(x)\)。虽然未来的状态可能未知，但只要给定 \(\pi\)，就知道将来到了任何状态会采取什么动作。在别的文献里，\(\pi\) 也叫反馈策略 feedback policy、反馈控制律 feedback control law、反应式计划 reactive plan 和条件计划 conditional plan。

对某些问题，尤其 \(K\) 固定为有限值时，可能需要依赖阶段的计划 stage-dependent plan：同一状态在不同阶段可以选不同动作。令 \(\mathcal{K} = \{1,\ldots,K\}\)，依赖阶段的计划是 \(\pi : X\times\mathcal{K}\to U\)，\(u = \pi(x,k)\)。2.3 节的 \(K\) 步计划是它的特例——那里动作只依赖阶段，因为未来状态总是可预测的；现在未来状态不再可预测，必须放进 \(\pi\) 的定义域。除非特别说明，默认 \(\pi\) 不依赖阶段。

一旦 \(\pi\) 确定，状态转移看起来就只是当前状态和自然动作的函数：下一状态是 \(f(x,\pi(x),\theta)\)，代价项是 \(l(x,\pi(x),\theta)\)。

固定计划下的前向投影

前向投影现在可以在「执行某个特定计划」的约束下定义：动作序列被 \(\pi\) 取代，每次需要在 \(x\) 处选动作就用 \(\pi(x)\)。在这种写法里，不同的 \(x\) 可以有不同的 \(U(x)\)，只要 \(\pi\) 只用 \(U(x)\) 中实际可用的动作。非确定情形：已知 \(x_1\) 和 \(\pi\)，\(u_1 = \pi(x_1)\) 代入 (10.10) 得到一步前向投影；第二步的 \(u_2\) 由 \(\pi(x_2)\) 决定，代入 (10.11)。递归形式是

$$\begin{aligned}X_{k+1}(x_1,\pi) = \{x_{k+1}\in X \mid\ &\exists\theta_k\in\Theta(x_k,\pi(x_k)) \text{ 使得 } \\ &x_k\in X_k(x_1,\pi) \text{ 且 } x_{k+1} = f(x_k,\pi(x_k),\theta_k)\}.\end{aligned} \tag{10.28}$$

把概率前向投影 (10.13)1改成用 \(\pi\)：

$$P(x_{k+2}\mid x_k,\pi) = \sum_{x_{k+1}\in X} P(x_{k+2}\mid x_{k+1},\pi(x_{k+1}))\,P(x_{k+1}\mid x_k,\pi(x_k)). \tag{10.29}$$

重复 \(k-1\) 次就得到 \(P(x_k\mid x_1,\pi)\)。状态转移矩阵也可以用：(10.15) 中所有列对应同一个动作 \(u\)；而固定计划下的 \(M_\pi\) 每一列可以对应不同的动作，因为每一列代表不同的状态 \(x_k\)：

$$m_{i,j} = P(x_{k+1} = i \mid x_k = j,\ \pi(x_k)). \tag{10.30}$$

这个 \(M_\pi\) 定义了在 \(\pi\) 作用下诱导出的 Markov 过程。

计划的图表示

与自然的博弈有两个决策者：自然和机器人。计划一旦确定，机器人的决策就固定了，只剩自然在做决策。按这个理解，可以像 2.1 节那样定义一个有向图，只是边由自然的动作而不是机器人的动作给出——甚至可以想象自然自己在面对一个 Formulation 2.1 那样的离散可行规划问题：\(\Theta(x,\pi(x))\) 代替 \(U(x)\)，并且没有目标集。记 \(\mathcal{G}_\pi\) 为基于计划的状态转移图 plan-based state transition graph：顶点集是 \(X\)；若存在 \(\theta\in\Theta(x,\pi(x))\) 使 \(x' = f(x,\pi(x),\theta)\)，就有边 \(x\to x'\)。于是从每个顶点出发的出边集合就是「按 \(\pi\) 施加动作时所有可能的转移」。概率情形下 \(\mathcal{G}_\pi\) 是带权图，每条边赋予概率 \(P(x'\mid x,\pi(x),\theta)\)，这正是常用来画 Markov 链的图。非确定前向投影可以直接从 \(\mathcal{G}_\pi\) 读出：从当前状态沿出边走一步得到一步前向投影，再走一步得到两步前向投影，依此类推；概率前向投影也一样。

反馈计划的代价

考虑从 \(x_1\in X\) 执行计划 \(\pi\) 的代价到目标 cost-to-go。代价依赖于访问的状态序列、计划施加的动作以及自然施加的动作。第 2 章只需把代价项加起来；现在还依赖于自然，最坏情况和期望情况两种分析都可以，它们把 9.2 节的处理推广到状态空间和多阶段。令 \(\mathcal{H}(\pi,x_1)\) 为从 \(x_1\) 出发、执行 \(\pi\) 时可能出现的所有「状态—动作—自然」历史。最坏情况分析：

$$G_\pi(x_1) = \max_{(\tilde{x},\tilde{u},\tilde\theta)\in\mathcal{H}(\pi,x_1)}\Big\{L(\tilde{x},\tilde{u},\tilde\theta)\Big\}, \tag{10.31}$$

即从 \(x_1\) 出发所有可能轨迹中的最大代价。只要有一条不能终止在目标里，代价就是无穷。(10.31) 里的 \(\tilde{x}\)、\(\tilde{u}\)、\(\tilde\theta\) 是无穷历史，但由于 \(u_T\)，它们对代价的影响会提早结束。最坏情况下的最优计划，是在所有可能的计划（所有给状态分配动作的方式）中使 \(G_\pi(x_1)\) 最小的计划；如果只做可行规划——所有轨迹都必须到达目标、代价无需最优——通常有大量等价的选择。期望情况分析：

$$G_\pi(x_1) = E_{\mathcal{H}(\pi,x_1)}\Big[L(\tilde{x},\tilde{u},\tilde\theta)\Big], \tag{10.32}$$

期望取遍 \(\mathcal{H}(\pi,x_1)\)：每个历史的代价 \(L\) 乘以它的概率再求和，也可以理解为从 \(x_1\) 出发的轨迹的期望代价。只要有概率非零的轨迹不能在目标终止，\(G_\pi(x_1) = \infty\)。概率情形的任务通常是找使 \(G_\pi(x_1)\) 最小的计划。

一个有趣的问题：同一个 \(\pi\) 能否对所有初始状态都最优？幸运的是能——8.2.1 节也观察到这一点。若 \(\pi\) 从某个 \(x_1\) 出发最优，那么它从执行过程中可能访问的任何其它状态 \(x\) 出发也一定最优：否则从 \(x\) 出发存在更好的计划，到达目标的代价更低，而从 \(x_1\) 出发的解必须经过 \(x\)，这与 \(\pi\) 的最优性矛盾。记 \(\pi^*\) 为对每个初始状态都最优的计划。

10.2 计算反馈计划的算法 Algorithms for Computing Feedback Plans

10.2.1 值迭代 Value Iteration

幸运的是，2.3.1.1 节的值迭代可以很好地推广到预测不确定的情形——这正是当初在第 2 章介绍值迭代的主要原因：那里没有自然的复杂性，讲起来容易；在现在的设定下，值迭代依然保持了大部分效率，能轻松解决几千甚至几百万个状态的问题。整个 10.2.1 节假设 \(X\) 有限（若不必增量地计算整个空间上的代价到目标，也可以推广到可数无穷）。这里只讲后向值迭代，前向版本可以类似定义（习题 7、8）。

非确定情形

下面推导动态规划递推式 (10.39)，它直接给出一个迭代方法，算出使最坏情况代价最小的计划。推导完全对照 2.3.1.1 节，不妨时时翻回去看。最优计划 \(\pi^*\) 通过计算最优代价到目标函数得到。对 \(1\le k\le F\)，令 \(G^*_k\) 为最优计划从阶段 \(k\) 执行到 \(F\) 时可能累积的最坏情况代价（对照 (2.5)）：

$$G^*_k(x_k) = \min_{u_k}\max_{\theta_k}\min_{u_{k+1}}\max_{\theta_{k+1}}\cdots\min_{u_K}\max_{\theta_K}\Big\{\sum_{i=k}^{K} l(x_i,u_i,\theta_i) + l_F(x_F)\Big\}. \tag{10.33}$$

min 和 max 里面是代价泛函 (10.8) 的最后 \(F-k\) 项；为简单起见各个 \(u_i\)、\(\theta_i\) 的取值范围没有写出。\(k = F\) 时的最优代价到目标是

$$G^*_F(x_F) = l_F(x_F), \tag{10.34}$$

与可预测情形的 (2.6) 相同。现在对 \(X\) 做 \(K\) 遍扫描，每遍由 \(G^*_{k+1}\) 算 \(G^*_k\)，\(k\) 从 \(F\) 递减到 1。第一遍 \(G^*_F\) 从 \(l_F\) 拷贝过来；第二遍对每个 \(x_K\in X\) 计算（对照 (2.7)）

$$G^*_K(x_K) = \min_{u_K}\max_{\theta_K}\Big\{l(x_K,u_K,\theta_K) + l_F(x_F)\Big\}, \tag{10.35}$$

其中 \(u_K\in U(x_K)\)、\(\theta_K\in\Theta(x_K,u_K)\)。由于 \(l_F = G^*_F\) 且 \(x_F = f(x_K,u_K,\theta_K)\)，代入 (10.35) 得到（对照 (2.8)）

$$G^*_K(x_K) = \min_{u_K}\max_{\theta_K}\Big\{l(x_K,u_K,\theta_K) + G^*_F(f(x_K,u_K,\theta_K))\Big\}, \tag{10.36}$$

它算出了从阶段 \(K\) 到 \(F = K+1\) 的所有最优一步计划的代价。更一般地，已知 \(G^*_{k+1}\) 就能算 \(G^*_k\)。仔细看 (10.33)，把第一项代价从和式里拿出来，把对 \(u_k\) 的最小化和其余的（\(u_{k+1}\) 到 \(u_K\)）分开（对照 (2.9)）：

$$G^*_k(x_k) = \min_{u_k}\max_{\theta_k}\Big\{\min_{u_{k+1}}\max_{\theta_{k+1}}\cdots\min_{u_K}\max_{\theta_K}\Big\{l(x_k,u_k,\theta_k) + \sum_{i=k+1}^{K} l(x_i,u_i,\theta_i) + l_F(x_F)\Big\}\Big\}. \tag{10.37}$$

第二组 min、max 不影响 \(l(x_k,u_k,\theta_k)\)，可以把它提出来（对照 (2.10)）：

$$G^*_k(x_k) = \min_{u_k}\max_{\theta_k}\Big\{l(x_k,u_k,\theta_k) + \min_{u_{k+1}}\max_{\theta_{k+1}}\cdots\min_{u_K}\max_{\theta_K}\Big\{\sum_{i=k+1}^{K} l(x_i,u_i,\theta_i) + l_F(x_F)\Big\}\Big\}. \tag{10.38}$$

里面那组 min 和 max 正是 \(G^*_{k+1}\)2，于是得到递推式（对照 (2.11)）

$$G^*_k(x_k) = \min_{u_k\in U(x_k)}\Big\{\max_{\theta_k}\Big\{l(x_k,u_k,\theta_k) + G^*_{k+1}(x_{k+1})\Big\}\Big\}. \tag{10.39}$$

概率情形

再次对照 2.3.1.1 节就能得到值迭代方法。对 \(k\) 从 1 到 \(F\)，令 \(G^*_k\) 为最优计划从阶段 \(k\) 执行到 \(F\) 的期望代价（对照 (2.5)）：

$$G^*_k(x_k) = \min_{u_k,\ldots,u_K}\Big\{E_{\theta_k,\ldots,\theta_K}\Big[\sum_{i=k}^{K} l(x_i,u_i,\theta_i) + l_F(x_F)\Big]\Big\}. \tag{10.40}$$

边界条件 \(k = F\) 仍是 (10.34)。算法仍做 \(K\) 遍扫描，\(G^*_F\) 拷贝自 \(l_F\)；第二遍对每个 \(x_K\) 计算（对照 (2.7)）

$$G^*_K(x_K) = \min_{u_K}\Big\{E_{\theta_K}\Big[l(x_K,u_K,\theta_K) + l_F(x_F)\Big]\Big\}, \tag{10.41}$$

其中 \(u_K\in U(x_K)\)，期望对 \(\theta_K\) 取。代入后（对照 (2.8)）

$$G^*_K(x_K) = \min_{u_K}\Big\{E_{\theta_K}\Big[l(x_K,u_K,\theta_K) + G^*_F(f(x_K,u_K,\theta_K))\Big]\Big\}. \tag{10.42}$$

一般的迭代是

$$G^*_k(x_k) = \min_{u_k}\Big\{E_{\theta_k}\Big[\min_{u_{k+1},\ldots,u_K}\Big\{E_{\theta_{k+1},\ldots,\theta_K}\Big[l(x_k,u_k,\theta_k) + \sum_{i=k+1}^{K} l(x_i,u_i,\theta_i) + l_F(x_F)\Big]\Big\}\Big]\Big\}, \tag{10.43}$$

同样是把第一项代价提出来、把对 \(u_k\) 的最小化分开得到的。第二组 min 和期望不影响 \(l(x_k,u_k,\theta_k)\)，把它提到外面（对照 (2.10)）：

$$G^*_k(x_k) = \min_{u_k}\Big\{E_{\theta_k}\Big[l(x_k,u_k,\theta_k) + \min_{u_{k+1},\ldots,u_K}\Big\{E_{\theta_{k+1},\ldots,\theta_K}\Big[\sum_{i=k+1}^{K} l(x_i,u_i,\theta_i) + l_F(x_F)\Big]\Big\}\Big]\Big\}. \tag{10.44}$$

里面的 min 和期望定义了 \(G^*_{k+1}\)，得到递推式（对照 (2.11) 和 (10.39)）

$$\begin{aligned}G^*_k(x_k) &= \min_{u_k\in U(x_k)}\Big\{E_{\theta_k}\Big[l(x_k,u_k,\theta_k) + G^*_{k+1}(x_{k+1})\Big]\Big\} \\ &= \min_{u_k\in U(x_k)}\Big\{\sum_{\theta_k\in\Theta(x_k,u_k)}\Big(l(x_k,u_k,\theta_k) + G^*_{k+1}(f(x_k,u_k,\theta_k))\Big)P(\theta_k\mid x_k,u_k)\Big\}.\end{aligned} \tag{10.45}$$

若代价项不依赖 \(\theta_k\)，可写成 \(l(x_k,u_k)\)，(10.45) 化简为

$$G^*_k(x_k) = \min_{u_k\in U(x_k)}\Big\{l(x_k,u_k) + \sum_{x_{k+1}\in X} G^*_{k+1}(x_{k+1})\,P(x_{k+1}\mid x_k,u_k)\Big\}. \tag{10.46}$$

状态转移对 \(\theta_k\) 的依赖隐含在 \(P(x_{k+1}\mid x_k,u_k)\) 里，它由 \(P(\theta_k\mid x_k,u_k)\) 和状态转移方程 \(f\) 定义。实现时 (10.46) 可能比 (10.45) 更方便。

收敛问题

如果问题定义里阶段数固定，收敛有保证。但若阶段数没有上限呢？回忆 2.3.2 节：每次值迭代把总路径长度增加 1；在后向动态规划里，真正的阶段编号并不重要，任意平移编号不影响结果。最终算法会因为所有能到达目标的状态都已算出代价到目标而停止，得到一个平稳的代价到目标函数 stationary cost-to-go function：能到达目标的状态收敛到有限值，其余保持 \(\infty\)。2.3.2 节提到，唯一能阻止平稳函数存在的是图里的负环：那时最好的计划是永远绕着环走，把代价降到 \(-\infty\)。

在现在的设定下，平稳的代价到目标函数依然会出现，但由于自然的影响，环带来的收敛困难更复杂。考虑基于计划的状态转移图 \(\mathcal{G}_\pi\) 会有帮助。先看非确定情形：若从某个 \(x_1\) 出发存在计划 \(\pi\)，使自然的所有可能动作都导致遍历累积负代价的环，那么 \(x_1\) 处的最优代价到目标收敛到 \(-\infty\)，值迭代无法终止。这种情形可以预先检测出来，并避开这样的初始状态（有些甚至可能在状态空间的另一个连通分量里）。

也可能存在无法避免的正环。2.3.2 节里，代价到目标函数的表现取决于目标集是否可达。由于自然，目标集可能是可能可达 possibly reachable 或保证可达 guaranteed reachable，如图 10.2 所示。从某个初始状态「可能可达」，是指存在计划 \(\pi\)，以及一串把状态带进目标集的自然动作；「保证可达」则要求不论自然动作的序列是什么都到达目标。如果从某个 \(x_1\) 出发目标只是可能可达而非保证可达，并且所有边的代价为正，那么重复值迭代时 \(x_1\) 的值趋于无穷。例如每个基于计划的状态转移图都可能含有正代价的环，最坏情况下自然可以让状态无限地绕下去。如果只在「目标保证可达」的状态上判断收敛，并且没有负环，那么所有代价到目标值都不再变化时算法就该停止。

图 10.2 的示意重画：(a) 目标可能可达，但不保证可达，因为可能出现无限循环；(b) 目标保证可达，因为所有的「流」都通向目标。（(b) 的边按「没有环」的原则重新排布，不是原图的逐边复制。）

概率情形有三种情况：

  1. 值迭代在有限次迭代后到达平稳的代价到目标函数。
  2. 值迭代在任何意义下都不收敛。
  3. 值迭代只是渐近地收敛到平稳函数，迭代次数随值收敛而趋于无穷。

前两种之前已经出现过：第一种发生在存在一个 \(\mathcal{G}_\pi\) 没有环的计划时；第二种发生在存在负环或正环、且环上所有边的概率都是 1 时——这本质上与非确定情形相同：最坏情况分析假定自然总施加最坏的动作，概率情形则是用概率 1 「强迫」了自然的动作。第三种是概率情形特有的：\(\mathcal{G}_\pi\) 中有正环或负环，但环上的边概率在 \((0,1)\) 之间；最优计划本身甚至都可能有这样的环。随着值迭代考虑越来越长的路径，环可能被多绕几圈，但每绕一圈概率就变小：概率随阶段数指数衰减，而代价只是线性累积。代价到目标函数的变化逐渐变小，只在迭代次数趋于无穷时才收敛到平稳值。如果可以接受一些近似误差，当整个 \(X\) 上的最大变化小于某个阈值 \(\epsilon\) 时就可以停止。得到所需质量的解要多少次迭代，取决于沿环走的概率和环的代价：概率越低，收敛越快。

例 10.6（转移图中的环）：设选定的计划 \(\pi\) 给出图 10.3 那样的基于计划的状态转移图，用概率模型，概率标在边上；为简单起见每次转移代价都是 1。从 \(x_I\) 出发的期望代价很好算：以概率 \(1/2\) 到达 \(x_G\) 的代价是 3；以概率 \(1/4\) 是 7；以概率 \(1/8\) 是 11。每多绕一圈代价增加 4，概率减半，于是得到无穷级数

$$G_\pi(x_I) = 3 + 4\sum_{i=1}^{\infty}\frac{1}{2^i} = 7. \tag{10.47}$$

这是标准的几何级数，和为 1，所以 (10.47) 收敛到 7。（补充：直接按定义写是 \(\sum_{i\ge1}2^{-i}(3+4(i-1))\)；(10.47) 用的是「绕圈次数 \(N\) 的期望 = \(\sum_{i\ge1}P(N\ge i)\)」这一尾和公式，\(P(N\ge i) = 2^{-i}\)，两者相等。）尽管代价收敛到有限值，这只在极限下发生：理论上需要无穷多次值迭代。大多数应用里近似解就够了，很少几次迭代就能得到很高的精度（书中举的例子是 20 次迭代后变化约十亿分之一）3，所以一般在最大变化小于某个基于精度的阈值时终止。注意如果用非确定不确定性，值迭代不收敛：最坏情况下自然会让状态永远绕圈。尽管目标不是保证可达，概率不确定性模型仍允许得到合理的解。

使用计划

假设阶段数没有上限。值迭代终止后得到 \(X\) 上的代价到目标函数——它还不完全是计划，因为计划要对每个 \(x\in X\) 给出一个动作。可以在 (10.45) 或 (10.39) 中记录产生最小值的 \(u\in U(x)\)。假设值迭代已经收敛到平稳的代价到目标函数。引入不确定性之前，最优动作由 (2.19) 决定；它的非确定和概率版本分别是

$$\pi^*(x) = \operatorname*{argmin}_{u\in U(x)}\Big\{\max_{\theta\in\Theta(x,u)}\Big\{l(x,u,\theta) + G^*(f(x,u,\theta))\Big\}\Big\} \tag{10.48}$$
$$\pi^*(x) = \operatorname*{argmin}_{u\in U(x)}\Big\{E_\theta\Big[l(x,u,\theta) + G^*(f(x,u,\theta))\Big]\Big\}. \tag{10.49}$$

对每个已知最优代价到目标的 \(x\)，算一次 (10.45) 就得到最好的动作。方便的是，最优动作可以在执行时直接恢复，不必存储动作：每次执行中到达 \(x_k\)，就在 \(x_k\) 处计算 (10.48) 或 (10.49) 选出 \(u_k = \pi^*(x_k)\)。这意味着只要明白需要一个局部算子来恢复动作，代价到目标函数本身就可以看作最优计划的一种表示。局部计算竟能得到全局最优，也许显得奇怪；这之所以成立，是因为代价到目标函数已经编码了全局代价。8.4.1 节的连续状态空间里也观察到同样的现象：导航函数定义了一个反馈运动计划，用梯度算子恢复运动方向；这里 (10.48) 和 (10.49) 起同样的作用。

10.2.2 策略迭代 Policy Iteration

10.2.1 节的值迭代是在状态空间上迭代地更新代价到目标值；最优计划也可以通过在计划空间里迭代搜索得到，这就是策略迭代 policy iteration（「策略 policy」是「计划」的同义词）。下面针对概率不确定性讲解，并假设 \(X\) 有限；稍作修改也可以得到非确定版本（习题 14）。

策略迭代反复需要计算给定计划 \(\pi\) 的代价到目标，即 (10.32) 的 \(G_\pi\)。先假设没有不确定性，状态转移方程是 \(x' = f(x,u)\)。2.3.2 节的动态规划方程 (2.18) 可以用来推导执行 \(\pi\) 时每个状态的代价到目标：对每个 \(x\in X\) 抄一份 (2.18)，并把其中的 min 换成给定的动作 \(u = \pi(x)\)：

$$G_\pi(x) = l(x,\pi(x)) + G_\pi(f(x,\pi(x))). \tag{10.50}$$

这里用 \(G_\pi\) 代替 \(G^*\)，因为已经没有变量需要优化（它只是执行 \(\pi\) 的代价）。可以把 (10.50) 看成一种平凡的动态规划：可选的计划被限制为单个 \(\pi\)；动态规划递推在所有计划的空间上成立，在只含一个计划的空间上当然也成立。若有 \(n\) 个状态，(10.50) 给出 \(n\) 个方程，每个都表达某个状态的 \(G_\pi(x)\)。对 \(x\in X_G\) 已知 \(G_\pi(x) = 0\)；于是一步能到达 \(X_G\) 的所有状态的代价可以用 (10.50) 及 \(G_\pi(f(x,\pi(x))) = 0\) 算出；接着又能算出一步能到达这些状态的状态……这一过程持续到所有状态的代价都算完，与 Dijkstra 算法的行为类似。这并不神秘：(10.50) 说明了状态转移图中相邻状态之间代价的差；所有差都给定、\(X_G\) 上又有初始条件，其它值就都能把这些差加起来得到。类似的想法出现在 Hamilton–Jacobi–Bellman 方程和 Pontryagin 极小值原理中（15.2 节）。

现在转到概率情形。(2.18) 的概率版本对应 (10.49)4。为简单起见考虑 \(l(x,u,\theta)\) 不依赖 \(\theta\) 的特殊情形：

$$\pi^*(x) = \operatorname*{argmin}_{u\in U(x)}\Big\{l(x,u) + \sum_{x'\in X} G^*(x')P(x'\mid x,u)\Big\}, \tag{10.51}$$

其中 \(x' = f(x,u)\)。代价到目标函数 \(G^*\) 满足动态规划递推式

$$G^*(x) = \min_{u\in U(x)}\Big\{l(x,u) + \sum_{x'\in X} G^*(x')P(x'\mid x,u)\Big\}. \tag{10.52}$$

把动作集合限制成单个计划 \(\pi\)，就得到 (10.50) 的概率版本：

$$G_\pi(x) = l(x,\pi(x)) + \sum_{x'\in X} G_\pi(x')P(x'\mid x,\pi(x)), \tag{10.53}$$

\(x'\) 是下一状态。对每个状态写出 (10.53) 就能确定执行 \(\pi\) 时每个 \(x\) 的代价到目标：除 \(G_\pi\) 外的量都已知，所以 \(n\) 个状态就有 \(n\) 个线性方程和 \(n\) 个未知数。(10.50) 也是这样，只是那里的方程简单得多；概率情形下必须解一个 \(n\) 元线性方程组，可以用经典的线性代数方法，例如奇异值分解 singular value decomposition（SVD）。

图 10.4　策略迭代算法 POLICY ITERATION ALGORITHM
取一个初始计划 π：在每个 x ∈ X_G 施加 u_T，其余动作任选。 用 (10.53) 计算计划 π 下每个 x ∈ X 的 G_π。 把算出的 G_π 当作 G*，用 (10.51) 算一个更好的计划 π′： π′(x) = argmin_{u∈U(x)} { l(x,u) + Σ_{x′∈X} G_π(x′) P(x′|x,u) } (10.54) 若 π′ 至少给出一个更低的代价到目标值，令 π = π′ 并重复第 2、3 步；否则宣布 π 为最优计划 π*。

有了计算计划代价的方法，策略迭代就很直接了（图 10.4）。注意第 3 步：为一个计划 \(\pi\) 算出的 \(G_\pi\) 被用来评估其它计划，结果是「第一阶段尝试一个新动作、之后都用 \(\pi\)」时的代价。如果新动作不能降低代价，\(\pi\) 一定已经是最优的，因为这意味着 (10.54) 已经等价于平稳的动态规划方程。如果能改进 \(\pi\)，就得到一个新计划；新计划一定严格优于前一个，而计划的总数有限，所以策略迭代在有限次迭代后收敛。

例 10.7（策略迭代的演示）：\(X = \{a,b,c\}\)，\(U = \{1,2,u_T\}\)，\(X_G = \{c\}\)。对所有 \(x\in X\) 和 \(u\in U\setminus\{u_T\}\)，\(l(x,u) = 1\)（施加 \(u_T\) 没有代价）。每个动作的概率状态转移图见图 10.5（下面互动图的两个面板）。第一步取初始计划：\(\pi(a) = 1\)、\(\pi(b) = 1\)，\(\pi(c) = u_T\)（因为 \(c\in X_G\)）。用 (10.53) 计算 \(G_\pi\)，得到三个方程：

$$G_\pi(a) = 1 + G_\pi(a)P(a\mid a,1) + G_\pi(b)P(b\mid a,1) + G_\pi(c)P(c\mid a,1) \tag{10.55}$$
$$G_\pi(b) = 1 + G_\pi(a)P(a\mid b,1) + G_\pi(b)P(b\mid b,1) + G_\pi(c)P(c\mid b,1) \tag{10.56}$$
$$G_\pi(c) = 0 + G_\pi(a)P(a\mid c,u_T) + G_\pi(b)P(b\mid c,u_T) + G_\pi(c)P(c\mid c,u_T). \tag{10.57}$$

每个方程对应一个状态，使用 \(\pi\) 中相应的动作。最后一个方程按终止动作的基本规则化为 \(G_\pi(c) = 0\)。代入 \(P(x'\mid x,u)\) 和 \(G_\pi(c) = 0\) 后，另两个方程变成

$$G_\pi(a) = 1 + \tfrac13 G_\pi(a) + \tfrac13 G_\pi(b) \tag{10.58}$$
$$G_\pi(b) = 1 + \tfrac13 G_\pi(a) + \tfrac13 G_\pi(b). \tag{10.59}$$

解得 \(G_\pi(a) = G_\pi(b) = 3\)。现在用 \(G_\pi(a) = G_\pi(b) = 3\)、\(G_\pi(c) = 0\) 对每个状态用 (10.54) 找更好的计划 \(\pi'\)。在状态 \(a\) 处求解

$$\pi'(a) = \operatorname*{argmin}_{u\in U}\Big\{l(x,a) + \sum_{x'\in X} G_\pi(x')P(x'\mid x,a)\Big\}. \tag{10.60}$$

（(10.60) 照抄原书：这里的 \(l(x,a)\)、\(P(x'\mid x,a)\) 按意思应读作 \(l(a,u)\)、\(P(x'\mid a,u)\)。）

最好的动作是 \(u = 2\)，代价为 5/2：

$$l(x,2) + \sum_{x'\in X} G_\pi(x')P(x'\mid x,2) = 1 + 0 + (3)\tfrac12 + (0)\tfrac12 = \tfrac52. \tag{10.61}$$

所以 \(\pi'(a) = 2\)5。类似地 \(\pi'(b) = 2\)，代价 7/4；\(\pi'(c) = u_T\)，这就确定了一个改进的计划。既然找到了改进的计划，用 \(\pi'\) 取代 \(\pi\)，回到第 2 步。新计划给出方程

$$G_\pi(a) = 1 + \tfrac12 G_\pi(b) \tag{10.62}$$
$$G_\pi(b) = 1 + \tfrac14 G_\pi(a). \tag{10.63}$$

解得 \(G_\pi(a) = 12/7\)、\(G_\pi(b) = 10/7\)。下一步试图用 (10.54) 找更好的计划，但发现当前计划无法再改进，策略迭代正确地报告 \(\pi^* = \pi\) 并终止。

10.2.3 图搜索方法 Graph Search Methods

值迭代很通用，但在很多情况下，大部分时间浪费在不更新值的状态上：要么最优代价到目标早已知道，要么目标还没「传」到那里。策略迭代似乎缓解了这个问题，但它只适用于小状态空间。这些不足促使人们考虑别的办法，比如推广 2.2 节的图搜索方法。在某些情况下 Dijkstra 算法甚至可以推广，快速得到最优解，但需要对解的结构做一个很强的假设。在非确定情形，可以发展出只求可行解、不管最优性的搜索方法。对本节的方法，只要搜索是 2.2 节意义下的系统的 systematic，\(X\) 不必有限。

用反向投影做后向搜索

可以从 \(X_G\) 出发，用反向投影逐步向外扩展一个计划。图 10.6 给出了非确定不确定性下求可行计划的一个完备算法。令 \(S\) 为已经算好计划的状态集合：初始 \(S = X_G\)，可能的话 \(S\) 会一直长到 \(S = X\)。计划一开始对每个 \(x\in X_G\) 定为 \(\pi(x) = u_T\)，执行过程中再逐步扩展到新状态。

图 10.6　反向投影算法 BACKPROJECTION ALGORITHM（非确定不确定性下求可行计划）
初始化 S = X_G，对每个 x ∈ X_G 令 π(x) = u_T。 对每个 x ∈ X ∖ S：若存在 u ∈ U(x) 使 x ∈ SB(S, u)，则 1) 令 π(x) = u，2) 把 x 插入 S。 若第 2 步没能扩大 S 就退出——这意味着 SB(S) = S，不可能再有进展。否则回到第 2 步。

第 2 步检查每个还不在 \(S\) 中的状态 \(x\) 是否应该加入：要判断是否存在某个动作 \(u\)，使从 \(x\) 施加 \(u\) 后的下一状态保证落在 \(S\) 里（图 10.7）。若是，就令 \(\pi(x) = u\) 并把 \(x\) 加入 \(S\)。若不能再有进展，算法就必须终止；否则回到第 2 步再检查每个状态——这是必要的，因为 \(S\) 变大了，下一轮可能有新的状态落进它的强反向投影里。出于效率考虑，第 2 步中的 \(X\setminus S\) 可以安全地换成更小的集合 \(\mathrm{WB}(S)\setminus S\)，因为其它状态不可能受影响。视具体问题，这个条件可能是快速剪掉许多无望状态的好办法。例如在一个任何时刻任何方向最多走两步的网格环境里，一个简单的距离测试就能排除许多不可能加入 \(S\) 的状态。只要考虑哪些状态加入 \(S\) 的方式是系统的（2.2 节），图 10.6 的算法就有很多变体。一种是同时维护代价到目标、按最小代价逐个插入状态来扩大 \(S\)——这就是下面的非确定版 Dijkstra 算法。

图 10.7 / 10.9 的示意重画。左：若存在 \(u\in U(x)\) 使一步前向投影整个落在 \(S\) 里，\(x\) 就能加入 \(S\)。右：对这样的 \(x\) 计算最坏情况代价到目标——前向投影落在更新后的 \(S\) 里，并且其中一个状态正是刚加入的 \(x_s\)。

非确定 Dijkstra

图 10.8 把 Dijkstra 算法推广到非确定不确定性下的 Formulation 10.1。它也可以看成图 10.6 算法的一个变体，因为它用反向投影扩大 \(S\)。图 10.8 是 Dijkstra 算法的后向搜索版本，所以它维护最坏情况代价到目标 \(G\)，这个 \(G\) 有时会成为最优的最坏情况代价到目标 \(G^*\)。初始时 \(X_G\) 中的状态 \(G = 0\)，其余 \(G = \infty\)。

图 10.8　非确定 Dijkstra NONDETERMINISTIC DIJKSTRA（非确定不确定性下求最优可行计划）
初始化 S = ∅，A = X_G；每个 x ∈ A 关联 u_T；A 中 G(x) = 0，其余状态 G(x) = ∞。 若 A 非空，取出 A 中 G 最小的 x_s 及其对应的 u；若 A 为空则退出（不可能再有进展）。 令 π*(x_s) = u 作为最优计划的一部分，把 x_s 插入 S；宣布 G*(x_s) = G(x_s)。 对前沿集合 Front(x_s, S) 中的每个 x 用 (10.64) 计算 G(x)，把 Front(x_s, S) 连同对应动作插入 A； 已经在 A 中的状态保留较低的 G 值（原来的或新算出的）。回到第 2 步。

第 1 步初始化。第 2 步选出 \(A\) 中值最小的状态。和确定性问题的 Dijkstra 算法一样，可以知道这个状态的代价到目标是最小可能的，因此第 3 步宣布 \(G^*(x_s) = G(x_s)\)，并把 \(\pi^*\) 扩展到 \(x_s\)。第 4 步更新一些状态的代价并扩大活跃集 \(A\)。把 \(x_s\) 插入 \(S\) 会立刻影响哪些状态的代价？是那些 \(x_k\in X\setminus S\)：存在 \(u_k\in U(x_k)\)，其一步前向投影 \(X_{k+1}(x_k,u_k)\) 满足 1）\(x_s\in X_{k+1}(x_k,u_k)\) 且 2）\(X_{k+1}(x_k,u_k)\subseteq S\)（图 10.9）。满足这两个条件的状态集合称为前沿集合 frontier set，记作 \(\mathrm{Front}(x_s,S)\)。对每个 \(x\in\mathrm{Front}(x_s,S)\)，令 \(U_f(x)\subseteq U(x)\) 为前向投影满足这两个条件的所有动作。

前沿集合也可以用反向投影来理解：弱反向投影 \(\mathrm{WB}(x_s)\) 给出所有可能一步到达 \(x_s\) 的状态；但代价到目标只对 \(\mathrm{SB}(S)\) 中的状态有限（这里 \(S\) 已含 \(x_s\)）；\(S\) 中的状态显然要排除，因为它们的最优代价已知。这样候选前沿状态缩小到 \((\mathrm{WB}(x_s)\cap\mathrm{SB}(S))\setminus S\)。这个集合仍然太大，因为必须是同一个动作 \(u\) 产生的前向投影既包含 \(x_s\) 又是 \(S\) 的子集。对所有 \(x\in\mathrm{Front}(x_s,S)\)，最坏情况代价到目标按下式计算：

$$G(x) = \min_{u\in U_f(x)}\Big\{\max_{\theta\in\Theta(x,u)}\Big\{l(x,u,\theta) + G(f(x,u,\theta))\Big\}\Big\}, \tag{10.64}$$

用的是受限的动作集合 \(U_f(x)\)。若 \(x\) 已经在 \(A\) 中且算过 \(G(x)\)，则保留原值与 (10.64) 中的较小者。

概率 Dijkstra

Dijkstra 算法的概率版本一般不存在；但对某些问题可以让它奏效。把图 10.8 的算法改用

$$G(x) = \min_{u\in U_f(x)}\Big\{E_\theta\Big[l(x,u,\theta) + G(f(x,u,\theta))\Big]\Big\} \tag{10.65}$$

代替 (10.64)。Front 的定义不变，概率问题仍然使用非确定的前向投影：转移图中概率非零的边才被当作可能的未来状态，概率为零的边从前向投影中排除，因为它们不会影响算出的代价。当存在一个计划 \(\pi\)，使得从任何 \(x_k\in X\) 出发都以概率 1 有 \(G_\pi(x_{k+1}) < G_\pi(x_k)\) 时，概率版的 Dijkstra 算法可以成功应用。这个条件是什么意思？从任何 \(x_k\) 出发，所有概率非零的下一状态都必须有更低的代价值。若所有边的代价为正，这就是说多阶段前向投影里的所有路径都朝目标单调前进。确定性情形下只要 \(l(x,u)\) 为正就总是如此。如果可能出现非单调的路径，Dijkstra 算法就会失效，因为代价到目标值发生变化的区域不再局限于一条向外传播的「带」里——而那正是确定性问题中 Dijkstra 算法的特点。

10.3 无限时域问题 Infinite-Horizon Problems

在随机控制理论和人工智能研究中，迄今考虑的大多数问题都不指定目标集，因此也没有终止动作。任务是找一个计划，使若干阶段上的期望代价最小（或期望回报最大）。若阶段数有限，直接套用 10.2.1 节的值迭代即可：后向值迭代到第一个阶段就停。阶段数无穷时问题更具挑战性，这称为无限时域问题 infinite-horizon problem。

10.1 节的规划问题阶段数也是无穷的，但那里预期只要目标可达，终止就会在有限次迭代内发生。没有终止条件，代价会趋于无穷。有两种替代的代价模型强迫代价变为有限：折扣代价模型 discounted cost model 让每阶段的代价随阶段向未来推进而缩小，总代价成为一个收敛的几何级数；平均每阶段代价模型 average cost-per-stage model 把总代价除以阶段数，本质上是做归一化，同样防止发散到无穷。10.2 节的部分计算方法可以改造到这两个模型上。

10.3.1 问题表述

两种代价模型都是为了在阶段数无穷时迫使累积代价有限，都可以看成对 Formulation 10.1 代价泛函的小改动。下面的表述在整个 10.3 节使用：

Formulation 10.2（无限时域问题 Infinite-Horizon Problems）
  1. 非空、有限的状态空间 \(X\)。
  2. 对每个 \(x\in X\)，有限的动作空间 \(U(x)\)（没有终止动作，与 Formulation 10.1 相反）。
  3. 对每个 \(x\in X\)、\(u\in U(x)\)，有限的自然动作空间 \(\Theta(x,u)\)。
  4. 状态转移函数 \(f(x,u,\theta)\)。
  5. 一组阶段，从 \(k = 1\) 开始无限延续。
  6. 阶段可加的代价泛函 \(L(\tilde{x},\tilde{u},\tilde\theta)\)，其中 \(\tilde{x}\)、\(\tilde{u}\)、\(\tilde\theta\) 分别是无穷的状态、动作和自然历史。下面给出两种形式。

与 Formulation 10.1 相比，这里没有初始状态和目标状态，所以也没有终止动作。没有目标集，这种规划看起来也许有些奇怪；反馈计划 \(\pi\) 的形式不变：对每个 \(x\in X\) 给出 \(u\in U(x)\)。一个可能的应用：工厂里的机器人在多个来源和多个目的地之间运送物料。它工作一整个长班次，对「运送请求何时到来」有一个概率模型。可以用 Formulation 10.2 定义一个使物料平均等待时间最短的问题。这个策略不应依赖于班次长度，所以阶段数无穷是合理的；如果班次太短，机器人可能只专注于一次运送，甚至来不及完成。

折扣代价

Formulation 10.2 的第 6 项必须小心定义，保证即使阶段数趋于无穷也总得到有限值。折扣代价模型提供了一个简单办法：让未来阶段的代价迅速减小。它基于标准的几何级数：对任意实参数 \(\alpha\in(0,1)\)，

$$\lim_{K\to\infty}\Big(\sum_{k=0}^{K}\alpha^k\Big) = \frac{1}{1-\alpha}. \tag{10.66}$$

最简单的情形 \(\alpha = 1/2\) 给出 \(1 + 1/2 + 1/4 + 1/8 + \cdots\)，显然收敛到 2。现在令 \(\alpha\in(0,1)\) 为折扣因子 discount factor，用于代价泛函的定义：

$$L(\tilde{x},\tilde{u},\tilde\theta) = \lim_{K\to\infty}\Big(\sum_{k=0}^{K}\alpha^k l(x_k,u_k,\theta_k)\Big). \tag{10.67}$$

记 \(l_k\) 为阶段 \(k\) 收到的代价 \(l(x_k,u_k,\theta_k)\)。为了方便，在这里第一个阶段记为 \(k = 0\)，而不是之前用的 \(k = 1\)。随着最大阶段 \(K\) 增大，未来远处的代价重要性越来越小，这很容易从图 10.10 看出。

阶段\(L^*_K\)
\(K = 0\)\(l_0\)
\(K = 1\)\(l_0 + \alpha l_1\)
\(K = 2\)\(l_0 + \alpha l_1 + \alpha^2 l_2\)
\(K = 3\)\(l_0 + \alpha l_1 + \alpha^2 l_2 + \alpha^3 l_3\)
\(K = 4\)\(l_0 + \alpha l_1 + \alpha^2 l_2 + \alpha^3 l_3 + \alpha^4 l_4\)

图 10.10：代价的量级随阶段指数衰减。

代价减小的速度强烈依赖于 \(\alpha\)：\(\alpha = 1/2\) 时代价下降得很快；\(\alpha = 0.999\) 时趋于零就慢得多。权衡在于：\(\alpha\) 大时考虑了更多阶段，设计出的计划通常质量更高；\(\alpha\) 小时值迭代之类的方法收敛快得多，但解的质量可能因为「短视 short sightedness」而变差。(10.67) 中的 \(l(x_k,u_k,\theta_k)\) 依 \(x_k\)、\(u_k\)、\(\theta_k\) 取不同的值；由于只有有限种可能，它们一定以某个正常数 \(c\) 为界（书中脚注：\(X\) 甚至可以是无穷的，只要可能的代价集合有界）。因此

$$\lim_{K\to\infty}\Big(\sum_{k=0}^{K}\alpha^k l(x_k,u_k,\theta_k)\Big) \le \lim_{K\to\infty}\Big(\sum_{k=0}^{K}\alpha^k c\Big) \le \frac{c}{1-\alpha}, \tag{10.68}$$

这说明 \(L(\tilde{x},\tilde{u},\tilde\theta)\) 有上界；类似地可以构造下界，保证总代价总是有限的。

试一试
  • α = 1/2：1 + 1/2 + 1/4 + … → 2，几个阶段之后权重就可以忽略（第 7 个阶段起权重低于 1%）。
  • α = 0.99：极限是 100，前 60 个阶段加起来还远没到；α = 0.999 时要几百个阶段权重才降到 1% 以下——这就是「α 越大考虑的未来越长，但值迭代越慢」。
  • 切到「代价时高时低」：折扣后的累计代价依然被 (10.68) 的 c/(1−α) 压住。

平均每阶段代价

折扣代价的替代方案是平均每阶段代价模型，它把总代价除以阶段数来保持有限：

$$L(\tilde{x},\tilde{u},\tilde\theta) = \lim_{K\to\infty}\Big(\frac{1}{K}\sum_{k=0}^{K-1} l(x_k,u_k,\theta_k)\Big). \tag{10.69}$$

用每阶段代价的上界 \(c\)，显然即使 \(K\to\infty\)，(10.69) 也不会超过 \(c\)。这个模型有时更可取，因为代价不依赖任意的参数 \(\alpha\)。

10.3.2 求解技术

10.2 节的值迭代和策略迭代对无限时域问题有直接的改造，下面介绍；但要注意，关于它们的收敛性和数值稳定性还有许多其它重要问题。还有几种更复杂的变体这里不讲，它们很重要，因为解决了很多这类问题。本节的要点是理解与 10.1、10.2 节问题之间简单的关系。

折扣代价的值迭代

后向值迭代的解自然地沿用 10.2.1 节的方法。为了记号方便，令第一个阶段为 \(k = 0\)，这样 \(\alpha^{k-1}\) 可以换成 \(\alpha^k\)。概率情形下的期望最优代价到目标是

$$G^*(x) = \lim_{K\to\infty}\Big(\min_{\tilde{u}}\Big\{E_{\tilde\theta}\Big[\sum_{k=1}^{K}\alpha^k l(x_k,u_k,\theta_k)\Big]\Big\}\Big). \tag{10.70}$$

期望取遍所有自然历史，每个都是自然动作的无穷序列。非确定情形对应的表达式是6

$$G^*(x) = \lim_{K\to\infty}\Big(\min_{\tilde{u}}\Big\{\max_{\tilde\theta}\Big\{\sum_{k=1}^{K}\alpha^k l(x_k,u_k,\theta_k)\Big\}\Big\}\Big). \tag{10.71}$$

概率情形更常见，下面只讲它；非确定版本类似处理（习题 17）。和以前一样用后向值迭代，因为它们更容易表达。折扣因子带来一个小麻烦，要修正之后动态规划递推才能正常工作。困难在于阶段编号现在以 \(\alpha^k\) 的形式出现在代价函数里，2.3.1.1 节的平移不变性不再成立，必须小心对待阶段编号——而后向值迭代的最终阶段编号原本是未知且不重要的。

考虑一系列折扣决策问题，最大阶段编号依次为 \(K = 0, 1, 2, \ldots\)。看图 10.10 中相邻两行：求 \(K+1\) 阶段问题和 \(K\) 阶段问题的最优代价到目标有什么区别？\(K = 4\) 那一行的后四项，可以把 \(K = 3\) 那一行的所有项乘以 \(\alpha\) 再加一个新项 \(l_0\) 得到；唯一的不同是从 \(K = 3\) 借来的每个 \(l_i\) 的下标要平移一位。一般地，\(K\) 阶段优化问题的最优代价乘以 \(\alpha\) 后，就能充当 \(K+1\) 阶段问题的最优代价：\(K+1\) 阶段问题可以通过优化「第一阶段代价 + 折扣 \(\alpha\) 后的 \(K\) 阶段最优代价」来求解。用直接的动态规划论证可以推出：设 \(K\) 固定，对 \(k\) 从 0 到 \(K\)，代价到目标可以递归地写成

$$G^*_k(x_k) = \min_{u_k\in U(x_k)}\Big\{E_{\theta_k}\Big[\alpha^k l(x_k,u_k,\theta_k) + G^*_{k+1}(x_{k+1})\Big]\Big\}, \tag{10.72}$$

其中 \(x_{k+1} = f(x_k,u_k,\theta_k)\)。问题是这个递推通过 \(\alpha^k\) 依赖于 \(k\)，看起来不平稳。按图 10.10 利用相邻代价值的想法，做一个记号变换：令 \(J^*_{K-k}(x_k) = \alpha^{-k}G^*_k(x_k)\)。这把阶段编号的方向反过来，避免指定最终阶段，同时用 \(\alpha^{-k}\) 抵消编号的变化。代入 (10.72)：

$$\alpha^k J^*_{K-k}(x_k) = \min_{u_k\in U(x_k)}\Big\{E_{\theta_k}\Big[\alpha^k l(x_k,u_k,\theta_k) + \alpha^{k+1}J^*_{K-k-1}(x_{k+1})\Big]\Big\}. \tag{10.73}$$

两边除以 \(\alpha^k\)，再令 \(i = K-k\)：

$$J^*_i(x_k) = \min_{u_k\in U(x_k)}\Big\{E_{\theta_k}\Big[l(x_k,u_k,\theta_k) + \alpha J^*_{i-1}(x_{k+1})\Big]\Big\}, \tag{10.74}$$

其中 \(J^*_i\) 表示 \(K = i\) 的有限时域折扣问题的期望代价。注意 (10.74) 用 \(J^*_{i-1}\) 表示 \(J^*_i\)，而 \(x_k\) 是给定的、右边用的是 \(x_{k+1}\)：下标看起来朝相反方向走，因为这只是去掉了一些下标的后向值迭代。只要 \(x_{k+1} = f(x_k,u_k,\theta_k)\)，\(x_k\)、\(x_{k+1}\) 具体用什么下标不重要（例如可以放心地代换成 \(x = x_k\)、\(x' = x_{k+1}\)、\(u = u_k\)、\(\theta = \theta_k\)）。

值迭代先令所有 \(x\in X\) 的 \(J^*_0(x_0) = 0\)，然后在状态空间上反复用 (10.74) 计算后续的代价到目标函数。在 10.2.1 节「避免环」的假设下，由于时域无穷，收敛通常是渐近的；折扣逐渐让代价差缩小，直到在所需容差之内。取 \(i\to\infty\) 的极限，得到动态规划递推的平稳形式：

$$J^*(x) = \min_{u\in U(x)}\Big\{E_{\theta}\Big[l(x,u,\theta) + \alpha J^*(f(x,u,\theta))\Big]\Big\}. \tag{10.75}$$

若代价项不依赖自然，化简为

$$J^*(x) = \min_{u\in U(x)}\Big\{l(x,u) + \alpha\sum_{x'\in X} J^*(x')P(x'\mid x,u)\Big\}. \tag{10.76}$$

和 10.2.1 节一样，最优动作 \(\pi^*(x)\) 取在 \(x\) 处满足 (10.75) 或 (10.76) 的 \(u\in U(x)\)。

折扣代价的策略迭代

也可以用策略迭代求解概率折扣代价问题。回忆图 10.4：总体思路不变——每次迭代解一个线性方程组，在计划空间里搜索。第 2 步的 (10.53) 换成

$$J_\pi(x) = l(x,u) + \alpha\sum_{x'\in X} J_\pi(x')P(x'\mid x,u), \tag{10.77}$$

它是 (10.76) 在固定计划下的特殊形式（这里的 \(u\) 即 \(\pi(x)\)）。第 3 步的 (10.54) 换成

$$\pi'(x) = \operatorname*{argmin}_{u\in U(x)}\Big\{l(x,u) + \alpha\sum_{x'\in X} J_\pi(x')P(x'\mid x,u)\Big\}. \tag{10.78}$$

做了这些改动，策略迭代就和 10.2.2 节一样进行。

平均每阶段代价的解法

平均代价模型的值迭代算法可以通过简单地不除以 \(K\) 得到：随着阶段数趋于无穷，优化总代价的动作同样优化平均代价。这可能使代价趋向 \(\pm\infty\)，不过实际中只执行有限次迭代。10.2.1 节的后向值迭代只需很小的修改：初始时对所有 \(x_F\in X\) 令 \(G^*(x_F) = 0\)，用标准形式计算值迭代：

$$G^*_k(x_k) = \min_{u_k\in U(x_k)}\Big\{\sum_{\theta\in\Theta(x_k,u_k)}\Big(l(x_k,u_k,\theta) + G^*_{k+1}(f(x_k,u_k,\theta))\Big)P(\theta\mid x_k,u_k)\Big\}. \tag{10.79}$$

迭代一直进行到收敛。判断解的质量是否足够，一个合理的判据是

$$\max_{x\in X}\Big\{\big|G^*_k(x)/N - G^*_{k+1}(x)/(N-1)\big|\Big\} < \epsilon, \tag{10.80}$$

其中 \(\epsilon\) 是误差容限，\(N\) 是已完成的值迭代次数（(10.80) 要求 \(N > 1\)）。一旦满足 (10.80) 就可以停止迭代。\(G^*(x)\) 的值不断增大可能带来数值问题：可以定期把所有值缩小一个常数因子，保证数值在浮点范围内。文献 [12] 介绍了一种叫相对值迭代 relative value iteration 的方法：任意选定一个状态 \(s\in X\)，把代价到目标值都表示成减去 \(s\) 处代价后的相对值。这同时压低所有值，使它们保持有界，同时仍保持算法的收敛性质。策略迭代也可以只稍作修改地沿用图 10.4。

10.4 强化学习 Reinforcement Learning

10.4.1 基本思路 The General Philosophy

这一节简要介绍一个近年在人工智能界非常流行的框架的基本思想。它主要由机器学习研究者发展和使用，因此本节称为强化学习 reinforcement learning。这个问题一般涉及为概率无限时域问题计算最优计划；基本想法是把「学习概率分布 \(P(\theta\mid x,u)\)」和「计算最优计划」合并到同一个算法里。

术语

在详细讲方法之前，先解释一下已有的各种名称。强化学习：机器学习里大多数决策论模型用回报 reward 而不是代价来表达，任务是做决策或找计划使回报泛函 reward functional 最大。在这个模型下选好的动作，会以回报的形式得到正向的「强化」，所以叫 reinforcement。若改用代价和最小化，也可以叫决策论学习 decision-theoretic learning 或基于代价的学习 cost-based learning。叫「学习」，是因为估计 \(P(\theta\mid x,u)\) 或 \(P(x'\mid x,u)\) 显然是个学习问题；但要记住这里也有计算代价到目标函数（或回报到目标函数）并确定最优计划的规划问题，所以叫强化规划 reinforcement planning 也同样合理。

文献 [13] 称这个一般框架为神经动态规划 neuro-dynamic programming，因为其表述和算法都基于动态规划，最常得到的是值迭代的某种变体；「neuro」指可用来近似计划和代价到目标值的一族函数。这个说法相当具体，因为也可以用别的函数族；而且对某些问题（例如很小的有限状态空间），代价值和计划无需近似就能表示。文献 [11] 用的名字是基于模拟的方法 simulation-based methods，在动态规划的语境下这也许是最准确的名字之一；于是基于模拟的动态规划或基于模拟的规划都很好地反映了这里讲的框架。「模拟」一词来自用蒙特卡罗模拟器生成样本、在规划过程中学习所需的分布。用什么名字随你，但要记住各种名字背后是同一个想法——读相关文献时这一点很有帮助。

一般框架

这个框架通常用于概率不确定性下的无限时域问题，最常用的是折扣代价模型；但我们主要用 Formulation 10.1，因为它更贴近本书的主题。到目前为止都假设在 Formulation 10.1 下做规划时所有模型分量都已知，包括 \(P(x_{k+1}\mid x_k,u_k)\)。这可以看成传统框架，有三个阶段：

  • 学习阶段：访问 \(X\) 中的状态、尝试动作、收集统计量来估计转移概率。这一阶段结束时，环境的模型完全已知。
  • 规划阶段：用值迭代或策略迭代之类的方法算出反馈计划。
  • 执行阶段：在一台机器上执行计划，这台机器连接的正是学习阶段所用的同一个环境。

图 10.11 的重画：强化学习（或基于模拟的动态规划）的一般框架。

基于模拟的框架把三个阶段合而为一：学习、规划和执行全由一台起初对状态转移甚至代价项一无所知的机器完成。理想情况下这台机器应连接一个 Markov 模型成立的物理环境；但几乎所有实现里，它连接的是图 10.11 那样的蒙特卡罗模拟器。算法根据当前状态把动作 \(u_k\) 发给模拟器，模拟器按内部的概率分布抽样算出效果。显然模拟器的设计者知道转移概率，但它们不直接交给规划算法。模拟器再把下一状态 \(x_{k+1}\) 和代价 \(l(x_k,u_k)\) 发回算法。

为了简单，这里用 \(l(x_k,u_k)\)，而不允许代价依赖具体的自然动作（那会是 \(l(x_k,u_k,\theta_k)\)）。这个框架通常不需要显式刻画自然：概率 \(P(x_{k+1}\mid x_k,u_k)\) 是直接学到的，不必指定自然动作。常见的推广是把代价项从 \(l(x_k,u_k)\) 推广到 \(l(x_k,u_k,x_{k+1})\)，这里为记号方便不这么做；基本思想不变，只需对下面的方程做些小改动。

模拟器的作用是模拟「现实」——机器与物理世界的交互。它取代了 1.4 节图 1.16b 中的环境。按那一节的理解，这里讲的算法在此语境下可以看成图 1.18b 那样的计划。若学习部分终止，得到的反馈计划可以编进另一台机器，如图 1.18a；这一步通常不做，因为常假设机器会在整个生命周期里持续学习。

主要问题之一是探索与利用 exploration vs. exploitation：需要反复探索状态空间，收集足够的数据以可靠地估计模型；为了理论上的收敛，每个状态—动作对都必须被尝试无穷多次。另一方面，又应该利用关于模型的信息来高效地完成任务。这两个目标常常冲突：过于注重探索不能优化代价；过于注重利用则可能因为更好的选择还没被发现而得不到有用的解。

10.4.2 用模拟评估计划 Evaluating a Plan via Simulation

模拟方法的基础是把从样本中逐步获得的信息平均起来。假设你收到一串代价 \(c_1,c_2,\ldots\)，想增量地计算它们的平均值：不告诉你样本总数，而且随时都要报告当前的平均值。令 \(m_i\) 为前 \(i\) 个样本的平均：

$$m_i = \frac{1}{i}\sum_{j=1}^{i} c_j. \tag{10.81}$$

要从 \(m_{i-1}\) 高效地算 \(m_i\)：把 \(m_{i-1}\) 乘以 \(i-1\) 恢复总和，加上 \(c_i\)，再除以 \(i\)：

$$m_i = \frac{(i-1)m_{i-1} + c_i}{i}, \tag{10.82}$$

整理成

$$m_i = m_{i-1} + \frac{1}{i}(c_i - m_{i-1}). \tag{10.83}$$

现在考虑为某个固定计划 \(\pi\) 估计每个 \(x\in X\) 的期望代价到目标 \(G_\pi(x)\)。如果 \(P(x'\mid x,u)\) 和代价 \(l(x,u)\) 已知，可以解

$$G_\pi(x) = l(x,u) + \sum_{x'} P(x'\mid x,u)G_\pi(x') \tag{10.84}$$

得到（这里 \(u = \pi(x)\)）。但没有这些信息，就只能依靠模拟器。假设从每个 \(x\in X\) 做 1000 次试验，记录并平均到达目标的代价。每次试验都是迭代过程：\(\pi\) 选动作，模拟器给出下一状态及其增量代价。一旦到达目标状态，把代价加总得到这次试验测得的代价到目标（这里假设对所有 \(x\in X_G\) 有 \(\pi(x) = u_T\)）。若 \(c_i\) 是第 \(i\) 次试验的总代价，\(i\) 次试验的平均 \(m_i\) 就是 \(G_\pi(x)\) 的估计；\(i\to\infty\) 时我们期望 \(m_i\) 收敛到 \(G_\pi(x)\)。更新公式 (10.83) 可以方便地维护不断改进的代价估计序列：令 \(\hat{G}_\pi(x)\) 为 \(G_\pi(x)\) 的当前估计，基于 (10.83) 的更新公式是

$$\hat{G}_\pi(x) := \hat{G}_\pi(x) + \frac{1}{i}\Big(l(x_1,u_1) + l(x_2,u_2) + \cdots + l(x_K,u_K) - \hat{G}_\pi(x)\Big), \tag{10.85}$$

其中 \(:=\) 表示赋值（就像某些编程语言里那样）。实际上一次试验就能为多个状态给出更新值。设从 \(x\) 出发的试验访问了 \(x_1 = x, x_2, \ldots, x_k, \ldots, x_K, x_F\)。对序列中每个状态 \(x_k\)，都可以记录从 \(x_k\) 到 \(x_K\) 累积的代价作为测得的代价到目标：

$$c_k(x_k) = \sum_{j=k}^{K} l(x_j,u_j). \tag{10.86}$$

对路径上访问的每个状态都用 (10.85) 更新，效率高得多。

时间差分 Temporal differences

与其等到每次试验结束才算 \(c_i(x_i)\)，不如在访问 \(x_i\) 并从模拟器收到 \(l(x_i,u_i)\) 之后立即更新它。这引出一个著名的代价到目标估计方法——时间差分 temporal differences。它与上面的方法很相似，只是稍复杂一些；之所以介绍，是因为它在强化学习文献里非常常见，而且它的推广能得到一个很好的、基于模拟更新代价到目标估计的方法。仍考虑一次试验产生的序列 \(x_1,\ldots,x_K,x_F\)，令 \(d_k\) 为时间差分：

$$d_k = l(x_k,u_k) + \hat{G}_\pi(x_{k+1}) - \hat{G}_\pi(x_k). \tag{10.87}$$

注意 \(l(x_k,u_k) + \hat{G}_\pi(x_{k+1})\) 和 \(\hat{G}_\pi(x_k)\) 都可以作为 \(G_\pi(x_k)\) 的估计；区别在于前者用模拟器给出的第一步最新代价，再用 \(\hat{G}_\pi(x_{k+1})\) 估计剩余代价。在这里和以下的式子中，每个动作都由计划选出：\(u_k = \pi(x_k)\)。令 \(v_k\) 为 \(x_k\) 到目前为止被访问的次数（\(1\le k\le K\)），包括以前的试验和本次访问。试验过程中可以使用下面的更新算法：到达 \(x_2\) 时，\(x_1\) 处的值更新为

$$\hat{G}_\pi(x_1) := \hat{G}_\pi(x_1) + \frac{1}{v_1}d_1. \tag{10.88}$$

到达 \(x_3\) 时，\(x_1\) 和 \(x_2\) 处的值更新为

$$\hat{G}_\pi(x_1) := \hat{G}_\pi(x_1) + \frac{1}{v_1}d_2,\qquad \hat{G}_\pi(x_2) := \hat{G}_\pi(x_2) + \frac{1}{v_2}d_2. \tag{10.89}$$

看看到此为止对 \(x_1\) 做了什么——时间差分部分抵消：

$$\begin{aligned}\hat{G}_\pi(x_1) &:= \hat{G}_\pi(x_1) + \frac{1}{v_1}d_1 + \frac{1}{v_1}d_2 \\ &= \hat{G}_\pi(x_1) + \frac{1}{v_1}\Big(l(x_1,u_1) + \hat{G}_\pi(x_2) - \hat{G}_\pi(x_1) + l(x_2,u_2) + \hat{G}_\pi(x_3) - \hat{G}_\pi(x_2)\Big) \\ &= \hat{G}_\pi(x_1) + \frac{1}{v_1}\Big(l(x_1,u_1) + l(x_2,u_2) - \hat{G}_\pi(x_1) + \hat{G}_\pi(x_3)\Big).\end{aligned} \tag{10.90}$$

到达 \(x_4\) 时做类似的更新。到达 \(x_{k+1}\) 时的更新是

$$\hat{G}_\pi(x_1) := \hat{G}_\pi(x_1) + \frac{1}{v_1}d_k,\quad \hat{G}_\pi(x_2) := \hat{G}_\pi(x_2) + \frac{1}{v_2}d_k,\quad\ldots,\quad \hat{G}_\pi(x_k) := \hat{G}_\pi(x_k) + \frac{1}{v_k}d_k. \tag{10.91}$$

这样一直更新到到达 \(x_F\in X_G\)。现在看对每个 \(x_k\) 实际算了什么：时间差分构成一个望远镜式的、会坍缩的和，就像 (10.90) 里两次迭代之后那样。所有迭代完成后，\(x_k\) 处的值被更新为7

$$\begin{aligned}\hat{G}_\pi(x_k) &:= \hat{G}_\pi(x_k) + \frac{1}{v_k}\big(d_k + d_{k+1} + \cdots + d_K\big) \\ &= \hat{G}_\pi(x_k) + \frac{1}{v_k}\Big(l(x_k,u_k) + l(x_{k+1},u_{k+1}) + \cdots + l(x_K,u_K) - \hat{G}_\pi(x_k) + \hat{G}_\pi(x_F)\Big) \\ &= \hat{G}_\pi(x_k) + \frac{1}{v_k}\Big(l(x_k,u_k) + l(x_{k+1},u_{k+1}) + \cdots + l(x_K,u_K) - \hat{G}_\pi(x_k)\Big).\end{aligned} \tag{10.92}$$

最后的 \(\hat{G}_\pi(x_F)\) 被删掉了，因为假设计划在 \(x_F\) 施加终止动作，它的值为零。若序列中每个被访问的状态都互不相同，最后的表达式就等价于 (10.85)。通常并非如此，这使上面的方法与 (10.85) 略有不同，因为在时间差分方案中，计数 \(v_k\) 可能在试验过程中变化。不过这个差别可以忽略，时间差分方法算出的估计会收敛到 \(G_\pi\)。

上面的时间差分方法可以推广，实践中常常收敛得更快。令 \(\lambda\in[0,1]\) 为给定参数，TD(λ) 时间差分方法把 (10.91) 换成

$$\begin{aligned}\hat{G}_\pi(x_1) &:= \hat{G}_\pi(x_1) + \lambda^{k-1}\Big(\frac{1}{v_1}d_k\Big), \\ \hat{G}_\pi(x_2) &:= \hat{G}_\pi(x_2) + \lambda^{k-2}\Big(\frac{1}{v_2}d_k\Big), \\ &\ \ \vdots \\ \hat{G}_\pi(x_{k-1}) &:= \hat{G}_\pi(x_{k-1}) + \lambda\Big(\frac{1}{v_{k-1}}d_k\Big), \\ \hat{G}_\pi(x_k) &:= \hat{G}_\pi(x_k) + \frac{1}{v_k}d_k.\end{aligned} \tag{10.93}$$

它的效果是对离 \(x_k\) 很远处收到的代价打折扣。(10.91) 的方法是 \(\lambda = 1\) 的特例，即 TD(1)。另一个有趣的特例是 TD(0)：

$$\hat{G}_\pi(x_k) = \hat{G}_\pi(x_k) + \frac{1}{v_k}\Big(l(x_k,u_k) + \hat{G}_\pi(x_{k+1}) - \hat{G}_\pi(x_k)\Big). \tag{10.94}$$

这种形式在强化学习文献里最常见（尽管那里多用于折扣代价模型）。实验证据表明较小的 \(\lambda\) 有助于提高收敛速度；对所有 \(\lambda\) 的收敛性在 [13] 中得到证明。

(10.94) 为何奏效的一个直觉来源：它是随机迭代算法 stochastic iterative algorithm（或 Robbins–Monro 算法）的特例。这是一种一般的统计估计技术，用一串样本求解形如 \(h(y) = y\) 的方程组：每个样本代表用蒙特卡罗模拟对 \(h(y)\) 的一次测量。这种迭代方法的一般形式是把 \(y\) 更新为

$$y := (1-\rho)y + \rho h(y), \tag{10.95}$$

其中 \(\rho\in[0,1]\) 是参数，它的选择影响收敛速度。直观上 (10.95) 是在原值与最新的 \(h(y)\) 样本之间插值。这里不给出收敛性证明（见 [13]）。典型的行为是：模拟过程噪声大时，\(\rho\) 越小估计越可靠，代价是收敛变慢。收敛是渐近的，要求基于计划的状态转移图中所有（概率非零的）边都被无穷多次访问。在随机迭代框架下推广 TD(0)，可以得到求 \(\hat{G}_\pi\) 的一般方法：

$$\hat{G}_\pi(x) := (1-\rho)\hat{G}_\pi(x) + \rho\Big(l(x,u) + \hat{G}_\pi(x')\Big). \tag{10.96}$$

(10.94) 那样的 TD(0) 本质上由推导过程选定了 \(\rho\)（\(\rho = 1/v_k\)），而在 (10.96) 中可以用任何 \(\rho\in(0,1)\)。更新式不考虑转移概率，这看起来也许不对；其实它们在模拟过程中已经被考虑进去了：更可能发生的转移对 (10.96) 的影响更大。用分布的样本估计一个非均匀概率密度的均值时也是如此：出现频率高的值对平均的贡献大，自动获得了合适的权重。

10.4.3 Q-learning：计算最优计划 Q-Learning: Computing an Optimal Plan

这一节从「评估一个计划」转到「在基于模拟的框架里计算最优计划」。最重要的想法是计算 Q 因子 Q-factors \(Q^*(x,u)\)：它是最优代价到目标 \(G^*\) 的推广，记录了每个状态 \(x\in X\) 与动作 \(u\in U(x)\) 组合的最优代价。\(Q^*(x,u)\) 的含义是：从 \(x\) 出发、施加 \(u\)、然后从得到的下一状态 \(x' = f(x,u,\theta)\) 起按最优计划行动所得的期望代价。若 \(u\) 恰好是最优计划会选的动作 \(\pi^*(x)\)，则 \(Q^*(x,u) = G^*(x)\)。所以 Q 值可以看成「第一阶段任意选一个动作、之后都最优决策」的代价。

值迭代

基于模拟的值迭代可以从 Q 因子构造出来。用它们而不用 \(G^*\) 的原因是：动态规划中可以避免对 \(U(x)\) 的最小化，从而能逐样本地估计最优值并最终得到最优计划。最优代价到目标可以由 Q 因子得到：

$$G^*(x) = \min_{u\in U(x)}\Big\{Q^*(x,u)\Big\}. \tag{10.97}$$

这使 (10.46) 的动态规划递推可以写成

$$Q^*(x,u) = l(x,u) + \sum_{x'\in X} P(x'\mid x,u)\min_{u'\in U(x')}\Big\{Q^*(x',u')\Big\}. \tag{10.98}$$

把 (10.97) 用到 (10.98) 的右边，也可以用 \(G^*\) 表示：

$$Q^*(x,u) = l(x,u) + \sum_{x'\in X} P(x'\mid x,u)G^*(x'). \tag{10.99}$$

若 \(P(x'\mid x,u)\) 和 \(l(x,u)\) 已知，(10.98) 就是另一种更占存储的值迭代。收敛后用 (10.97) 得到 \(G^*\) 的值，最优计划是

$$\pi^*(x) = \operatorname*{argmin}_{u\in U(x)}\Big\{Q^*(x,u)\Big\}. \tag{10.100}$$

由于代价和转移概率未知，需要基于模拟的方法。再次用随机迭代算法的想法：回忆 (10.96) 用单个样本和收敛速度参数 \(\rho\) 估计计划的代价；同样的想法可以导出基于模拟的值迭代：

$$\hat{Q}^*(x,u) := (1-\rho)\hat{Q}^*(x,u) + \rho\Big(l(x,u) + \min_{u'\in U(x')}\Big\{\hat{Q}^*(x',u')\Big\}\Big), \tag{10.101}$$

其中 \(x'\) 是下一状态，\(l(x,u)\) 是在 \(x\) 施加 \(u\) 时从模拟器得到的代价。初始时所有 Q 因子设为零。用模拟生成到达目标的样本轨迹，对每个阶段得到的状态和代价应用 (10.101)。同样，更新式没有显式提到转移概率，看起来也许不对，但它们已经通过模拟自动考虑进去了。大多数文献把 Q-learning 用于折扣代价模型，得到 (10.101) 的一个小变体：

$$\hat{Q}^*(x,u) := (1-\rho)\hat{Q}^*(x,u) + \rho\Big(l(x,u) + \alpha\min_{u'\in U(x')}\Big\{\hat{Q}^*(x',u')\Big\}\Big), \tag{10.102}$$

折扣因子 \(\alpha\) 出现是因为这个更新式由 (10.76) 推出。

策略迭代

也可以用 Q 因子推导出基于模拟的策略迭代。回忆 10.2.2 节需要的两种方法：1）评估给定计划 \(\pi\)；2）选择更好的动作来改进计划。以前的计划评估要解线性方程组；现在任何计划 \(\pi\) 都可以用 10.4.2 节的方法评估，根本不需要知道 \(P(x'\mid x,u)\)。一旦从每个 \(x\in X\) 都可靠地算出 \(\hat{G}_\pi\)，就可以继续模拟，对每个 \(x\in X\)、\(u\in U\) 计算 \(Q_\pi(x,u)\)——定义 (10.99) 受限于 \(\pi\) 的版本：

$$Q_\pi(x,u) = l(x,u) + \sum_{x'\in X} P(x'\mid x,u)G_\pi(x'). \tag{10.103}$$

转移概率无需已知，Q 因子通过模拟和平均算出。计划可以这样改进：

$$\pi'(x) = \operatorname*{argmin}_{u\in U(x)}\Big\{Q_\pi(x,u)\Big\}, \tag{10.104}$$

它基于 (10.97)8。

10.5 序贯博弈论 Sequential Game Theory

到目前为止，本章的序贯决策过程只涉及与自然的博弈。这一节引入其它决策者，把 9.3、9.4 节的单阶段博弈及其均衡概念推广到一系列博弈上。10.5.1 节介绍用博弈树表示的序贯零和博弈，它有助于直观理解；10.5.2 节用状态空间表示讨论序贯零和博弈；10.5.3 节简要介绍其它博弈的推广，包括非零和博弈和有自然参与的博弈。本节的表述称为序贯博弈论 sequential game theory，另一个常见名字是动态博弈论 dynamic game theory。如果阶段是连续的（13.5 节简要讨论），就得到微分博弈论 differential game theory。

10.5.1 博弈树 Game Trees

多数文献用博弈树 game tree 表述序贯博弈；与本章表示方式更一致的状态空间表示在 10.5.2 节介绍。树表示通常称为博弈的扩展形式 extensive form（与之相对的标准形式 normal form 是第 9 章用的代价矩阵）。树表示有助于直观理解博弈论中的许多问题，也许最有助于直观理解信息状态；博弈树的这方面推迟到 11.7 节正式引入信息空间之后。这里只讲描述起来简单、不必深入信息空间的情形。

在介绍序贯博弈之前，先考虑用树表示单阶段博弈。回忆例 9.14：一个 \(3\times3\) 的零和矩阵博弈。它可以表示成图 10.12 那样的博弈树（下面互动图的「图 10.12」预设）：根部 P₁ 有三个选择；下一层 P₂ 也有三个选择；双方的选择决定了九个叶子中的一个，到达叶子时得到写在它下面的代价。代价矩阵 (9.53) 的元素横排在叶子上。每个非叶顶点称为决策顶点 decision vertex：某个玩家必须在那里选一个动作。图 10.12 的博弈有两种可能的解释：

  1. P₂ 在做决定之前知道 P₁ 施加了哪个动作。这不对应 9.3 节的零和博弈表述，因为 P₂ 看起来和自然一样强大；这时它与例 9.14 的博弈不等价。
  2. P₂ 不知道 P₁ 的动作。这等价于假设 P₁ 和 P₂ 同时决策，与 Formulation 9.7 一致；这棵树也可以画成 P₂ 先行。

现在设想 P₁ 和 P₂ 进行一系列博弈：把博弈树推广到更多层，就定义了 9.3 节零和博弈的序贯版本，即下面的序贯博弈 sequential game：

Formulation 10.3（树形式的零和序贯博弈 Zero-Sum Sequential Game in Tree Form）
  1. 两个玩家 P₁、P₂ 轮流进行一个博弈。以前的一个阶段现在被拉伸成两个子阶段 substages，每个玩家各自行动。通常假设总是 P₁ 先行，然后 P₂，再 P₁，如此交替直到博弈结束。这个模型反映了国际象棋、扑克等许多流行游戏的规则。令 \(\mathcal{K} = \{1,\ldots,K\}\) 为 P₁ 和 P₂ 都行动一次的阶段集合。
  2. 每个玩家行动时，从一个非空有限的动作集合中选择；可用的集合可以依赖于决策顶点。
  3. 博弈结束时，根据双方所选的动作序列为 P₁ 产生一个代价；这个代价被解释为 P₂ 的回报。
  4. 必须规定每个玩家做决策时拥有的信息量。这通常通过说明动作历史中哪些部分已知来表达。例如 P₁ 刚行动完，P₂ 知道它的选择吗？它知道 P₁ 在之前某个阶段选了什么吗？

图 10.13 是两个阶段（\(K = 2\)，\(\mathcal{K} = \{1,2\}\)）的一个具体例子。每个顶点对应一个玩家需要决策的时刻，从顶点发出的每条边代表一个动作。根是博弈的开始，通常意味着 P₁ 选一个动作；叶子是博弈的结束，即得到代价的时刻，代价通常写在叶子下面。最后要规定每个玩家在决策前可用的信息：自己或其他玩家之前施加的动作中哪些是已知的？图 10.13 有两个玩家、两个阶段，因此有四层决策顶点。玩家的动作集合是 \(U = V = \{L,R\}\)（左、右）。因为总是两个动作，所以是二叉树。有 16 种可能的结果，对应每个玩家四种可能的两阶段计划的所有两两组合。

对单阶段博弈，为了得到鞍点，定义了确定性和随机化两种策略；9.3.3 节说过，要保证鞍点存在需要随机化策略。对序贯博弈，它们分别推广为确定性计划和随机化计划。10.1.3 节把（确定性）计划定义为从状态空间到动作空间的映射，这个定义可以用于每个玩家；但必须先确定博弈树的「状态」是什么——这取决于每个玩家行动时可用的信息。表示博弈树中信息的一般框架在 11.7 节讲；这里讨论三种简单的信息模型。在每种情形下，每个玩家都知道自己在之前阶段施加的动作，区别在于对其他玩家所施加动作的了解，它们定义了计划中用于决策的「状态」：

  • 交替行动 alternating play：玩家轮流行动，所有玩家都知道之前施加的全部动作——这是下棋时的情形。定义计划时，令 \(N_1\)、\(N_2\) 分别为 P₁、P₂ 必须做决策的所有顶点（图 10.13 中 \(N_1\) 是深色顶点，\(N_2\) 是白色顶点）。令 \(U(n_1)\)、\(V(n_2)\) 为 P₁、P₂ 的动作空间，它们依赖于顶点。P₁ 的（确定性）计划是定义在 \(N_1\) 上的函数 \(\pi_1\)，对每个 \(n_1\in N_1\) 给出动作 \(u\in U(n_1)\)；P₂ 的确定性计划是 \(N_2\) 上的函数 \(\pi_2\)，对每个 \(n_2\in N_2\) 给出 \(v\in V(n_2)\)。随机化情形下，令 \(W(n_1)\)、\(Z(n_2)\) 分别为 \(U(n_1)\)、\(V(n_2)\) 上所有概率分布的集合；P₁ 的随机化计划对每个 \(n_1\in N_1\) 给出某个 \(w\in W(n_1)\)，P₂ 的随机化计划把 \(N_2\) 映射到 \(Z(n_2)\)。
  • 逐阶段 stage-by-stage：每个玩家知道对方在之前所有阶段施加的动作，但不知道对方在当前阶段选了什么。这实际上意味着每个阶段双方同时行动。这时 P₁ 的确定性或随机化计划的定义同交替行动；但 P₂ 的计划要定义在 \(N_1\) 而不是 \(N_2\) 上，因为它做决定时所拥有的信息与 P₁ 完全相同；P₂ 的动作空间也必须相应地依赖于 \(N_1\) 的元素，否则 P₂ 不知道有哪些动作可用，因此定义为 \(V(n_1)\)。下文称它为「阶段式」。
  • 开环 open loop：每个玩家都不知道对方之前的动作，只知道到目前为止施加了几个动作，即博弈进行到第几阶段。计划定义为 \(\mathcal{K}\) 上的函数，因为不知道具体在哪个顶点。注意确定性情形下开环计划就是一串动作（像 2.3 节那样），随机化情形下是一串概率分布；动作空间同样必须与信息相符，即 \(U(k)\) 和 \(V(k)\)，\(k\in\mathcal{K}\)。

对图 10.12 那样的单阶段博弈，阶段式和开环两种模型是等价的。

确定安全计划

9.3.2 节的安全策略可以自然地推广到序贯博弈，得到安全计划 security plan：每个玩家把对方当作非确定不确定性下的自然，做最坏情况分析。安全计划及其代价可以通过把代价从叶子向上传播到根来计算。图 10.13 中 P₁ 安全计划的计算见图 10.14：先确定 P₂ 在倒数第二层所有顶点会选的动作；由于 P₂ 想让代价最大，这些顶点上记录的代价是其孩子代价的最大值。再上一层确定 P₁ 会选的动作，每个顶点记录其孩子中的最小代价。再上一层考虑 P₂，如此直到根。此时 P₁ 能保证的最低代价就知道了，这就是序贯博弈的上值 upper value \(\overline{L}^*\)。安全计划由「对每个 \(n_1\in N_1\) 选出代价最低的孩子顶点的动作」定义。如果 P₂ 对 P₁ 的安全计划做理性的回应，就会走图 10.14d 中粗线所示的路径：P₁ 的安全计划执行出的动作序列是 P₁ 的 \((L,L)\)、P₂ 的 \((R,L)\)，上值 \(\overline{L}^* = 1\)。

P₂ 的安全计划可以类似地计算，但必须交换决策的次序。除非在树中把玩家的次序交换，否则这不容易看出来。如果 P₂ 先行，得到图 10.15 那样的树：叶子上的代价顺序不同，但对 P₁、P₂ 选择的同一动作序列，博弈结束时得到的代价与图 10.14 相同。博弈的下值 lower value 为 \(\underline{L}^* = 1\)。安全计划由「对每个 \(n_2\in N_2\) 选择使其孩子代价最大的动作」定义。如果 P₁ 对 P₂ 的安全计划理性回应，执行的动作是 P₁ 的 \((L,L)\)、P₂ 的 \((R,L)\)——与执行 P₁ 安全计划时得到的相同，尽管由于玩家次序交换，它们在两棵树里看起来不同。不过在许多情况下会得到不同的动作序列。

和单阶段博弈一样，\(\underline{L}^* = \overline{L}^*\) 意味着博弈有确定性鞍点，序贯博弈的值 value 为 \(L^* = \underline{L}^* = \overline{L}^*\)。这个博弈有唯一的确定性鞍点，即使双方各自做最坏情况分析，也会得到可预测的、相同的选择。

如果认识到树的某些部分不必探索（因为它们不可能带来更好的代价），计算安全策略的代价可以大幅降低。这个想法在 AI 文献中称为 alpha-beta 剪枝 alpha-beta pruning（参考文献与简史见 [40]，第 186–187 页）。假设为了确定 P₁ 的安全策略而按深度优先顺序搜索树。在 P₁ 的某个决策顶点，假设已确定施加动作 \(u\) 能保证代价 \(c\)，但还有其它动作的可保证代价未知。考虑为其中一个剩余动作 \(u'\) 确定可保证的代价：这需要计算 P₂ 会怎样最大化代价来回应 \(u'\)。一旦 P₂ 至少有一个选项的代价 \(c'\) 大于 \(c\)，P₂ 的其它孩子就不必探索了。为什么？因为如果 P₂ 能以导致比 P₁ 通过选 \(u\) 已能保证的代价更高的方式回应，P₁ 就绝不会选 \(u'\)。图 10.16 给出了一个简单的例子。这种情况可以发生在树的任何一层；一个动作不必考虑时，整棵子树都被剪掉。在其它情形下也可以剪掉 P₁ 的孩子，因为 P₂ 不会做出让 P₁ 把代价降到 P₂ 已能为自己保证的值以下的选择。

计算鞍点

P₁ 的安全计划是交替行动模型下博弈的合法解：P₂ 只需在每个阶段对 P₁ 的计划选最优回应即可。在阶段式模型下，「解」的概念是鞍点，它在上值和下值相等时出现。上面的过程可以用来确定值和相应的计划；但如果值不相等呢？这时应为玩家设计随机化安全计划。和单阶段博弈一样，得到随机化上值 \(\overline{\mathcal{L}}^*\) 和随机化下值 \(\underline{\mathcal{L}}^*\)。在随机化计划的空间里，鞍点总是存在，这意味着博弈总有随机化值 \(\mathcal{L}^* = \underline{\mathcal{L}}^* = \overline{\mathcal{L}}^*\)。这个鞍点可以用与刚才计算安全计划类似的方式自底向上地算出。

回到图 10.13 的例子。如前所述，这个博弈实际上有确定性鞍点，但它仍可以很好地演示方法，因为任何确定性计划都可以看成随机化计划的特例（全部概率质量放在一个动作上）。考虑图 10.13 最下面只用最后两层决策顶点得到的四棵子树：每种情况下 P₁ 和 P₂ 都要同时行动来结束序贯博弈，每棵子树都可以看成一个矩阵博弈，因为两人行动后立即得到代价。这引出了描绘图 10.13 博弈的另一种方式（图 10.17）：最下面两层决策顶点被矩阵博弈取代。现在为每个矩阵博弈计算随机化值，放在相应的叶子顶点处（图 10.18）。例子中只剩两层决策顶点，可以表示为博弈

$$\begin{array}{c|cc} & V & \\ \hline U & 0 & 1 \\ & 2 & 3 \end{array} \tag{10.105}$$

它的值是 1，出现在 P₁ 施加 \(L\)、P₂ 施加 \(R\) 时。于是原序贯博弈的解通过求解矩阵博弈得到，作为求安全计划方法的替代。新方法的好处是：如果某个矩阵没有确定性鞍点，可以改为计算它的随机化值；如果执行时到达相应的决策顶点，玩家必须采用随机化策略。

把树转换成单阶段博弈

到目前为止，已经为交替行动和阶段式模型确定了解；剩下开环模型。这时玩家之间直到博弈结束、得到代价之前都没有信息交换。因此可以设想，进行这样一个序贯博弈的玩家，等价地在进行一个大的单阶段博弈。回忆开环模型下的计划是 \(\mathcal{K}\) 上的函数。令 \(\Pi_1\)、\(\Pi_2\) 分别为 P₁、P₂ 可能的计划集合。对图 10.13 的博弈，\(\Pi_i\) 是每个玩家的四个计划，按以下顺序指定：\((L,L)\)、\((L,R)\)、\((R,L)\)、\((R,R)\)。它们可以排成一个 \(4\times4\) 的矩阵博弈：

$$\begin{array}{c|cccc} & & \Pi_2 & & \\ \hline \Pi_1 & 4 & 2 & 1 & 0 \\ & 0 & 0 & 3 & 2 \\ & 2 & 3 & 4 & 1 \\ & 1 & 2 & 3 & 2 \end{array} \tag{10.106}$$

这个矩阵博弈没有确定性鞍点。遗憾的是，必须解一个四维线性规划问题才能求出随机化值和均衡。这与另两种信息模型得到的解有很大不同。矩阵博弈形式也可以为阶段式模型推导出来，但计划的空间更大：图 10.13 的例子中，每个玩家有 5 个决策顶点，在每个顶点可以施加两种不同的动作，因此 \(i = 1\) 和 \(i = 2\) 时都有 \(|\Pi_i| = 2^5 = 32\)，这是一个 \(32\times32\) 的矩阵博弈！它应该有我们已经得到的同一个鞍点解。树表示的优点是把这个庞大的博弈分解成了许多很小的矩阵博弈；逐阶段地处理问题，计算上得到了巨大的节省。这种威力源于在基于树的计算方法中隐式地使用了动态规划原理——把序贯博弈分解成小的矩阵博弈。与以前动态规划方法的联系在下一节会更清楚，它考虑定义在状态空间上的序贯博弈。

10.5.2 状态空间上的序贯博弈 Sequential Games on State Spaces

上一节一个明显的问题是顶点数随阶段数指数增长。不过在一些博弈中，可能有多个动作序列导致同一个状态——国际象棋、跳棋、井字棋等许多流行游戏都是这样。这时方便的做法是定义一个刻画所有不同博弈局面的状态空间，玩家的动作改变状态；如果不同的动作序列导致同一个状态，就不需要不同的顶点。通过声明表示同一状态的顶点等价，博弈树就变成了博弈图 game graph。博弈图在许多方面类似于 10.1 节讨论的、与自然的序贯博弈中的转移图；有对立玩家时也可以用同样的想法。

我们将把博弈树收缩成博弈图，得到一个在状态空间上进行的序贯博弈；还允许更一般的情形——代价出现在任何转移边上，而不只是原博弈树的叶子上。这里只推广博弈树中的阶段式模型，其它信息模型的推广在 11.7 节。下面的表述中，P₂ 可以看作 Formulation 10.1 里自然的替代者；新表述仍是 Formulation 9.7（单阶段零和博弈）的推广。为了概念简单，所有空间都假设有限。

Formulation 10.4（状态空间上的零和序贯博弈 Sequential Zero-Sum Game on a State Space）
  1. 两个玩家 P₁ 和 P₂。
  2. 有限非空的状态空间 \(X\)。
  3. 对每个 \(x\in X\)，P₁ 有限非空的动作空间 \(U(x)\)。
  4. 对每个 \(x\in X\)，P₂ 有限非空的动作空间 \(V(x)\)。为了推广 10.5.1 节的交替行动模型，也可以定义 \(V(x,u)\)，让 P₂ 可用的动作集依赖于 P₁ 的动作 \(u\in U\)。
  5. 状态转移函数 \(f\)：对每个 \(x\in X\)、\(u\in U(x)\)、\(v\in V(x)\) 给出 \(f(x,u,v)\)。
  6. \(K\) 个阶段的集合 \(\mathcal{K}\)，每个记为 \(k\)，从 \(k = 1\) 开始到 \(k = K\) 结束；令 \(F = K+1\)，它是最后一个动作施加之后的最终阶段。
  7. 初始状态 \(x_I\in X\)。有些问题不指定它，这时要对所有初始状态求解。
  8. 阶段可加的代价泛函 \(L\)。令 \(\tilde{v}_K\) 为到阶段 \(K\) 为止 P₂ 的动作历史，代价泛函可以作用于状态和动作历史的任何组合：
    $$L(\tilde{x}_F,\tilde{u}_K,\tilde{v}_K) = \sum_{k=1}^{K} l(x_k,u_k,v_k) + l_F(x_F). \tag{10.107}$$

假设两个玩家总是知道当前状态。注意表述中没有终止动作：每个玩家行动 \(K\) 次之后博弈结束；也没有直接的目标集表述。终止动作和目标集都可以毫无困难地加进来，但这里不考虑。动作集也可以很容易地推广为依赖阶段的 \(U(x,k)\) 和 \(V(x,k)\)；本节的方法都能顺利改造，为了记号简单这里不这么做。

为每个玩家定义计划

现在每个玩家都要有自己的计划。和 10.1 节一样，计划最好定义为从状态到动作的映射，因为不一定清楚另一个决策者会采取什么动作。10.1 节的另一个决策者是自然，这里是理性的对手。令 \(\pi_1\)、\(\pi_2\) 分别为 P₁、P₂ 的计划。由于 Formulation 10.4 中阶段数固定，形如 \(\pi_1 : X\times\mathcal{K}\to U\) 和 \(\pi_2 : X\times\mathcal{K}\to V\) 的依赖阶段的计划是合适的（回忆 10.1.3 节）。每个计划都给出一个动作 \(\pi_1(x,k)\in U(x)\) 和 \(\pi_2(x,k)\in V(x)\)。

再看 Formulation 10.4 的不同解概念。对 P₁，确定性计划是函数 \(\pi_1 : X\times\mathcal{K}\to U\)，对每个状态 \(x\in X\) 和阶段 \(k\in\mathcal{K}\) 给出动作 \(u = \pi(x)\in U(x)\)；对 P₂ 则是 \(\pi_2 : X\times\mathcal{K}\to V\)，给出 \(v = \pi(x)\in V(x)\)。再定义随机化计划：令 \(W(x)\)、\(Z(x)\) 分别为 \(U(x)\)、\(V(x)\) 上所有概率分布的集合。P₁ 的随机化计划对每个 \(x\in X\)、\(k\in\mathcal{K}\) 给出某个 \(w\in W(x)\)；同样 P₂ 的随机化计划对每个 \(x\in X\)、\(k\in\mathcal{K}\) 给出某个 \(z\in Z(x)\)。

序贯博弈中的鞍点

再次为每个玩家定义安全策略来得到鞍点。每个玩家把对方当作自然；如果得到同样的最坏情况值，结果就是博弈的鞍点；若值不同，就需要随机化计划来弥合上值与下值之间的差距。上值和下值现在依赖于初始状态 \(x_1\in X\)——10.5.1 节没有这样的东西，因为博弈树的根是唯一可能的起点。若从 \(x_1\) 施加动作序列 \(\tilde{u}_K\) 和 \(\tilde{v}_K\)，反复用状态转移函数 \(f\) 就能推出状态历史 \(\tilde{x}_F\)。从 \(x_1\) 出发的上值定义为

$$\overline{L}^*(x_1) = \min_{u_1}\max_{v_1}\min_{u_2}\max_{v_2}\cdots\min_{u_K}\max_{v_K}\Big\{L(\tilde{x}_F,\tilde{u}_K,\tilde{v}_K)\Big\}, \tag{10.108}$$

若把 P₂ 换成自然，它与 (10.33) 相同；(10.108) 也把 (9.44) 推广到多阶段。从 \(x_1\) 出发的下值推广了 (9.46)：

$$\underline{L}^*(x_1) = \max_{v_1}\min_{u_1}\max_{v_2}\min_{u_2}\cdots\max_{v_K}\min_{u_K}\Big\{L(\tilde{x}_F,\tilde{u}_K,\tilde{v}_K)\Big\}. \tag{10.109}$$

若 \(\overline{L}^*(x_1) = \underline{L}^*(x_1)\)9，则从 \(x_1\) 出发存在确定性鞍点。这意味着在每个阶段内部 max 和 min 的次序都可以交换。

值迭代

把用于 (10.33) 的推导改用于 (10.108)，就得到值迭代方法，即动态规划递推

$$\overline{L}^*_k(x_k) = \min_{u_k\in U(x_k)}\Big\{\max_{v_k\in V(x_k)}\Big\{l(x_k,u_k,v_k) + \overline{L}^*_{k+1}(x_{k+1})\Big\}\Big\}, \tag{10.110}$$

它类似于 (10.39)，可以用来迭代地计算 P₁ 的安全计划。P₂ 的安全计划可以用

$$\underline{L}^*_k(x_k) = \max_{v_k\in V(x_k)}\Big\{\min_{u_k\in U(x_k)}\Big\{l(x_k,u_k,v_k) + \underline{L}^*_{k+1}(x_{k+1})\Big\}\Big\} \tag{10.111}$$

计算，这是由 (10.109) 推出的动态规划方程。从最终阶段 \(F\) 开始，上值和下值直接由代价函数确定：

$$\overline{L}^*_F(x_F) = \underline{L}^*_F(x_F) = l_F(x_F). \tag{10.112}$$

现在计算 \(\overline{L}^*_K\) 和 \(\underline{L}^*_K\)：从每个状态 \(x_K\) 计算 (10.110) 和 (10.111)，判断是否 \(\overline{L}^*_K(x_K) = \underline{L}^*_K(x_K)\)。若是，则 \(L^*_K(x_K) = \overline{L}^*_K(x_K) = \underline{L}^*_K(x_K)\) 就是阶段 \(K\) 从 \(x_K\) 出发的博弈的值。若发现某个 \(x_K\in X\) 的上值和下值不相等，从 \(x_K\) 出发就没有确定性鞍点；而且这还会妨碍更早阶段从其它状态出发的确定性鞍点存在——它们会在后面的值迭代中遇到。允许随机化计划可以避免这些问题，但优化会复杂一些，因为要反复求解线性规划。

暂且假设对所有 \(x_K\in X\) 都有 \(\overline{L}^*_K(x_K) = \underline{L}^*_K(x_K)\)。值迭代照常从 \(k = K\) 进行到 \(k = 1\)。再假设每个阶段对所有 \(x_k\in X\) 都有 \(\overline{L}^*_k(x_k) = \underline{L}^*_k(x_k)\)；注意 (10.110) 和 (10.111) 中可以用 \(L^*_{k+1}\) 代替 \(\overline{L}^*_{k+1}\) 和 \(\underline{L}^*_{k+1}\)，因为假设上值和下值重合。若不重合，方法就失效，需要随机化计划来得到随机化鞍点。从每个 \(x_1\in X\) 算出结果后，P₁ 的安全计划 \(\pi_1^*\) 定义为：对每个 \(k\in\mathcal{K}\) 和 \(x_k\in X\)，取满足 (10.110) 中最小值的任意动作 \(u\)；P₂ 的安全计划 \(\pi_2^*\) 类似地取满足 (10.111) 中最大值的任意动作 \(v\)。

现在假设从一个或多个初始状态出发不存在确定性鞍点。为避免遗憾，必须设计随机化安全计划。它们直接推广自 9.3.3 节的随机化安全策略。用向量 \(w\)、\(z\) 表示 \(U(x)\)、\(V(x)\) 上的概率分布，概率向量分别从对应于 \(U(x)\)、\(V(x)\) 上所有概率分布的集合 \(W(x)\)、\(Z(x)\) 中选取。为了记号方便，设 \(U(x) = \{1,\ldots,m(x)\}\)、\(V(x) = \{1,\ldots,n(x)\}\)，\(m(x)\)、\(n(x)\) 是正整数。回忆定义单阶段博弈随机化上值和下值的 (9.61)、(9.62)，这里推广为序贯博弈的随机化上值和下值。它们的定义类似于 (10.108) 和 (10.109)，只是：1）交替的 min 和 max 取遍动作空间上的概率分布；2）使用期望代价。动态规划原理可以用于随机化上值，得到

$$\overline{\mathcal{L}}^*_k(x_k) = \min_{w\in W(x_k)}\Big\{\max_{z\in Z(x_k)}\Big\{\sum_{i=1}^{m(x_k)}\sum_{j=1}^{n(x_k)}\Big(l(x_k,i,j) + \overline{\mathcal{L}}^*_{k+1}(x_{k+1})\Big)w_i z_j\Big\}\Big\}, \tag{10.113}$$

其中 \(x_{k+1} = f(x_k,i,j)\)。随机化下值类似地为

$$\underline{\mathcal{L}}^*_k(x_k) = \max_{z\in Z(x_k)}\Big\{\min_{w\in W(x_k)}\Big\{\sum_{i=1}^{m(x_k)}\sum_{j=1}^{n(x_k)}\Big(l(x_k,i,j) + \underline{\mathcal{L}}^*_{k+1}(x_{k+1})\Big)w_i z_j\Big\}\Big\}. \tag{10.114}$$

在许多博弈中，代价项可能只依赖于状态：对所有 \(x\)、\(u\)、\(v\)，\(l(x,u,v) = l(x)\)。这时 (10.113) 和 (10.114) 化简为

$$\overline{\mathcal{L}}^*_k(x_k) = \min_{w\in W(x_k)}\Big\{\max_{z\in Z(x_k)}\Big\{l(x_k) + \sum_{i=1}^{m(x_k)}\sum_{j=1}^{n(x_k)}\overline{\mathcal{L}}^*_{k+1}(x_{k+1})w_i z_j\Big\}\Big\} \tag{10.115}$$
$$\underline{\mathcal{L}}^*_k(x_k) = \max_{z\in Z(x_k)}\Big\{\min_{w\in W(x_k)}\Big\{l(x_k) + \sum_{i=1}^{m(x_k)}\sum_{j=1}^{n(x_k)}\underline{\mathcal{L}}^*_{k+1}(x_{k+1})w_i z_j\Big\}\Big\}, \tag{10.116}$$

这与 (10.46) 中的化简类似（那里假设 \(\theta_k\) 不出现在代价项里）。这些求和本质上是把 (9.57) 推广到多阶段；如果需要，甚至可以像 9.3.3 节那样写成矩阵乘法。在上面的方程上做值迭代就能得到序贯博弈的随机化值。由于上值和下值总是相同，不需要检查两者是否不一致。实践中最好在每次计算 (10.113) 和 (10.114)（或它们的简化形式）时先检查从 \(x_k\) 出发是否存在确定性鞍点；不存在时，必须求解 9.3.3 节表述的线性规划问题来确定每个玩家的值和最佳随机化计划。若从当前状态和阶段出发存在确定性鞍点，就可以避免求解线性规划。

10.5.3 其它序贯博弈

到目前为止 10.5 节的大多数想法都能自然地推广到其它序贯博弈问题。本小节简要提及其中一些可能的推广。

序贯博弈中的 Nash 均衡

Formulation 10.3 和 10.4 可以推广到序贯非零和博弈。对博弈树，在每个叶子上写一个代价向量 cost vector，每个玩家一个分量。在阶段式模型下，可以用 10.5.1 节介绍的自底向上技术计算确定性和随机化的 Nash 均衡，得到的是一个 Nash 均衡。要表示所有 Nash 均衡就困难得多：照例把博弈树分解成许多矩阵博弈，但每种情况下都必须找出所有 Nash 均衡并记录它们对应的代价；不再是沿树向上传播单个代价，而是要传播一个代价向量集合（连同每个代价向量相关的动作）直到根。和单阶段博弈一样，可以排除不可容许的 Nash 均衡，因此在计算中遇到的每个矩阵博弈里，只有可容许的 Nash 均衡及其代价需要向上传播。

Formulation 10.4 可以通过为 P₁、P₂ 分别引入代价函数 \(L_1\)、\(L_2\) 来推广。值迭代方法可以像博弈树方法那样推广：对每个状态和阶段的组合，都要维护多个值向量及其对应的动作，它们对应可容许的 Nash 均衡。Nash 均衡的不唯一性是序贯博弈中最大的困难——序贯博弈中通常比单阶段博弈多得多的均衡。因此这个概念在设计规划方法时不太有用；它可能更适合例如对复杂经济系统可能结果的建模。关于这个主题的详尽论述见 [4]。

自然这个玩家可以很容易地引入博弈。例如把自然引入零和博弈，就有三个玩家：P₁、P₂ 和自然。图 10.19 是一个有自然参与的单阶段零和博弈的博弈树：假设三个玩家同时行动，符合阶段式模型；也可能有许多其它信息模型。假设用概率不确定性对自然建模，已知自然以概率 1/3 选左支、以概率 2/3 选右支。根据自然选的分支，P₁ 和 P₂ 似乎要玩一个特定的 \(2\times2\) 矩阵博弈。以概率 1/3，代价矩阵是

$$\begin{array}{c|cc} & V & \\ \hline U & 3 & -2 \\ & -6 & 3 \end{array} \tag{10.117}$$

以概率 2/3 是

$$\begin{array}{c|cc} & V & \\ \hline U & 3 & -1 \\ & 6 & 0 \end{array} \tag{10.118}$$

遗憾的是，P₁ 和 P₂ 不知道自己实际在玩哪个矩阵博弈。如果博弈在许多独立试验中进行，遗憾可以在期望意义下消除。令 \(A_1\)、\(A_2\) 分别表示 (10.117) 和 (10.118)，定义新的代价矩阵 \(A = (1/3)A_1 + (2/3)A_2\)（标量乘矩阵即每个元素乘以它）。得到的矩阵是10

$$\begin{array}{c|cc} & V & \\ \hline U & 3 & -4/3 \\ & 2 & 1 \end{array} \tag{10.119}$$

这个矩阵博弈有确定性鞍点：P₁ 选 \(R\)（第 2 行）、P₂ 选 \(L\)（第 1 列），代价为 2。这意味着如果在许多独立试验上平均，它们可以用确定性策略得到期望代价 2。如果这个矩阵没有确定性鞍点，就需要随机化策略。有趣的是，这个例子不需要随机化，尽管 P₁ 和 P₂ 各自都在同时对抗自然和一个聪明的对手。

还可能有若干其它变体。如果用非确定方式对自然建模，可以构造一个最坏情况遗憾的矩阵，来判断是否可能消除遗憾。也可以考虑图 10.19 那种博弈的序贯版本：每个阶段有三个子阶段，自然、P₁、P₂ 都行动。10.5.1 节的自底向上方法可以把树分解成许多单阶段博弈，它们的代价可以像以前一样向上传播到根，得到均衡解。Formulation 10.4 也可以很容易地推广到在状态空间上的博弈中引入自然：对每个 \(x\)，定义一个自然动作集合 \(\Theta(x)\)，状态转移方程定义为

$$x_{k+1} = f(x_k,u_k,v_k,\theta_k), \tag{10.120}$$

这意味着下一状态除了依赖当前状态外，还依赖三个玩家的动作。把自然的影响适当地考虑进动态规划方程，就可以把值迭代推广到求解这类问题：例如概率情形下，每次迭代都需要对自然求期望。这样得到的序贯博弈常称为 Markov 博弈 Markov game。

  • 把 p 调到 1/2：A = [[3, −3/2], [0, 3/2]] 没有确定性鞍点，随机化值 3/4；p = 2/3 时随机化值 4/13。

引入更多玩家

引入更多玩家除了使记号复杂外没有大困难。例如设 \(n\) 个玩家 P₁、P₂、…、Pₙ 轮流进行博弈。考虑用博弈树表示：一个阶段现在被拉伸成 \(n\) 个子阶段，每个玩家各自行动。设总是 P₁ 先行，然后 P₂，如此直到 Pₙ；Pₙ 行动之后开始下一个阶段，P₁ 再行动。这种循环的玩家轮替一直持续到博弈结束。同样可能有许多不同的信息模型：例如在阶段式模型下，每个玩家不知道其他 \(n-1\) 个玩家在当前阶段选的动作。自底向上的计算方法可以用来计算 Nash 均衡，但又要面对不唯一性的问题。可以通过为每个玩家 Pᵢ 和状态 \(x\in X\) 引入动作集 \(U^i(x)\) 来做出推广 Formulation 10.4 的状态空间表述。令 \(u^i_k\) 表示 Pᵢ 在阶段 \(k\) 选的动作，状态转移变成

$$x_{k+1} = f(x_k,u^1_k,u^2_k,\ldots,u^n_k). \tag{10.121}$$

每个 Pᵢ 还有一个代价函数 \(L_i\)。改造成维护多个均衡和代价向量的值迭代可以用来计算 Nash 均衡。

10.6 连续状态空间 Continuous State Spaces

本章涵盖的几乎所有概念都能推广到连续状态空间，这使它们至少在理论上能用于配置空间。于是涉及不确定性或不合作机器人的运动规划问题，可以用本章的概念建模；这样的问题也继承了第 8 章的反馈概念。本节讨论包含自然带来的不确定性的反馈运动规划问题。在特定情形下，也许能推广 8.4 和 8.5 节的一些方法；解反馈计划必须保证尽管有自然的努力也能到达目标。在第 8 章的方法中，最容易推广的是 8.5.2 节介绍的带插值的值迭代，因此它是本节的重点。连续状态空间中的博弈见 13.5 节。

10.6.1 扩展值迭代方法

讲法与 8.5.2 节相同：从离散问题开始，把各个组成部分变成连续的。从 Formulation 10.1 出发，令 \(X\) 是 \(\mathbb{R}^n\) 的有界开子集，假设 \(U(x)\) 和 \(\Theta(x,u)\) 是有限的。利用 8.5.2 节的插值概念，可以直接用 10.2.1 节的值迭代方法计算 \(X\) 上的代价到目标值。非确定情形下的递推是 (10.39)，其中 \(G^*_{k+1}\) 表示在有限样本集 \(S\subset X\) 上，在 \(R(S)\) 的其它点上用插值求值（回忆 8.5.2 节，\(R(S)\) 是 \(S\) 的插值区域）。概率情形下仍可用 (10.45) 或 (10.46)，但 \(G^*_{k+1}\) 用插值求值。

若 \(U(x)\) 是连续的，可以像 8.5.2 节建议的那样对它采样，来求每个递推中的最小值。现在设 \(\Theta(x,u)\) 是连续的。非确定情形下，可以对 \(\Theta(x,u)\) 采样来求 (10.39) 中的最大值，或者直接在 \(\Theta(x,u)\) 上用一般的优化技术。概率情形下，期望必须在连续的概率空间上求：概率密度函数 \(p(\theta\mid x,u)\) 刻画自然的动作，由此可以推出概率状态转移密度函数 \(p(x_{k+1}\mid x_k,u_k)\)。用这些密度，(10.45) 和 (10.46) 的连续版本分别变成

$$G^*_k(x_k) = \min_{u_k\in U(x_k)}\Big\{\int_{\Theta(x_k,u_k)}\Big(l(x_k,u_k,\theta_k) + G^*_{k+1}(f(x_k,u_k,\theta_k))\Big)p(\theta_k\mid x_k,u_k)\,d\theta_k\Big\} \tag{10.122}$$
$$G^*_k(x_k) = \min_{u_k\in U(x_k)}\Big\{l(x_k,u_k) + \int_X G^*_{k+1}(x_{k+1})\,p(x_{k+1}\mid x_k,u_k)\,dx_{k+1}\Big\}. \tag{10.123}$$

可以用采样来求积分。一种直接的方法是用离散分布近似 \(p(\theta\mid x,u)\)：例如在一维中，把 \(\Theta(x,u)\) 划分成若干区间，每个区间宣布为一个离散的自然动作，与之关联的概率就是 \(p(\theta\mid x,u)\) 在该区间上的积分。

8.5.2 节最后描述了连续空间的类 Dijkstra 算法。它们主要用反向投影 (8.66) 推出：某些样本因为离活跃集太远而不能改变它们的值。同样的原理可以用于现在的设定，但必须改用弱反向投影 (10.20)：用弱反向投影，可以在去掉所有不在活跃集中的样本的同时照常做值迭代。不过对许多问题，活跃集可能很快变得难以管理，因为弱反向投影的传播往往比原来的反向投影快得多。10.2.3 节类 Dijkstra 算法的连续状态推广也可以做出来；但这需要一个附加条件：每次迭代都必须能够不顾自然地把下一状态强迫落在 \(R(D)\) 中，从而扩大 \(D\)。

10.6.2 与自然对抗的运动规划

回忆 8.5.2 节：带插值的值迭代可以用于以离散时间近似的运动规划问题。自然甚至也可以引入离散时间近似。例如 (8.62) 可以换成

$$x(t+\Delta t) = x(t) + \Delta t\,(u + \theta), \tag{10.124}$$

其中 \(\theta\) 从有界集合 \(\Theta(x,u)\) 中选取。用 (10.124) 可以像上面那样做值迭代。图 10.20 是这个模型下用概率不确定性的一个二维运动规划问题的例子：自然是概率的（在一个角度区间上均匀分布），可以干扰运动方向；这个问题中实际上允许与障碍接触11。有趣的是，从固定初始状态执行计划时，每次得到的轨迹都不同；但多次执行的平均代价接近期望最优值。

常见陷阱

  1. 用动作序列当计划：有自然时未来状态不可预测，必须用 \(\pi : X\to U\)；只看动作序列的前向投影会「冲过头」（例 10.1，数轴前向投影图）。
  2. 把 SB(S, u) 当成 SB(x, u) 的并：强反向投影要求整个前向投影落在 S 里，逐点求再并会漏掉（习题 1，例 10.5）。
  3. 概率问题用 \(l_F = \infty\)：任何有限阶段问题都有正概率没到达，值迭代全是 ∞；给一个大的有限值。
  4. 把「可能可达」当「保证可达」：最坏情况下只要 \(\mathcal{G}_\pi\) 有一个不经过目标的环，代价就是 ∞，而期望代价可能很小。
  5. 等值迭代「完全不变」再停：概率情形常常只是渐近收敛（例 10.6），要用阈值 \(\epsilon\)。
  6. 转移矩阵的方向：(10.16) 的 \(M_u\) 是列随机的，\(v' = M_u v\) 里 \(v\) 是列向量；很多书用行随机矩阵和行向量。
  7. 折扣时混用阶段编号：书中折扣部分令第一阶段 \(k = 0\)，与 Formulation 10.1 的 \(k = 1\) 不同；(10.70)(10.71) 的求和下标还与此不一致（脚注 6）。
  8. 对概率问题直接套 Dijkstra：只有存在以概率 1 单调前进的计划时才行，否则代价变化的区域不是一条传播带。
  9. TD / Q-learning 的步长：用 \(1/v\) 递减步长、初值又差得远时，自举方法可能非常慢；常数 \(\rho\) 更快但有噪声（(10.95) 后的讨论）。
  10. 忽略信息模型：同一棵博弈树，交替行动、阶段式、开环给出不同的值（图 10.13：1、1、2）。
  11. 把 P₂ 的安全计划画在 P₁ 先行的树上算：求下值要交换次序，叶子也随之重排（图 10.15）。

习题导引

只给思路，不给完整解答。标「互动」的可以先在本页对应的图里做实验。

  1. SB(S, u) 不是 SB(x, u) 的并：例 10.5 就是反例：\(S = X_G\)、\(u = 2\)，逐点都是 ∅，合起来是 {−2}。（互动：「弱反向投影与强反向投影」。）
  2. SB(S) ⊆ WB(S)：\(\Theta(x',u)\) 非空，所以「∀θ 都进 S」蕴含「∃θ 进 S」；对 \(u\) 取存在量词保持包含关系。
  3. 多阶段反向投影：像 (10.12) 那样递归：\(\mathrm{SB}_2(S) = \mathrm{SB}(\mathrm{SB}(S))\)……想想弱的版本对应「存在一条自然动作序列」，强的对应反向投影算法里 S 的逐遍增长。
  4. 无限阶段的前向投影：用 (10.28) 递归，注意 \(X_G\) 里 \(u_T\) 让状态不再变化；关注前向投影的并 \(\bigcup_k X_k(x_1,\pi)\) 是否有限。
  5. 用 0/1 矩阵算非确定前向投影：把 (10.16) 的概率换成「是否可能」，矩阵乘法换成布尔半环（OR / AND）；每步 \(O(n^2)\) 时间、\(O(n^2)\) 空间（每个动作一个矩阵），稀疏时可以按边数计。
  6. 「可能达到」版本的图 10.6：把 SB 换成 WB——它得到的是「可能可达」的状态集合，计划只保证存在一条好运的自然序列。
  7. –8. 前向值迭代：对照 2.3.1.1 节的前向值迭代，把 \(f^{-1}\) 换成反向投影；概率情形要小心「代价到达」的定义需要初始分布。
  8. 从 \(\mathcal{G}_\pi\) 直接算概率前向投影：在带概率的边上做 (10.29) 的传播即可，也就是稀疏地乘 \(M_\pi\)。（互动：「计划、G_π 与代价」的前向投影。）
  9. 处理「可能但非保证可达」的状态：先用图 10.6（或它的弱版本）分出保证可达集合，只在它上面判断收敛；其余状态的值标为 ∞。（互动：值迭代实验室的「侧滑 + 最坏情况」。）
  10. –12. 依赖阶段的 \(f\) 与 \(l\)：递推里把 \(f(x_k,u_k,\theta_k)\) 换成 \(f(x_k,u_k,\theta_k,k)\)、\(l\) 同理；此时不能再期望平稳解，计划也要依赖阶段。
  11. 代价依赖自然的策略迭代：(10.53) 里的 \(l(x,\pi(x))\) 换成 \(\sum_\theta l(x,\pi(x),\theta)P(\theta\mid x,\pi(x))\)，(10.54) 同理。
  12. 非确定版策略迭代：求值步变成在 \(\mathcal{G}_\pi\) 上求最长路（有环就是 ∞，见本页「计划、G_π 与代价」的做法）；改进步用 (10.48) 的 max。
  13. 在 Formulation 2.3 上用策略迭代：可以；求值退化成 (10.50) 那样沿计划回溯的加法（像 Dijkstra 一样一圈圈求出），改进步就是在图上做局部改进。
  14. 折扣 ≡ 随机最短路（提示：[11] 第 378 页）：加一个吸收的终止状态，每步以概率 \(1-\alpha\) 跳过去、以 \(\alpha\) 按原转移走；期望总代价正好等于折扣代价。
  15. 非确定折扣值迭代：把 (10.74) 的期望换成 \(\max_\theta\)，得到 \(J^*_i(x) = \min_u\max_\theta\{l + \alpha J^*_{i-1}\}\)，它计算 (10.71)。
  16. 图 10.23 的随机化值：照 (10.105) 的做法：先解四个 2×2 矩阵（有一个没有确定性鞍点），再解顶层 2×2。（互动：「三种信息模型」里选图 10.23，自己算完再看。）
  17. 状态空间上的 alpha-beta：从固定初始状态做深度优先，维护 α、β；在博弈图上要小心同一状态被多次访问（可以缓存值，但缓存要连同当时的 α、β 窗口）。
  18. 推导 (10.110)(10.111)：照搬 (10.33)–(10.39) 的推导，把 \(\max_\theta\) 换成 \(\max_v\)；下值则从 (10.109) 开始，min 与 max 对调。
  19. –22. Formulation 2.4（STRIPS 式）加不确定性：每个算子给出一组可能的效果（非确定）或带概率的效果（概率）；对应到状态空间就是 \(\Theta(x,u)\)。
