Part III · 第 9 章

基本决策论 Basic Decision Theory

Part III 讨论不确定性下的规划。这一章是它的地基：把规划问题压缩成只有一步的决策，然后认真地问——当还有别的决策者 decision maker（DM）会干扰结果时，什么叫「最好的决策」？那个干扰者可能是一个用来建模不确定性的虚构角色「自然 nature」，也可能是一个真正有智能、和你利益冲突的对手。第 10–12 章会把这里的一步决策串成多步。

本章导读

本章的脉络。9.2 与 9.3 其实是同一张矩阵的两种读法：列由「自然」选，还是由一个聪明的对手选。

和第 2 章相比，这一章把规划的步数降到 1，再引入更复杂的建模方式。因为没有信息需要跨越多个阶段传递，也就不需要状态空间；所以书中暂时不说「为机器人设计计划 plan」，而说「为决策者设计策略 strategy」，规划问题也降格成决策问题 decision-making problem。回到多阶段的第 10 章时，第 2 章的大部分算法都能自然地吸收这里的决策论概念。

Part III 反复出现的主题是多个决策者的相互作用。除了一直被称为「机器人」的主角之外，还有别的 DM：它们不能被机器人预测或控制。一个特殊的 DM 叫自然，它是建模不确定性的通用手段——通常是虚构的，并不真的在为自己的利益做理性决策，只是一个方便的建模工具。也有一些情形里其它 DM 是真正的对手，这就进入博弈论 game theory，所有 DM（包括机器人）都叫玩家 players。

9.1 预备概念 Preliminary Concepts

9.1.1 优化 Optimization

单目标优化

先看最简单的情形：只有一个决策者，它要做出最好的决策。这就是熟悉的优化 optimization 问题。

Formulation 9.1（优化 Optimization）
  1. 非空集合 \(U\)，称为动作空间 action space；每个 \(u\in U\) 称为一个动作 action。
  2. 函数 \(L : U \to \mathbb{R}\cup\{\infty\}\)，称为代价函数 cost function。

和 Formulation 2.2 对比：状态空间 \(X\)、状态转移都不需要了，因为只有一次决策；没有状态空间，也就没有初始状态和目标状态。策略就是选出最好的动作。如果 \(U\) 有限，最好的动作 \(u^*\in U\) 是

$$u^* = \operatorname*{argmin}_{u\in U}\Big\{L(u)\Big\}. \tag{9.1}$$

\(U\) 无限时情况就不同了。设 \(U = (-1,1)\)、\(L(u) = u\)：我们想说 \(-1\) 代价最低，但 \(-1\notin U\)；若 \(U = [-1,1]\) 就没问题。在开区间上没有代价最小的动作：任给 \(u\)，总能找到 \(u'\) 使 \(L(u') < L(u)\)。可如果 \(L(u) = |u|\)，(9.1) 正确地给出 \(u = 0\)——最小值在内部而不在边界上。所以一般要当心：最优值可能不存在。两种补救：

  • 要求 \(U\) 闭且有界（4.1 节）。闭集包含边界，避免了上面的问题；有界性排除 \(U = \mathbb{R}\)、\(L(u) = u\) 这种情形（\(\mathbb{R}\) 是闭集，但越往负方向代价越小）。
  • 改用下确界 infimum inf——能放在代价下面的最大下界。对 \(U=(-1,1)\)、\(L(u)=u\)：
    $$\inf_{u\in(-1,1)}\Big\{L(u)\Big\} = -1. \tag{9.2}$$
    唯一的困难是没有任何 \(u\) 真正取到这个代价——下确界实际上用到了 \(U\) 的闭包。无界问题也能处理：\(U = \mathbb{R}\)、\(L(u)=u\) 的下确界是 \(-\infty\)。

经验法则：拿不准时，在本该写 min 的地方写 inf 更安全——最小值存在时下确界就等于它，不存在时也给出合理的答案（只是在 \(U\) 有限时写 inf 看起来有点多余）。

把 \(L\) 乘以 \(-1\) 就得到「倒过来」的问题，本质不变。有时最大化更自然，例如 9.5.1 节的效用理论：定义回报函数 reward function \(R\)，选 \(u\) 使回报最大；令 \(L(u) = -R(u)\) 就变回最小化。最大化问题里，inf 换成上确界 supremum sup。

本书大多数问题里，一次决策中选最优 \(u\) 都很直接——规划的复杂性来自别处。但要意识到：当 \(U\) 和 \(L\) 复杂时，优化本身就极具挑战。\(U\) 可能有限但极大，也可能是 \(\mathbb{R}^n\) 的高维子集（比如 1000 维）；代价函数可能根本写不出闭式。简单时可以用微积分里的一阶、二阶导数；真实应用中往往要用梯度下降之类的方法，只能保证局部最小。很多时候需要基于采样的技术——5.2 节的分散度等采样思想最初就是为优化发展的。另一些问题有组合解法，例如线性规划 linear programming（求一组线性函数的最小 / 最大，9.4 节会出现）。第 5、6 章分别沿着采样和组合两种思路——它们与优化有平行之处。最优运动规划其实是在路径空间上的优化问题，极难刻画；6.2.4 节等特殊情形能求最优解，一般则极具挑战。变分法 calculus of variations 是在满足微分约束的路径空间上做优化的一般方法（13.4.1 节）。

多目标优化

Formulation 9.2（多目标优化 Multiobjective Optimization）
  1. 非空集合 \(U\)，称为动作空间；每个 \(u\in U\) 称为一个动作。
  2. 向量值代价函数 \(L : U\to\mathbb{R}^d\)（\(d\) 是某个整数）。如有需要，代价的任何分量都可以是 \(\infty\)。

7.7.2 节多机器人最优协调时已经见过这个问题。两个动作 \(u\)、\(u'\) 称为等价 equivalent，若 \(L(u) = L(u')\)。称 \(u\) 支配 dominate \(u'\)，若它们不等价，且对所有 \(1\le i\le d\) 都有 \(L_i(u)\le L_i(u')\)。这在动作集合上定义了一个偏序 partial ordering \(\le\)；许多动作是不可比的 incomparable。不被任何其它动作支配的动作叫 Pareto 最优 Pareto optimal——也就是关于这个偏序的极小元。

例 9.1（Pareto 最优的简单例子）：\(U=\{1,2,3,4,5\}\)、\(d=2\)，\(L(1)=(4,0)\)、\(L(2)=(3,3)\)、\(L(3)=(2,2)\)、\(L(4)=(5,7)\)、\(L(5)=(9,0)\)。动作 2、4、5 可以排除，因为它们被别的动作支配：例如 \((3,3)\) 被 \((2,2)\) 支配，所以 \(u=3\) 比 \(u=2\) 好。剩下的 \(u=1\) 和 \(u=3\) 是 Pareto 最优的。看来 Pareto 最优的主要作用是丢掉被支配的动作：可能剩下不止一个，但至少把 \(U\) 缩小到一组「最好的候选」。

例 9.2（宾夕法尼亚收费公路 Pennsylvania Turnpike）：想象开车横穿宾夕法尼亚州，收费公路上曾经立着吓人的限速与罚款牌。\(U=\{50,51,\ldots,100\}\) 是可选的整数车速（英里 / 小时）。罚款：56–65 罚 \$50，66–75 罚 \$100，76–85 罚 \$200，86–100 罚 \$500；超过 100 据说要坐牢，不予考虑。两个准则：(1) 穿过全州的时间，(2) 罚款金额；假设只要超速就一定被抓。目标是两者都小。比较 56 和 57：罚款相同，57 更快，所以 57 支配 56。事实上 65 支配一直到 56 的所有速度——罚款一样，时间最短。由此推出 Pareto 最优车速是 55、65、75、85、100。在它们之间怎么选取决于司机自己；但明显不该选这五个之外的速度。

例 9.3（连续的 Pareto 最优解）：\(U=[0,1]\)、\(d=2\)、\(L(u)=(u,1-u)\)。每个 \(u\) 都是 Pareto 最优：一个准则稍微变小，另一个就变大，任何两个动作都不可比。这说明了 Pareto 最优的主要「挫败感」：去掉非支配解之后可能还是太多，甚至有一整个连续统。它是否有用，取决于具体应用。

9.1.2 概率论回顾 Probability Theory Review

这一节回顾一些基本的概率概念，并引入整个 Part III 使用的记号。

概率空间 probability space \((S,\mathcal{F},P)\)
  1. 样本空间 sample space：非空集合 \(S\)，代表所有可能的结果。
  2. 事件空间 event space：\(S\) 的子集族 \(\mathcal{F}\)。\(S\) 离散时通常 \(\mathcal{F} = \mathrm{pow}(S)\)；\(S\) 连续时 \(\mathcal{F}\) 通常是 5.1.3 节的 σ-代数。
  3. 概率函数 probability function \(P:\mathcal{F}\to\mathbb{R}\)，给事件赋概率；有时也叫 \(S\) 上的概率分布。它满足公理：\(P(E)\ge0\)；\(P(S)=1\)；若 \(E\cap F=\emptyset\)，则 \(P(E\cup F) = P(E)+P(F)\)。

\(S\) 离散时，\(P\) 只要在单元素上定义就能由公理推出整个 \(\mathcal{F}\) 上的值。常写 \(P(s)\)——严格说应写 \(P(\{s\})\)，因为 \(s\) 不是事件。例 9.4（掷一颗骰子）：\(S=\{1,\ldots,6\}\)，事件空间 \(\mathrm{pow}(S)\) 共 \(2^6\) 个子集；均匀时 \(P(\{s\})=1/6\)；「掷出偶数」的事件 \(E=\{2,4,6\}\) 概率为 1/2。第三条公理像 5.1.3 节测度空间的最后一条公理——\(P\) 其实是一种特殊的测度（例 5.12）。\(S\) 连续时单点的概率通常为零，改用概率密度函数 probability density function \(p : S\to\mathbb{R}\)：

$$P(E) = \int_E p(x)\,dx. \tag{9.3}$$

条件概率、独立与贝叶斯规则

条件概率「给定 \(F\) 时 \(E\) 的概率」：

$$P(E\,|\,F) = \frac{P(E\cap F)}{P(F)}. \tag{9.4}$$

\(E\)、\(F\) 独立 independent 当且仅当 \(P(E\cap F) = P(E)P(F)\)，否则相关 dependent。一个重要又容易误解的概念是条件独立 conditional independence：\(E\)、\(F\) 本身相关，但给定第三个事件 \(G\) 后变得独立：\(P(E\cap F)\neq P(E)P(F)\)，而 \(P(E\cap F\,|\,G) = P(E|G)P(F|G)\)。书中的例子：\(E\) 是一个人的身高，\(F\) 是他的阅读水平——孩子个子矮、阅读水平也低，所以两者相关；但给定年龄 \(G\) 后，身高和阅读水平就不该再有关联了。

(9.4) 给出约束

$$P(E\cap F) = P(F)P(E|F) = P(E)P(F|E), \tag{9.5}$$

由此得到交换 \(E\) 与 \(F\) 的贝叶斯规则 Bayes' rule：

$$P(F\,|\,E) = \frac{P(E|F)P(F)}{P(E)}. \tag{9.6}$$

\(P(F)\) 称为先验 prior，\(P(F|E)\) 称为后验 posterior——分别是考虑 \(E\) 之前和之后的概率。所有概率都以某个 \(G\) 为条件时，得到条件贝叶斯规则：

$$P(F\,|\,E,G) = \frac{P(E|F,G)P(F|G)}{P(E|G)}. \tag{9.7}$$

边缘化 marginalization：设 \(F_1,\ldots,F_n\) 是 \(S\) 的任一划分，则

$$P(E) = \sum_{i=1}^{n} P(E|F_i)P(F_i). \tag{9.8}$$

它最有用的地方是贝叶斯规则的分母。把 (9.8) 代进 (9.6)：

$$P(F\,|\,E) = \frac{P(E|F)P(F)}{\displaystyle\sum_{i=1}^{n}P(E|F_i)P(F_i)}. \tag{9.9}$$

这个形式常常更好用，因为 \(P(E)\) 看起来被「消掉」了。

随机变量与期望

随机变量 random variable \(X\) 是把 \(S\) 映到 \(\mathbb{R}\) 的函数。书中脚注吐槽这个名字很糟糕：它既不「随机」，也不是「变量」，就是一个函数 \(X:S\to\mathbb{R}\)；更糟的是习惯上用大写字母表示它，而函数通常用小写。\(S\) 本身就是 \(\mathbb{R}\) 的子集时，\(X\) 默认取恒等函数。期望 expectation 是按概率加权的平均：

$$E[X] = \sum_{s\in S} X(s)P(s), \tag{9.10}$$
$$E[X] = \int_S X(s)p(s)\,ds \qquad(S\ \text{连续}). \tag{9.11}$$

（用测度论的语言，两者都是 Lebesgue 积分的特例，不必分开写。）条件期望把分布换成条件分布，例如 \(S\) 离散、给定事件 \(F\)：

$$E[X\,|\,F] = \sum_{s\in S} X(s)P(s|F). \tag{9.12}$$

例 9.5（掷骰子）：回到例 9.4，令 \(X(s)=s\)，用 (9.10)1 得 \(E[X] = 3.5\)。注意期望值未必是实际中「期望」出现的值：3.5 根本不可能掷出来。若只在掷出大于 3 的试验上取期望，即事件 \(F=\{4,5,6\}\)，由 (9.12) 得 \(E[X|F]=5\)。连掷两颗时 \(s=(i,j)\)，\(S\not\subset\mathbb{R}\)，可以令 \(X(s)=i+j\)，此时 \(E[X]=7\)。

9.1.3 随机化策略 Randomized Strategies

到目前为止，计划里的动作都是确定性的 deterministic：第 2 章的计划完全确定地指定动作；Formulation 9.1 的策略就是「每次都做同一个决策」。有些应用里决策者不希望被预测，这时可以把随机化引入策略。\(U\) 离散时，随机化策略 randomized strategy \(w\) 由 \(U\) 上的一个概率分布 \(P(u)\) 给出；\(W\) 表示所有随机化策略的集合。现在要区分定义策略和应用（执行）策略：执行时按 \(P(u)\) 抽样选出动作。重复执行时假设各次独立：\(P(u_k|u_i)=P(u_k)\)，即第 \(k\) 次选 \(u_k\) 的概率不受之前第 \(i纯策略 pure 和混合策略 mixed。

例 9.6（抛硬币做决定）：\(U=\{a,b\}\)，抛一枚均匀硬币，正面选 \(a\)、反面选 \(b\)，即 \(P(a)=P(b)=1/2\)。每次执行前不知道会选哪个，但多次之后大约一半时间选 \(a\)。

确定性策略总可以看成随机化策略的特例：要模拟 \(u_i\)，令 \(P(u)=1\)（\(u=u_i\)）、否则为 0——「只有以概率零才会选到别的动作（可能，但不大可能！）」。用随机化策略求解 Formulation 9.1 时，代价没法预测，于是定义平均代价：执行次数趋于无穷时，平均值收敛到期望代价 \(\bar L(w)\)（把 \(L\) 看成随机变量）。\(U\) 离散时

$$\bar L(w) = \sum_{u\in U} L(u)P(u) = \sum_{u\in U} L(u)\,w_i, \tag{9.13}$$

其中 \(w_i\) 是 \(w\) 对应于该 \(u\) 的分量。是否存在比所有确定性策略都好的 \(w\)，即对所有 \(u\) 都有 \(\bar L(w) < L(u)\)？答案是否：最好的策略总是把概率 1 放在最小化 \(L\) 的 \(u^*\) 上。若有两个以上动作同样最优，随机化策略可以在它们之间随意分配概率，但不会进一步降低代价。所以在这种情形下随机化毫无意义——除非有别的考虑。

一个随机化至关重要的例子是对抗有智能的对手：如果问题重复很多次，对手很容易学会任何确定性策略。随机化可以削弱对手的预测能力。9.3 节会用这个想法改进零和博弈的玩法。

例 9.7（猜硬币 Matching Pennies）：两个玩家反复同时把硬币放在桌上，正面 H 或反面 T 朝上。结果 HH 或 TT（相同）时，玩家 1 付玩家 2 一比索；HT 或 TH 时，玩家 2 付玩家 1 一比索。如果玩家 1 用确定性策略，玩家 2 一旦摸清它，就能每次都赢；玩家 1 用最好的随机化策略，平均下来最多不输不赢。哪个随机化策略能做到？把它推广到三个动作就是著名的石头剪刀布：要写一个和聪明对手反复对弈的程序，最好引入随机化。

9.2 与自然对弈 A Game Against Nature

9.2.1 为自然建模 Modeling Nature

这是全书第一次直接为不确定性建模。有两个 DM：

  • 机器人 Robot：全书主要 DM 的名字。现在有两个 DM 了，这个名字用来区分彼此。
  • 自然 Nature：一种对机器人来说不可预测的神秘力量。它有自己的动作集合，选择的方式会干扰机器人的成就。自然可以看作为了在决策或规划中建模不确定性而构造出来的合成 DM。

想象机器人和自然各做一个决策，代价取决于双方的选择，仍然代表结果对机器人的影响；但机器人现在必须考虑自然的影响。自然不可预测，所以机器人要为它的行为建立模型。机器人有动作集合 \(U\)；自然也有一个动作集合，称为自然动作空间 nature action space，记为 \(\Theta\)，自然动作记为 \(\theta\in\Theta\)。\(U\) 现在称为机器人动作空间，不致混淆时仍简称动作空间。

Formulation 9.3（与自然对弈 A Game Against Nature）
  1. 非空集合 \(U\)，称为（机器人）动作空间；每个 \(u\in U\) 称为一个动作。
  2. 非空集合 \(\Theta\)，称为自然动作空间；每个 \(\theta\in\Theta\) 称为一个自然动作。
  3. 函数 \(L : U\times\Theta\to\mathbb{R}\cup\{\infty\}\)，称为代价函数。

代价现在同时依赖 \(u\) 和 \(\theta\)。\(U\)、\(\Theta\) 有限时，可以把 \(L\) 写成 \(|U|\times|\Theta|\) 的代价矩阵 cost matrix。例 9.8（一个简单的与自然对弈）：\(U\)、\(\Theta\) 各有三个动作，九种结果的代价矩阵是

L(u, θ)θ₁θ₂θ₃
u₁1−10
u₂−12−2
u₃2−11

机器人的动作选一行，自然的动作选一列，代价就是对应的矩阵元素。

Formulation 9.3 里双方像是同时行动：自然在决策前不知道机器人的动作。很多情境下自然可能知道机器人的动作，这时可以对每个 \(u\) 定义不同的自然动作空间：

Formulation 9.4（自然知道机器人的动作 Nature Knows the Robot Action）
  1. 非空集合 \(U\)，称为动作空间。
  2. 对每个 \(u\in U\)，一个非空集合 \(\Theta(u)\)，称为自然动作空间。
  3. 函数 \(L : U\times\Theta\to\mathbb{R}\cup\{\infty\}\)，称为代价函数。

机器人选了 \(u\) 之后，自然从 \(\Theta(u)\) 中选。

9.2.2 非确定性模型 vs 概率模型 Nondeterministic vs. Probabilistic Models

与自然对弈时，什么是最好的决策？这取决于机器人对自然如何选择动作掌握了什么信息。总假设机器人不知道自然究竟会选哪个动作（否则就没必要定义自然了）。从机器人的视角，有两种模型：

模型机器人的心声做法
非确定性 nondeterministic「我完全不知道自然会做什么。」只知道 \(\Theta\)（或 \(\Theta(u)\)）；按最坏情况决策
概率 probabilistic「我一直在观察自然、收集统计数据。」还知道 \(P(\theta)\)（或 \(p(\theta)\)）；按期望决策

这两个术语借自 Erdmann。有些文献用 possibilistic 代替 nondeterministic——很好的词，可惜在英语里和 probabilistic 太像。

最坏情况分析

非确定性模型下没有更多信息。合理的做法是假设最坏：甚至可以想象自然知道机器人会选什么，并恶意地选一个把代价推到最高的动作。这种悲观的看法常被戏称为墨菲定律（「凡是可能出错的事就一定会出错」）或 Sod 定律。于是最好的动作是

$$u^* = \operatorname*{argmin}_{u\in U}\Big\{\max_{\theta\in\Theta}\Big\{L(u,\theta)\Big\}\Big\}. \tag{9.14}$$

这叫最坏情况分析 worst-case analysis，因式中的 min 和 max 也常叫 minimax 解。\(U\) 或 \(\Theta\) 无限时 min、max 可能不存在，应换成 inf、sup。

期望情况分析

最坏情况有时太悲观；也许假设 \(\Theta\) 中所有动作等可能更好——这是下面概率模型的特例。概率模型下，假设机器人已经收集了足够数据，能可靠地估计 \(P(\theta)\)（或 \(p(\theta)\)）。这相当于想象自然在执行 9.1.3 节的随机化策略：过去很多次试验观察到的自然动作，将来也会按 \(P(\theta)\) 以同样方式出现。于是改用期望情况分析 expected-case analysis，优化在大量独立试验中得到的平均代价：

$$u^* = \operatorname*{argmin}_{u\in U}\Big\{E_\theta\big[L(u,\theta)\big]\Big\}, \tag{9.15}$$

\(E_\theta\) 表示按 \(\theta\) 的分布取期望。\(\Theta\) 与 \(P(\theta)\) 构成概率空间，对每个 \(u\)，\(L(u,\theta)\) 是一个随机变量（也可以把随机变量定义在 \(U\times\Theta\) 上，再取给定 \(u\) 的条件期望）。于是

$$E_\theta\big[L(u,\theta)\big] = \sum_{\theta\in\Theta} L(u,\theta)P(\theta). \tag{9.16}$$

例 9.9（非确定性 vs 概率）：回到例 9.8，\(U=\{u_1,u_2,u_3\}\)，\(\Theta=\{\theta_1,\theta_2,\theta_3\}\)。非确定性模型下 \(u^*=u_1\)，最坏代价 \(L(u^*,\theta)=1\)。概率模型下设 \(P(\theta_1)=1/5\)、\(P(\theta_2)=1/5\)、\(P(\theta_3)=3/5\)，用 (9.15) 逐个计算期望代价：

$$\begin{aligned} E_\theta[L(u_1,\theta)] &= (1)\tfrac15 + (-1)\tfrac15 + (0)\tfrac35 = 0\\ E_\theta[L(u_2,\theta)] &= (-1)\tfrac15 + (2)\tfrac15 + (-2)\tfrac35 = -1\\ E_\theta[L(u_3,\theta)] &= (2)\tfrac15 + (-1)\tfrac15 + (1)\tfrac35 = \tfrac45. \end{aligned} \tag{9.17}$$

最好的是 \(u^*=u_2\)，期望代价 \(-1\)。若分布换成 \(P=[1/10\ \ 4/5\ \ 1/10]\)，就会得到 \(u^*=u_1\)。所以最好的决策依赖于 \(P(\theta)\)：如果这个信息在统计上可靠，就能做出更有根据的决策；如果没有这样的信息，非确定性模型可能更合适。没有数据时也可以把 \(P(\theta)\) 设成均匀分布（所有自然动作等可能），但基于此的结论是危险的（9.5 节）。

在 Formulation 9.4 中，自然动作空间 \(\Theta(u)\) 依赖于机器人的动作 \(u\)。非确定性模型下 (9.14) 简单地变成

$$u^* = \operatorname*{argmin}_{u\in U}\Big\{\max_{\theta\in\Theta(u)}\Big\{L(u,\theta)\Big\}\Big\}. \tag{9.18}$$

可惜这类问题没有漂亮的矩阵表示，因为 \(\Theta(u)\) 的大小可以随 \(u\) 变化。概率情形下 \(P(\theta)\) 换成条件分布 \(P(\theta|u)\)；估计它需要对每个可能的 \(u\) 观察大量独立试验。自然的行为现在可以依赖于机器人的动作，但它仍由一个随机化策略刻画——它不会跨试验调整策略。(9.16) 中的期望变成

$$E_\theta\big[L(u,\theta)\big] = \sum_{\theta\in\Theta(u)} L(u,\theta)P(\theta|u). \tag{9.19}$$

遗憾 regret

要注意，这里给出的模型并不是做出好决策的唯一公认方式。博弈论的关键想法是最小化「遗憾」——做了一个坏决策、事后希望能改掉时的那种感觉。假设你选了 \(u\) 之后被告知自然用了 \(\theta\)；遗憾就是「给定自然的动作，如果你换一个动作本可以省下多少代价」。对每个 \((u,\theta)\)，遗憾 \(T\) 定义为

$$T(u,\theta) = \max_{u'\in U}\Big\{L(u,\theta) - L(u',\theta)\Big\}. \tag{9.20}$$

对 Formulation 9.3，\(U\)、\(\Theta\) 有限时可以定义遗憾矩阵 regret matrix3：每列减去该列的最小值。若最关心的是最小化遗憾而不是实际代价，非确定性模型下最小化最坏遗憾的动作是

$$u^* = \operatorname*{argmin}_{u\in U}\Big\{\max_{\theta\in\Theta}\Big\{T(u,\theta)\Big\}\Big\}, \tag{9.21}$$

概率模型下最小化期望遗憾的动作是

$$u^* = \operatorname*{argmin}_{u\in U}\Big\{E_\theta\big[T(u,\theta)\big]\Big\}. \tag{9.22}$$

与 (9.14)、(9.15) 的唯一区别就是 \(L\) 换成了 \(T\)。9.3.2 节会更详细地讨论遗憾，因为它是博弈论中最优性概念的基础。

例 9.10（遗憾矩阵）：例 9.8 的遗憾矩阵是

T(u, θ)θ₁θ₂θ₃
u₁202
u₂030
u₃303

非确定性模型下由 (9.21) 得 \(u^*=u_1\)，最坏遗憾为 2。概率模型下设 \(P(\theta_1)=P(\theta_2)=P(\theta_3)=1/3\)，由 (9.22) 算出三个动作的期望遗憾分别是 4/3、1、2，所以最优动作是 \(u^*=u_2\)，最优期望遗憾为 12。

9.2.3 利用观测 Making Use of Observations

Formulation 9.3 和 9.4 不允许机器人在决策前得到（除 \(L\) 以外的）任何信息。现在假设机器人有一个传感器，在选动作之前可以检查一下。传感器给出一个观测 observation（或测量），包含关于自然会选哪个动作的信息。某些情境下可以把自然动作想象成已经选定的一种状态，观测提供关于它的信息。例如自然选定曼谷此刻的气温，观测就是曼谷某支温度计的读数。

表述问题

令 \(Y\) 为观测空间 observation space，即所有可能观测 \(y\in Y\) 的集合。方便起见设 \(Y\)、\(U\)、\(\Theta\) 都是离散的。模型的一部分是：给定 \(y\) 后，对 \(\theta\) 的某些约束是已知的。非确定性模型下，对每个 \(\theta\in\Theta\) 指定集合 \(Y(\theta)\subseteq Y\)，表示自然动作为 \(\theta\) 时可能出现的观测；概率模型下指定条件分布 \(P(y|\theta)\)。9.2.4 节会给出传感模型的例子，11.1.1、11.5.1 节还有更多（那里是关于状态空间 \(X\) 写的，在本节退化成 \(\Theta\)）。和之前一样，概率情形还需要先验 \(P(\theta)\)。

Formulation 9.5（有观测的与自然对弈 A Game Against Nature with an Observation）
  1. 有限非空集合 \(U\)，称为动作空间；每个 \(u\in U\) 称为一个动作。
  2. 有限非空集合 \(\Theta\)，称为自然动作空间。
  3. 有限非空集合 \(Y\)，称为观测空间。
  4. 对每个 \(\theta\in\Theta\) 指定集合 \(Y(\theta)\subseteq Y\) 或概率分布 \(P(y|\theta)\)，表示自然动作为 \(\theta\) 时哪些观测是可能的或有多大概率。概率情形还要指定先验 \(P(\theta)\)。
  5. 函数 \(L : U\times\Theta\to\mathbb{R}\cup\{\infty\}\)，称为代价函数。

求解 Formulation 9.5 时，策略不再只是指定一个动作，因为我们要在收到观测之前就完整描述机器人的行为。于是把策略定义为函数 \(\pi : Y\to U\)：对每个可能的观测 \(y\)，策略给出一个动作。我们要在所有可能的策略中搜索，找出对所有可能观测都做得最好的那一个。这里的 \(Y\) 其实是信息空间 information space 的一个特例，那是第 11、12 章的主题；最终，策略（或计划）将以信息状态为条件，它推广了观测。

最优策略

先看非确定性模型下的最优策略 \(\pi^*\)。对每个 \(\theta\) 的集合 \(Y(\theta)\) 必须「反过来」，求出对每个观测 \(y\) 可能的自然动作：

$$\Theta(y) = \{\theta\in\Theta \mid y\in Y(\theta)\}. \tag{9.23}$$

最优策略对每个 \(y\in Y\) 设

$$\pi^*(y) = \operatorname*{argmin}_{u\in U}\Big\{\max_{\theta\in\Theta(y)}\Big\{L(u,\theta)\Big\}\Big\}. \tag{9.24}$$

对比 (9.14)：那里的 max 取遍整个 \(\Theta\)；有了观测 \(y\)，集合缩小到 \(\Theta(y)\subseteq\Theta\)。

概率模型下要做与 (9.23) 类似的运算：由 \(P(y|\theta)\) 算出 \(P(\theta|y)\)，确定 \(y\) 含有的关于 \(\theta\) 的信息。用分母边缘化的贝叶斯规则 (9.9)：

$$P(\theta\,|\,y) = \frac{P(y|\theta)P(\theta)}{\displaystyle\sum_{\theta\in\Theta}P(y|\theta)P(\theta)}. \tag{9.25}$$

两种情形的联系：取 \(P(y|\theta)\) 仅当 \(y\in Y(\theta)\) 时非零，并取均匀的 \(P(\theta)\)，则 (9.25) 恰好给 (9.23) 中 \(\Theta(y)\) 的元素非零概率——(9.25) 就是 (9.23) 的概率版本。最优策略对每个 \(y\) 规定为

$$\pi^*(y) = \operatorname*{argmin}_{u\in U}\Big\{E_\theta\Big[L(u,\theta)\,\Big|\,y\Big]\Big\} = \operatorname*{argmin}_{u\in U}\Big\{\sum_{\theta\in\Theta}L(u,\theta)P(\theta|y)\Big\}. \tag{9.26}$$

与 (9.15)、(9.16) 的区别是 \(P(\theta)\) 换成了 \(P(\theta|y)\)。对每个 \(u\)，(9.26) 中的期望称为条件贝叶斯风险 conditional Bayes' risk，最优策略总是选使它最小的动作。注意 (9.26) 中的 \(P(\theta|y)\) 可以用 (9.25) 表示，其分母4就是 \(P(y)\)，与 \(u\) 无关、不影响优化；所以在 (9.26) 中用 \(P(y|\theta)P(\theta)\) 代替 \(P(\theta|y)\)，得到的 \(\pi^*\) 相同。空间连续时把概率换成概率密度，方法不变。

自然行动两次

另一种方便的表述是让自然行动两次：

  1. 先选一个自然动作 \(\theta\in\Theta\)，机器人不知道它。
  2. 再选一个自然观测动作 nature observation action，干扰机器人感知 \(\theta\) 的能力。

令 \(\psi\) 表示自然观测动作，从自然观测动作空间 \(\Psi(\theta)\) 中选。传感器映射 sensor mapping \(h\) 对每个 \(\theta\in\Theta\)、\(\psi\in\Psi(\theta)\) 给出 \(y = h(\theta,\psi)\)。于是对两种自然动作，都得到一个观测 \(y=h(\theta,\psi)\)。这给出 Formulation 9.5 的另一种写法：

Formulation 9.6（自然干扰观测 Nature Interferes with the Observation）
  1. 有限非空集合 \(U\)，称为动作空间。
  2. 有限非空集合 \(\Theta\)，称为自然动作空间。
  3. 有限非空集合 \(Y\)，称为观测空间。
  4. 对每个 \(\theta\in\Theta\)，非空集合 \(\Psi(\theta)\)，称为自然观测动作空间。
  5. 传感器映射 \(h : \Theta\times\Psi\to Y\)。
  6. 函数 \(L : U\times\Theta\to\mathbb{R}\cup\{\infty\}\)，称为代价函数。

它用一个函数 \(h\) 优雅地统一了非确定性模型与概率模型。非确定性模型假设任何 \(\psi\in\Psi(\theta)\) 都可能出现，于是

$$\Theta(y) = \{\theta\in\Theta \mid \exists\psi\in\Psi(\theta)\ \text{使得}\ y = h(\theta,\psi)\}. \tag{9.27}$$

概率模型指定分布 \(P(\psi|\theta)\)（常常退化为 \(P(\psi)\)）。设把 \(h\) 的定义域限制在某个固定的 \(\theta\) 上时，它是从 \(\Psi\) 到 \(Y\) 的单射——换句话说，\(\theta\) 固定时每个自然观测动作导致唯一的观测。利用 \(P(\psi)\) 和 \(h\)，\(P(y|\theta)\) 由下式导出：

$$P(y\,|\,\theta) = \begin{cases} P(\psi|\theta) & \text{对唯一满足 } y = h(\theta,\psi) \text{ 的 } \psi,\\ 0 & \text{若不存在这样的 }\psi.\end{cases} \tag{9.28}$$

去掉单射假设时，\(P(\psi|\theta)\) 换成对所有满足 \(y=h(\theta,\psi)\) 的 \(\psi\) 求和。在 Formulation 9.6 中，非确定性模型与概率模型的唯一区别就是对 \(\psi\) 的刻画，它代表一种测量干扰。策略仍然形如 \(\pi : Y\to U\)5。甚至可以用混合模型：一种自然动作按非确定性建模，另一种按概率建模。

接收多个观测

Formulation 9.5 的另一个扩展是在决策前接收多个观测 \(y_1,y_2,\ldots,y_n\)，每个 \(y_i\) 属于观测空间 \(Y_i\)。策略 \(\pi\) 现在依赖于所有观测：

$$\pi : Y_1\times Y_2\times\cdots\times Y_n\to U. \tag{9.29}$$

非确定性模型对每个 \(i\) 和 \(\theta\) 指定 \(Y_i(\theta)\)，把 (9.24) 中的 \(\Theta(y)\) 换成

$$\Theta(y_1)\cap\Theta(y_2)\cap\cdots\cap\Theta(y_n), \tag{9.30}$$

得到最优动作 \(\pi^*(y_1,\ldots,y_n)\)。概率模型改为指定 \(P(y_i|\theta)\)。通常假设各观测在给定 \(\theta\) 时条件独立：对任意 \(y_i\)、\(\theta\)、\(y_j\)（\(i\ne j\)），\(P(y_i|\theta,y_j) = P(y_i|\theta)\)。(9.26) 中的 \(P(\theta|y)\) 换成 \(P(\theta|y_1,\ldots,y_n)\)；利用贝叶斯规则和条件独立，

$$P(\theta\,|\,y_1,\ldots,y_n) = \frac{P(y_1|\theta)P(y_2|\theta)\cdots P(y_n|\theta)P(\theta)}{P(y_1,\ldots,y_n)}. \tag{9.31}$$

分母可以看作不影响优化的常数，所以除非还需要最优期望代价，否则不必显式计算。条件独立让我们不必完整指定 \(P(y|\theta)\)，是一个巨大的简化；有时即使条件独立并不成立，也会为了这个简化而假设它。使用观测条件独立的方法常被称为朴素贝叶斯 naive Bayes。

9.2.4 最优决策的例子 Examples of Optimal Decision Making

到这里给出的框架刻画了统计决策论 statistical decision theory，它涵盖了广泛的应用和研究问题：几乎任何需要自动做决策的情境（由机器或按规则办事的人来做）都可以用这些概念。第 10–12 章会把这个决策问题反复嵌进复杂的规划问题：规划被看成一个反复修改状态空间中状态的序贯决策过程。通常每一步决策都比常见的决策论应用简单，因为规划问题还被许多其它因素复杂化——如果某个应用的单步决策已经太难解，那么扩展到规划就没什么希望了。尽管如此，认识到在这一框架下建模、求解决策问题时一般会遇到的挑战仍然重要。下面的例子展示了它的威力与范围。

模式分类 pattern classification

过去几十年，计算机视觉和机器学习中一个活跃的领域是模式分类：用一组数据做分类。例如在计算机视觉里，数据对应从图像中提取的信息，是视觉系统用来给物体分类的观测特征（比如「我在看一碗越南米粉」）。这里给出的是模式分类的一个高度理想化的版本：假设所有模型细节（包括所需的概率分布）都已经有了。有些情境中可以通过在大数据集上收集统计得到它们；但在许多应用中，获取这些数据昂贵或不可行，必须在缺乏好信息的情况下发展分类技术。有些问题甚至是无监督 unsupervised 的——连可能的类别都要自动发现。因此模式分类仍是一个有挑战的研究领域。

一般模型是：自然先确定类别，然后得到关于类别的观测，最后机器人的动作试图根据观测猜出正确的类别。这正符合 Formulation 9.5。令 \(\Theta\) 为有限的类别集合；机器人要猜类别，所以 \(U=\Theta\)。用一个简单的代价函数衡量 \(u\) 与 \(\theta\) 的不符：

$$L(u,\theta) = \begin{cases} 0 & \text{若 } u = \theta\ \text{（分类正确）}\\ 1 & \text{若 } u \ne \theta\ \text{（分类错误）。}\end{cases} \tag{9.32}$$

非确定性模型下，只要动作 \(u\) 可能分错，代价就是 1；概率模型下，(9.32) 的期望就是动作 \(u\) 分错的概率。用于做分类决策的信息构成特征空间 feature space \(Y\)，每个 \(y\in Y\) 称为一个特征或特征向量（常常 \(y\in\mathbb{R}^n\)）——在这里它不过是 Formulation 9.5 中的观测。最好的分类器 classifier（分类规则）就是一个策略 \(\pi : Y\to U\)，它按所选模型在最坏情况或期望意义下给出最小的分类错误。

贝叶斯分类器 Bayesian classifier：模式分类中最常见的是概率方法，得到贝叶斯分类器。这里假设给定了 \(P(y|\theta)\) 和 \(P(\theta)\)：\(P(y|\theta)\) 描述每个类别的特征分布，\(P(\theta)\) 描述各类别总体出现的频率。如果有大量预先分好类的数据，这些分布可以可靠地学到。特征空间常常是连续的，得到密度 \(p(y|\theta)\)，而 \(P(\theta)\) 仍是离散分布。最优分类器 \(\pi^*\) 按 (9.26) 设计：收到特征向量 \(y\) 后宣布类别 \(u=\pi^*(y)\)；用 (9.32) 时，期望代价就是错误率。

例 9.11（光学字符识别 OCR）：设相机拍下一页文字的数字图像，先做分割确定每个字母的位置，然后要把每个字母正确分类。令 \(\Theta=\{A,B,C,D,E,F,G,H\}\)（实际中应包括整个字母表）。设有三种图像处理算法：

参数估计 parameter estimation

本节框架的另一个重要应用是参数估计。这里自然选一个参数 \(\theta\in\Theta\)，\(\Theta\) 是参数空间。经过一次或多次独立试验得到一些观测；理想情况下每个观测都是 \(\Theta\) 的直接测量，但测量过程的缺陷会扭曲观测。通常 \(\Theta\subseteq Y\)，很多时候 \(Y=\Theta\)。机器人的动作是猜自然选的参数，所以 \(U=\Theta\)。大多数应用中这些空间都是 \(\mathbb{R}^n\) 的连续子集；代价函数随误差 \(\|u-\theta\|\) 增大而增大。

例 9.12（参数估计）：设 \(U=Y=\Theta=\mathbb{R}\)。自然选一个实数参数，机器人去估计它；犯错的代价是

$$L(u,\theta) = (u-\theta)^2. \tag{9.35}$$

采用贝叶斯方法。先验密度 \(p(\theta)\) 在区间 \([a,b]\subset\mathbb{R}\) 上均匀。收到一个有噪声的观测；噪声可以按 9.2.3 节那样建模为自然的第二个动作，得到密度 \(p(y|\theta)\)。设噪声是高斯的：

$$p(y\,|\,\theta) = \frac{1}{\sqrt{2\pi\sigma^2}}\,e^{-(y-\theta)^2/2\sigma^2}, \tag{9.36}$$

均值为 \(\theta\)、标准差为 \(\sigma\)。基于 \(y\) 的最优参数估计选 \(u\in\mathbb{R}\) 使下式最小：

$$\int_{-\infty}^{\infty} L(u,\theta)\,p(\theta|y)\,d\theta, \tag{9.37}$$

其中由贝叶斯规则

$$p(\theta\,|\,y) = \frac{p(y|\theta)p(\theta)}{p(y)}. \tag{9.38}$$

\(p(y)\) 不依赖 \(\theta\)，在优化中可以忽略。先验在 \([a,b]\) 外为 0，所以积分域可以限制在 \([a,b]\) 上；\(p(\theta)=1/(b-a)\) 也是常数，也可以忽略。于是 \(u\) 的选取是优化

$$\int_a^b L(u,\theta)\,p(y|\theta)\,d\theta, \tag{9.39}$$

它可以用标准误差函数 \(\mathrm{erf}(x)\)（高斯密度在一个区间上的积分）表示。若得到一列独立观测 \(y_1,\ldots,y_k\)，(9.39) 换成

$$\int_a^b L(u,\theta)\,p(y_1|\theta)\cdots p(y_k|\theta)\,d\theta. \tag{9.40}$$
补充：平方损失下的最优估计是后验均值

把 (9.37) 对 \(u\) 展开：\(\int(u-\theta)^2p(\theta|y)\,d\theta = \mathrm{Var}(\theta\,|\,y) + \big(u - E[\theta\,|\,y]\big)^2\)。第一项与 \(u\) 无关，所以 \(u^* = E[\theta|y]\)，最小期望代价就是后验方差。对例 9.12，后验是截断在 \([a,b]\) 上的正态分布，\(u^*\) 就是截断正态的均值；观测靠近边界时它会被「拉回」区间内部。

9.3 二人零和博弈 Two-Player Zero-Sum Games

9.2 节只有一个真正的 DM——机器人——它在和一个虚构的 DM「自然」对弈。现在设第二个 DM 是一个聪明的对手，它做决策的方式和机器人一样。这导致一种对称的局面：两个 DM 同时做决策，都不知道对方会怎么行动。本节假设两个 DM 的利益完全对立：一方的损失就是另一方的收益。这就是博弈论最基本的形式，称为零和博弈 zero-sum game。

9.3.1 博弈的表述 Game Formulation

两个玩家 \(\mathrm{P}_1\)、\(\mathrm{P}_2\) 各做一个决策，各有有限的动作集合 \(U\) 和 \(V\)。\(V\) 可以看作 Formulation 9.3 中 \(\Theta\) 的「替代品」——由真正的对手而不是自然选择。每个玩家有一个代价函数 \(L_i : U\times V\to\mathbb{R}\)（\(i=1,2\)）。零和博弈的一个重要约束是

$$L_1(u,v) = -L_2(u,v), \tag{9.41}$$

即一方的代价就是另一方的回报——这正是「零和」一词的来源：两个代价加起来是零。零和博弈中玩家的利益完全对立；9.4 节会去掉这个约束。由 (9.41)，没必要表示两个代价函数：下标省掉，\(L\) 指 \(\mathrm{P}_1\) 的代价 \(L_1\)。\(\mathrm{P}_1\) 的目标是最小化 \(L\)；由 (9.41)，\(\mathrm{P}_2\) 的目标是最大化 \(L\)。所以 \(L\) 对 \(\mathrm{P}_2\) 是回报，对 \(\mathrm{P}_1\) 是代价。

Formulation 9.7（零和博弈 A Zero-Sum Game）
  1. 两个玩家 \(\mathrm{P}_1\)、\(\mathrm{P}_2\)。
  2. 非空有限集合 \(U\)，称为 \(\mathrm{P}_1\) 的动作空间。为方便举例，设 \(U\) 是从 1 到 \(|U|\) 的连续整数。每个 \(u\in U\) 称为 \(\mathrm{P}_1\) 的一个动作。
  3. 非空有限集合 \(V\)，称为 \(\mathrm{P}_2\) 的动作空间；设 \(V\) 是从 1 到 \(|V|\) 的连续整数。每个 \(v\in V\) 称为 \(\mathrm{P}_2\) 的一个动作。
  4. 函数 \(L : U\times V\to\mathbb{R}\cup\{-\infty,\infty\}\)，称为 \(\mathrm{P}_1\) 的代价函数；由 (9.41) 它也是 \(\mathrm{P}_2\) 的回报函数。

讨论「求解」零和博弈之前还需要一些假设。假设玩家知道彼此的代价函数——对手的动机被完全理解。另一个假设是玩家是理性的 rational：只要可能就会设法得到最好的代价；有更低代价的动作可选时，\(\mathrm{P}_1\) 不会选代价更高的，\(\mathrm{P}_2\) 也不会选让代价更低的动作。最后，假设双方同时做决策，没有任何关于对方决策的信息可以被利用。

9.3.2 确定性策略 Deterministic Strategies

什么是 Formulation 9.7 的好解？从 \(\mathrm{P}_1\) 的角度看，为了对付 \(\mathrm{P}_2\) 会采取的动作，用最坏情况分析似乎很合理——等于假设 \(\mathrm{P}_2\) 是 9.2.2 节非确定性模型下的自然。对矩阵博弈，先求每一行的最大代价，再选最大代价最小的那一行，这是 \(\mathrm{P}_1\) 能为自己保证的最低代价。这个选择称为 \(\mathrm{P}_1\) 的安全策略 security strategy。对 (9.42)，行最大分别是 3、2、2（式 9.43），\(u=2\) 和 \(u=3\) 都是最好的动作：无论 \(\mathrm{P}_2\) 选什么，代价都不超过 2。形式化地，

$$u^* = \operatorname*{argmin}_{u\in U}\Big\{\max_{v\in V}\Big\{L(u,v)\Big\}\Big\}. \tag{9.44}$$

可能有多个安全策略满足 argmin，这不会造成麻烦（马上解释）。把得到的最坏代价记为 \(\overline{L}^*\)，称为博弈的上值 upper value：

$$\overline{L}^* = \max_{v\in V}\Big\{L(u^*,v)\Big\}. \tag{9.45}$$

现在换位，从想最大化 \(L\) 的 \(\mathrm{P}_2\) 的角度看。它也可以用最坏情况分析：选一个动作，保证即使 \(\mathrm{P}_1\) 想把代价压低，也能得到较高的代价。\(\mathrm{P}_2\) 的安全策略 \(v^*\) 定义为

$$v^* = \operatorname*{argmax}_{v\in V}\Big\{\min_{u\in U}\Big\{L(u,v)\Big\}\Big\}. \tag{9.46}$$

注意它和 (9.44) 的对称性——\(\mathrm{P}_2\) 的安全策略不过是 9.2.2 节最坏情况分析的「倒过来」版本。下值 lower value \(\underline{L}^*\) 定义为

$$\underline{L}^* = \min_{u\in U}\Big\{L(u,v^*)\Big\}. \tag{9.47}$$

回到 (9.42)：列最小分别是 −2、−1、0、1（式 9.48），按 (9.46) 选最后一列 \(v^*=4\)。上值与下值之间有一个有趣的关系：对 Formulation 9.7 的任何博弈都有 \(\underline{L}^*\le\overline{L}^*\)，因为

$$\underline{L}^* = \min_{u\in U}\Big\{L(u,v^*)\Big\} \le L(u^*,v^*) \le \max_{v\in V}\Big\{L(u^*,v)\Big\} = \overline{L}^*, \tag{9.49}$$

其中 \(L(u^*,v^*)\) 是双方各用安全策略时得到的代价。如果博弈由理性的 DM 来玩，结果代价总落在 \(\underline{L}^*\) 与 \(\overline{L}^*\) 之间。

遗憾

设双方都用安全策略 \(u^*=2\)、\(v^*=4\)，代价 \(L(2,4)=1\)。结果出来后双方感觉如何？\(\mathrm{P}_1\) 可能很满意：既然 \(\mathrm{P}_2\) 选了 \(v^*=4\)，它已经得到了可能的最低代价。\(\mathrm{P}_2\) 却可能对自己的决策感到后悔：如果早知道 \(\mathrm{P}_1\) 会选 \(u=2\)，它本可以选 \(v=3\) 得到 \(L(2,3)=2\)，比 \(L(2,4)=1\) 好7。如果博弈重复进行，\(\mathrm{P}_2\) 会想改变策略，希望骗 \(\mathrm{P}_1\) 给它更高的回报。

有没有办法让双方都满意？只要 \(\underline{L}^*\) 与 \(\overline{L}^*\) 之间有缺口，就有一方或双方有遗憾。若 \(r_1\)、\(r_2\) 分别是 \(\mathrm{P}_1\)、\(\mathrm{P}_2\) 的遗憾，则总遗憾为

$$r_1 + r_2 = \overline{L}^* - \underline{L}^*. \tag{9.50}$$

所以让双方都满意的唯一办法是 \(\underline{L}^*=\overline{L}^*\)。但这是博弈本身的性质，不由玩家决定。有些博弈两者相等，但很多博弈 \(\underline{L}^* < \overline{L}^*\)。幸运的是，用随机化策略后上值与下值总会重合（9.3.3 节）。

鞍点 saddle points

若 \(\underline{L}^*=\overline{L}^*\)，双方的安全策略称为一个鞍点 saddle point，\(L^*=\underline{L}^*=\overline{L}^*\) 称为博弈的值 value。此时 max 与 min 的顺序可以交换而不改变值：

$$L^* = \min_{u\in U}\Big\{\max_{v\in V}\Big\{L(u,v)\Big\}\Big\} = \max_{v\in V}\Big\{\min_{u\in U}\Big\{L(u,v)\Big\}\Big\}. \tag{9.51}$$

鞍点有时也叫均衡 equilibrium，因为玩家没有改变选择的动机（没有遗憾）。鞍点就是满足下式的任意 \(u^*\in U\)、\(v^*\in V\)：

$$L(u^*,v) \le L(u^*,v^*) \le L(u,v^*) \tag{9.52}$$

对所有 \(u\in U\)、\(v\in V\) 成立。注意 \(L^*=L(u^*,v^*)\)。在矩阵里找鞍点，就是找图 9.2 那种简单的图案。

9.3.3 随机化策略 Randomized Strategies

有些零和博弈没有鞍点，这令人失望，因为那时遗憾无法避免。稍微改一下规则：同一个博弈由 \(\mathrm{P}_1\)、\(\mathrm{P}_2\) 反复玩很多次。如果用确定性策略，它们每次都选同样的动作，得到同样的代价；也可以在几个安全策略之间切换，这会让代价波动。如果双方都执行随机化策略会怎样？用 9.1.3 节的想法，每个策略是动作上的一个概率分布；博弈次数趋于无穷时，得到一个期望代价。博弈论最著名的结果之一是：在随机化策略的空间上，任何零和矩阵博弈都存在鞍点——不过要用期望代价。所以使用随机化后就没有遗憾了：单次试验中仍可能后悔，但对所有试验取平均后，双方都会满意。

扩展表述

Formulation 9.7 的博弈可以优雅地写成矩阵，所以很自然地用线性代数来表示期望代价。令 \(|U|=m\)、\(|V|=n\)。和 9.1.3 节一样，\(\mathrm{P}_1\) 的随机化策略可以表示为一个 \(m\) 维向量

$$w = [w_1\ \ w_2\ \ \ldots\ \ w_m]. \tag{9.55}$$

它必须满足 9.1.2 节的概率公理：对所有 \(i\) 有 \(w_i\ge0\)，且 \(w_1+\cdots+w_m=1\)。把 \(w\) 看成 \(\mathbb{R}^m\) 中的点，这两个约束说明它位于一个 \((m-1)\) 维单纯形上（回忆 6.3.1 节）。\(m=3\) 时 \(w\) 落在 \(\mathbb{R}^3\) 的一个三角形子集里。同样，用 \(n\) 维向量表示 \(\mathrm{P}_2\) 的随机化策略

$$z = [z_1\ \ z_2\ \ \ldots\ \ z_n]^T, \tag{9.56}$$

它也满足概率公理；转置 \(T\) 让它成为列向量，满足后面矩阵乘法的维数要求。令 \(\bar L(w,z)\) 表示 \(\mathrm{P}_1\) 用 \(w\)、\(\mathrm{P}_2\) 用 \(z\) 时的期望代价：

$$\bar L(w,z) = \sum_{i=1}^{m}\sum_{j=1}^{n} L(i,j)\,w_i z_j. \tag{9.57}$$

这里 \(L(i,j)\) 用到了 Formulation 9.7 中「动作是连续整数」的假设。期望代价也可以用代价矩阵 \(A\) 表示：

$$\bar L(w,z) = wAz, \tag{9.58}$$

乘积 \(wAz\) 是一个标量，恰好等于 (9.57)。先看 \(Az\)：它是一个 \(m\) 维向量，第 \(i\) 个元素是 \(\mathrm{P}_1\) 试 \(u=i\) 时会得到的期望代价——看起来 \(\mathrm{P}_1\) 把 \(\mathrm{P}_2\) 当成了概率模型下的自然。再乘上 \(w\)，按 \(w\) 的概率对 \(Az\) 中的代价取平均。

令 \(W\)、\(Z\) 分别为 \(\mathrm{P}_1\)、\(\mathrm{P}_2\) 的所有随机化策略的集合。它们包含了与 9.3.2 节确定性策略等价的策略（把概率 1 放在一个动作上），所以是确定性情形下可选策略集合的扩展。用 \(W\)、\(Z\) 定义 \(\mathrm{P}_1\)、\(\mathrm{P}_2\) 的随机化安全策略：

$$w^* = \operatorname*{argmin}_{w\in W}\Big\{\max_{z\in Z}\Big\{\bar L(w,z)\Big\}\Big\} \tag{9.59}$$
$$z^* = \operatorname*{argmax}_{z\in Z}\Big\{\min_{w\in W}\Big\{\bar L(w,z)\Big\}\Big\}. \tag{9.60}$$

与 (9.44)、(9.46) 相比，差别在于策略空间扩大了，并且用的是期望代价。随机化上值与随机化下值分别定义为

$$\overline{\mathcal{L}}^* = \max_{z\in Z}\Big\{\bar L(w^*,z)\Big\}, \tag{9.61}$$
$$\underline{\mathcal{L}}^* = \min_{w\in W}\Big\{\bar L(w,z^*)\Big\}. \tag{9.62}$$

\(W\)、\(Z\) 包含确定性的安全策略，所以 \(\overline{\mathcal{L}}^*\le\overline{L}^*\)、\(\underline{\mathcal{L}}^*\ge\underline{L}^*\)：随机化安全策略总有希望缩小两个值之间的缺口。

零和博弈论最基本的结果由 von Neumann 证明：对 Formulation 9.7 的任何博弈都有 \(\underline{\mathcal{L}}^*=\overline{\mathcal{L}}^*\)。这给出博弈的随机化值 \(\mathcal{L}^*=\underline{\mathcal{L}}^*=\overline{\mathcal{L}}^*\)。这意味着只要玩家坚持用安全策略，就永远不会有期望遗憾；双方都用随机化安全策略时，得到的是一个随机化鞍点。它不能像矩阵 \(A\) 中的简单图案那样被看出来，因为它存在于 \(W\) 和 \(Z\) 上。随机化鞍点的保证存在很重要，它说明了与有智能的对手做决策时随机化的价值。例 9.7 中我们直观地论证过，随机化在对抗聪明的对手时似乎有帮助：用确定性策略反复玩时，对方可以学会你的策略、每次都赢；一旦用随机化策略，玩家就不会有遗憾。

计算随机化鞍点

已经知道随机化鞍点总存在，但怎么找？两个关键观察使问题可以用组合方法求解：

  1. 每个玩家的安全策略都可以只考虑对手的确定性策略来求。
  2. 如果另一个玩家的策略固定，期望代价是未定概率的线性函数。

先考虑求 \(\mathrm{P}_1\) 的安全策略。第一个观察说明 (9.59) 不必考虑 \(\mathrm{P}_2\) 的随机化策略。在 argmin 内部 \(w\) 是固定的，哪个随机化策略 \(z\in Z\) 使 \(\bar L(w,z)=wAz\) 最大？\(w\) 固定时 \(wA\) 可以看作常数 \(n\) 维向量 \(s\)，于是 \(\bar L(w,z)=s\cdot z\)（点积）。任务变成选 \(z\) 使 \(s\cdot z\) 最大：只要找到 \(s\) 的最大元素 \(s_i\)，把全部概率质量放在动作 \(i\) 上即可。于是 \(z_i=1\)、其余 \(z_j=0\)（\(i\ne j\)）的策略给出最高代价，而且它是确定性的。由第一个观察，对每个 \(w\in W\) 只需考虑 \(\mathrm{P}_2\) 的 \(n\) 个可能回应——\(n\) 个确定性策略，每个对某个 \(i\in\{1,\ldots,n\}\) 令 \(z_i=1\)。

再看第二个观察。\(z\) 固定时期望代价 \(\bar L(w,z)=wAz\) 是 \(w\) 的线性函数。\(z\) 只需固定在 \(n\) 个不同的值上，所以 \(w\) 取在 \(n\) 个线性函数的最大值最小的地方——这是这组线性函数的上包络 upper envelope 的最小值（6.5.2 节提到过这种包络）。例 9.16 会演示。这个优化的定义域可以方便地取成 \(\mathbb{R}^{m-1}\) 中的三角形：虽然 \(W\subset\mathbb{R}^m\)，但最后一个坐标 \(w_m\) 不需要，因为总有 \(w_m=1-(w_1+\cdots+w_{m-1})\)。得到的优化属于线性规划 linear programming，有许多组合算法。

上面的解释对 \(\mathrm{P}_1\) 并没有什么特殊之处，同样的方法可以求 \(\mathrm{P}_2\) 的安全策略，只是每个最小化换成最大化、反之亦然。总之，(9.60) 中的 min 只需考虑 \(W\) 中的确定性策略；\(w\) 固定后 \(\bar L(w,z)=wAz\) 又是 \(z\) 的线性函数，最好的随机化动作是在 \(m\) 个线性函数中使最小值最大的点 \(z\in Z\)——这些线性函数的下包络 lower envelope 的最大值。优化在 \(\mathbb{R}^{n-1}\) 上进行，最后一个坐标 \(z_n=1-(z_1+\cdots+z_{n-1})\)。

9.4 非零和博弈 Nonzero-Sum Games

这一节平行于 9.3 节，只是考虑更一般的非零和博弈。这样可以对任意程度的冲突建模；有些决策甚至可能让所有玩家都受益。这门学问的主要应用之一在经济学，用来解释相互竞争的企业的行为。鞍点解被 Nash 均衡 Nash equilibrium 取代，它同样基于消除遗憾。由于玩家不一定彼此对立，可以对任意多个玩家建模。非零和博弈出现了新困难：Nash 均衡不唯一，而且随机化 Nash 均衡的计算一般不能纳入线性规划。

9.4.1 二人博弈 Two-Player Games

为了与 9.3 节衔接得更顺，先考虑二人博弈；记号更简单，也更好理解。这些想法可以毫无困难地推广到多个玩家。

Formulation 9.8（二人非零和博弈 A Two-Player Nonzero-Sum Game）
  1. 除代价函数外，组成部分与 Formulation 9.7 相同。
  2. 函数 \(L_1 : U\times V\to\mathbb{R}\cup\{\infty\}\)，称为 \(\mathrm{P}_1\) 的代价函数。
  3. 函数 \(L_2 : U\times V\to\mathbb{R}\cup\{\infty\}\)，称为 \(\mathrm{P}_2\) 的代价函数。

与 Formulation 9.7 的唯一区别是现在有两个独立的代价函数，每个玩家一个，每个玩家都想最小化自己的代价。这里没有最大化——那只在 \(\mathrm{P}_2\) 与 \(\mathrm{P}_1\) 利益对立的零和博弈中出现。令 \(L_1=L\)、\(L_2=-L\)，零和博弈就成了 Formulation 9.8 的特例。

仿照 9.3 节，先考虑用确定性策略求解。和之前一样，玩家可以用自己的安全策略——为此它甚至不需要看另一个玩家的代价函数。但做决策时完全不考虑两个代价函数似乎不妥；多数情况下安全策略会导致遗憾，所以不适合非零和博弈。

下面给出一个避免遗憾的策略。一对动作 \((u^*,v^*)\) 称为 Nash 均衡，如果

$$L_1(u^*,v^*) = \min_{u\in U}\Big\{L_1(u,v^*)\Big\} \tag{9.66}$$
$$L_2(u^*,v^*) = \min_{v\in V}\Big\{L_2(u^*,v)\Big\}. \tag{9.67}$$

这两个式子意味着 \(\mathrm{P}_1\)、\(\mathrm{P}_2\) 都没有遗憾。(9.66) 说明给定 \(\mathrm{P}_2\) 选的 \(v^*\)，\(\mathrm{P}_1\) 对自己的动作 \(u^*\) 满意——改动作也不能进一步降低代价；(9.67) 说明 \(\mathrm{P}_2\) 对 \(v^*\) 满意。

Formulation 9.8 的博弈可以用两个代价矩阵完整表示：\(A\)、\(B\) 分别是 \(\mathrm{P}_1\)、\(\mathrm{P}_2\) 的代价矩阵。回忆图 9.2 检测鞍点的图案；Nash 均衡可以按图 9.5 检测（见上面 9.3.2 节的图）：找某个 \((i,j)\)，使 \(L_a^*=L_1(i,j)\) 是 \(A\) 第 \(j\) 列中最小的元素，且 \(L_b^*=L_2(i,j)\) 是 \(B\) 第 \(i\) 行中最小的元素。想想两者的关系：若 \(A=-B\)，把 \(B\) 取负后叠在 \(A\) 上，就得到图 9.2 的图案（取负使 ≥ 变成 ≤），\(L_a^*\) 与 \(L_b^*\) 重合。这说明 \(A=-B\) 时 Nash 均衡和鞍点其实是同一个概念；但 Nash 均衡适用于一般得多的博弈。

处理多个 Nash 均衡

例 9.17 有点令人沮丧，因为存在多个 Nash 均衡。一般可以有任意多个均衡。每个玩家怎么知道该玩哪一个？如果两人各选了不同的均衡，它们不保证落到另一个均衡上（零和博弈的鞍点则有这个保证）。许多均衡可以用 Pareto 最优（9.1.1 节、7.7.2 节）排除：把选择写成多目标优化问题，套进 Formulation 9.2。考虑二维向量 \((x_i,y_i)\)，\(x\)、\(y\) 是 Nash 均衡 \(\pi_i\) 下的代价 \(L_1\)、\(L_2\)。对两个不同的均衡 \(\pi_1\)、\(\pi_2\)，得到代价向量 \((x_1,y_1)\)、\((x_2,y_2)\)；例 9.17 中它们是 \((1,2)\) 和 \((-1,0)\)。一般地，若 \(x_1\le x_2\)、\(y_1\le y_2\) 且至少一个不等式严格，就说 \(\pi_1\) 好于 \(\pi_2\)。例 9.17 中产生 \((-1,0)\) 的均衡显然好于产生 \((1,2)\) 的，因为双方都受益。

「好于」在 Nash 均衡空间上诱导一个偏序。它只是偏序，因为有些向量不可比：例如 \((-1,1)\) 和 \((1,-1)\)，前者 \(\mathrm{P}_1\) 更喜欢，后者 \(\mathrm{P}_2\) 更喜欢。博弈论中关于这个偏序极小的 Nash 均衡称为可容许的 admissible，也可以叫 Pareto 最优。

最好的情况是博弈只有一个 Nash 均衡。如果有多个，还可以指望其中只有一个是可容许的；这时理性的玩家应该足够聪明，能想到非可容许的均衡应该被丢掉。可惜很多博弈有多个可容许的 Nash 均衡。这时分析表明，玩家必须以某种方式沟通或合作来消除遗憾的可能，否则最坏情况下遗憾不可避免。也可能根本没有 Nash 均衡；幸运的是，允许随机化策略后，随机化 Nash 均衡总是存在的——在下面两个例子之后讨论。

例 9.18（性别之战 The Battle of the Sexes）：

(L₁, L₂)v=1v=2
u=1−2,−10,0
u=20,0−1,−2

(9.69)

这是有名的「性别之战」。一男一女是一对，对晚上怎么过各有偏好：男方想去购物，女方想看一场足球赛。博弈就是在这两个活动中选一个。对任何一方，最好的情况是做自己喜欢的事、同时两人在一起；最坏的情况是各做各的，两人分开。这个博弈有点不现实，因为大多数情况下两人之间是会合作的。\(u=v=1\) 和 \(u=v=2\) 都是 Nash 均衡，代价向量分别是 \((-2,-1)\) 和 \((-1,-2)\)。两个解谁也不比谁好，所以都是可容许的。除非两人合作，否则无法避免遗憾的可能（「这你大概早就知道了」）。

下面是最有名的非零和博弈之一。例 9.19（囚徒困境 The Prisoner's Dilemma）：这个博弈表述非常简单，却展示了许多有趣的问题。设两个人犯了一桩重罪。当局知道他们有罪，但证据不足以定罪。于是当局设计了一个圈套：每个嫌疑人（玩家）被关在单独的牢房里，有两个选择——与当局合作（\(u=1\) 或 \(v=1\)），或拒绝（\(u=2\) 或 \(v=2\)）。合作意味着认罪并交出能指证对方的证据；拒绝意味着声称无辜、拒绝帮助当局。代价 \(L_i\) 表示该玩家要被判的年数：

(L₁, L₂)v=1 合作v=2 拒绝
u=1 合作8,80,30
u=2 拒绝30,02,2

(9.70)

设计思路是：双方都合作则各判 8 年——这是罪行被定罪、又因合作而减刑后的刑期。双方都拒绝则各判 2 年，因为当局证据不足以判更久。有意思的是一人拒绝、一人合作：拒绝的人麻烦大了，对方提供的证据会被用来对付他；合作的人可以免罪（代价 0），而另一个人被定罪、坐 30 年牢。

玩家该怎么做？如果能协调决策，双方都拒绝似乎是个好选择，代价 \((2,2)\)。但这时会有遗憾：每个人都会想，自己本可以通过合作而免罪（代价 0）。如果再玩一次，他们可能会想改变决策。这个问题的 Nash 均衡是双方都合作，得到 \((8,8)\)。所以他们为无法沟通、协调策略付出了代价。这个解同时也是玩家的安全策略，因为它在最坏情况分析下代价最低。（注意：本书的「合作」指与当局合作，即坦白；许多教材从两名囚徒的角度称之为「背叛 defect」。）

随机化 Nash 均衡

如果一个博弈在确定性策略空间上没有 Nash 均衡怎么办？同样可以把策略空间扩大到随机化策略来缓解。9.3.3 节说明了 Formulation 9.7 的每个零和博弈都在随机化策略空间上有随机化鞍点；Nash 证明了 Formulation 9.8 的每个非零和博弈都有随机化 Nash 均衡。这是个好结果，但有两点顾虑：仍可能有多个可容许的均衡，所以除非玩家合作，否则没有可靠的办法避免遗憾；另一个顾虑是随机化 Nash 均衡不能用 9.3.3 节的线性规划方法计算，需要的优化是一种非线性规划，未必有好的组合解法。

回忆 9.3.3 节随机化策略的定义。对一对随机化策略 \((w,z)\)，期望代价 \(\bar L^1(w,z)\)、\(\bar L^2(w,z)\) 可以用 (9.57) 计算。一对策略 \((w^*,z^*)\) 称为随机化 Nash 均衡，如果

$$\bar L^1(w^*,z^*) = \min_{w\in W}\Big\{\bar L^1(w,z^*)\Big\} \tag{9.71}$$
$$\bar L^2(w^*,z^*) = \min_{z\in Z}\Big\{\bar L^2(w^*,z)\Big\}. \tag{9.72}$$

博弈论文献中通常叫混合 Nash 均衡 mixed Nash equilibrium。(9.71)、(9.72) 只是把 (9.66)、(9.67) 从确定性策略空间推广到随机化策略空间。用代价矩阵 \(A\)、\(B\)，Nash 均衡条件可以写成

$$w^*Az^* = \min_{w\in W}\Big\{wAz^*\Big\} \tag{9.73}$$
$$w^*Bz^* = \min_{z\in Z}\Big\{w^*Bz\Big\}. \tag{9.74}$$

可惜随机化 Nash 均衡的计算比鞍点难得多。主要困难是 Nash 均衡不一定是安全策略。用安全策略时，可以把玩家的决策解耦成两个独立的线性规划问题（例 9.16）；对随机化 Nash 均衡，玩家之间的优化仍然耦合在一起。得到的优化常被称为线性互补问题 linear complementarity problem，可以写成非线性规划问题——同时带有等式和不等式约束的非线性优化（在这个特例中得到一个双线性规划 bilinear programming 问题）。

例 9.20（求随机化 Nash 均衡）：为了体会需要什么样的优化，回到例 9.18。可以找到一个不同于两个确定性均衡的随机化 Nash 均衡。用例 9.18 的代价矩阵，给定随机化策略 \(w\)、\(z\) 时 \(\mathrm{P}_1\) 的期望代价是

$$\begin{aligned}\bar L^1(w,z) &= wAz = \begin{pmatrix}w_1 & w_2\end{pmatrix}\begin{pmatrix}-2&0\\0&-1\end{pmatrix}\begin{pmatrix}z_1\\z_2\end{pmatrix}\\ &= -2w_1z_1 - w_2z_2\\ &= -3w_1z_1 + w_1 + z_1 - 1,\end{aligned} \tag{9.75}$$

最后一步用到 \(w_2=1-w_1\)、\(z_2=1-z_1\)。类似地，\(\mathrm{P}_2\) 的期望代价是

$$\begin{aligned}\bar L^2(w,z) &= wBz = \begin{pmatrix}w_1 & w_2\end{pmatrix}\begin{pmatrix}-1&0\\0&-2\end{pmatrix}\begin{pmatrix}z_1\\z_2\end{pmatrix}\\ &= -w_1z_1 - 2w_2z_2\\ &= -3w_1z_1 + 2w_1 + 2z_1 - 2.\end{aligned} \tag{9.76}$$

（这两个末行的常数项 −1、−2 原书漏掉了9；它们不影响下面的求导。）若 \(z\) 固定，(9.75) 的最后一个式子对 \(w\) 是线性的；若 \(w\) 固定，(9.76) 对 \(z\) 是线性的。求零和博弈的鞍点时可以利用这一点，但这里不行：必须选 \((w^*,z^*)\)，使 \(z=z^*\) 时 (9.75) 最优，同时 \(w=w^*\) 时 (9.76) 最优。

这个问题简单到可以用微积分求解。用经典的求导方法，可以通过计算

$$\frac{\partial\bar L^1(w_1,z_1)}{\partial w_1} = 1 - 3z_1 \tag{9.77}$$
$$\frac{\partial\bar L^2(w_1,z_1)}{\partial z_1} = 2 - 3w_1 \tag{9.78}$$

找到候选解。两者同时为 0 时出现极值：解 \(1-3z_1=0\)、\(2-3w_1=0\) 得 \((w^*,z^*)=(2/3,1/3)\)（即 \(w_1^*=2/3\)、\(z_1^*=1/3\)），这是一个随机化 Nash 均衡。确定性的 Nash 均衡用这个方法检测不到，因为它们出现在 \(W\)、\(Z\) 的边界上，那里导数没有定义。

例 9.20 的计算看起来不难，因为每个玩家只有两个动作，而且一半的矩阵元素是 0。一般要同时解两个复杂的方程。不过这些表达式总是二次多项式；而且只要 \(w\) 或 \(z\) 之一固定，它们就对另一组变量线性。

可能的解：小结

对 Formulation 9.8 的非零和博弈，要记住的几种可能：(1) 可能有多个可容许的（确定性）Nash 均衡；(2) 可能没有（确定性）Nash 均衡；(3) 总至少有一个随机化 Nash 均衡。

9.4.2 多于两个玩家 More Than Two Players

9.4.1 节的想法很容易推广到任意多个玩家。主要的困难是复杂的记号让概念显得更难；但要记住，没有本质区别。\(n\) 个玩家的非零和博弈表述如下：

Formulation 9.9（n 人非零和博弈 An n-Player Nonzero-Sum Game）
  1. \(n\) 个玩家的集合：\(\mathrm{P}_1,\mathrm{P}_2,\ldots,\mathrm{P}_n\)。
  2. 对每个玩家 \(\mathrm{P}_i\)，有限非空集合 \(U^i\)，称为 \(\mathrm{P}_i\) 的动作空间。为方便起见，设每个 \(U^i\) 是从 1 到 \(|U^i|\) 的连续整数。每个 \(u^i\in U^i\) 称为 \(\mathrm{P}_i\) 的一个动作。
  3. 对每个玩家 \(\mathrm{P}_i\)，函数 \(L_i : U^1\times U^2\times\cdots\times U^n\to\mathbb{R}\cup\{\infty\}\)，称为 \(\mathrm{P}_i\) 的代价函数。

矩阵表述不再可行，因为维数太多。例如 \(n=3\)、每人 \(|U^i|=2\) 时，\(L_i(u^1,u^2,u^3)\) 由一个 \(2\times2\times2\) 共 8 个元素的立方体给出，需要三个这样的立方体才能描述博弈。所以把 \(L_i\) 想成多元函数、避免用矩阵可能更有帮助（喜欢张量的话，可以用张量刻画 \(n\) 人的代价函数）。

Nash 均衡的想法推广为：给定其它 \(n-1\) 个玩家选的动作，每个 \(\mathrm{P}_i\) 都没有遗憾。形式化地，一组动作 \((u^{1*},\ldots,u^{n*})\) 称为（确定性）Nash 均衡，如果对每个 \(i\in\{1,\ldots,n\}\)：

$$L_i(u^{1*},\ldots,u^{i*},\ldots,u^{n*}) = \min_{u^i\in U^i}\Big\{L_i(u^{1*},\ldots,u^{(i-1)*},u^i,u^{(i+1)*},\ldots,u^{n*})\Big\}. \tag{9.79}$$

\(n>2\) 时，9.4.1 节末尾总结的每种情况都会出现：可能没有确定性 Nash 均衡，也可能有多个。可容许 Nash 均衡的定义推广为在 \(n\) 维代价向量上定义「好于」；关于所得偏序的极小向量仍称为可容许的（或 Pareto 最优的）。可惜仍可能有多个可容许的 Nash 均衡。

可以证明 Formulation 9.9 的任何博弈都有随机化 Nash 均衡。令 \(z^i\) 表示 \(\mathrm{P}_i\) 的随机化策略，每个 \(\mathrm{P}_i\) 的期望代价是

$$\bar L^i(z^1,z^2,\ldots,z^n) = \sum_{i_1=1}^{m_1}\sum_{i_2=1}^{m_2}\cdots\sum_{i_n=1}^{m_n} L_i(i_1,i_2,\ldots,i_n)\,z^1_{i_1}z^2_{i_2}\cdots z^n_{i_n}. \tag{9.80}$$

令 \(Z^i\) 为 \(\mathrm{P}_i\) 的随机化策略空间。一组随机化策略 \((z^{1*},\ldots,z^{n*})\) 称为随机化 Nash 均衡，如果对所有 \(i\in\{1,\ldots,n\}\)：

$$\bar L^i(z^{1*},\ldots,z^{i*},\ldots,z^{n*}) = \min_{z^i\in Z^i}\Big\{\bar L^i(z^{1*},\ldots,z^{(i-1)*},z^i,z^{(i+1)*},\ldots,z^{n*})\Big\}. \tag{9.81}$$

可以想见，\(n>2\) 时计算随机化 Nash 均衡比 \(n=2\) 更难。例 9.20 的方法可以推广到 \(n\) 人博弈，只是表达式更复杂：有 \(n\) 个方程，固定其余 \(n-1\) 个玩家的随机化策略后每个都是线性的。结果是一组 \(n\) 次多项式，要在其上同时解 \(n\) 个优化问题。

例 9.21（三人非零和博弈）：三个玩家 \(\mathrm{P}_1\)、\(\mathrm{P}_2\)、\(\mathrm{P}_3\) 各有两个动作 1、2。确定性策略由一个向量给出，例如 \((1,2,1)\) 表示 \(u^1=1\)、\(u^2=2\)、\(u^3=1\)。方便起见对每个 \(i,j,k\in\{1,2\}\) 令

$$L(i,j,k) = \big(L_1(i,j,k),\ L_2(i,j,k),\ L_3(i,j,k)\big), \tag{9.82}$$

代价为

$$\begin{aligned} L(1,1,1) &= (1,1,-2) & L(1,1,2) &= (-4,3,1)\\ L(1,2,1) &= (2,-4,2) & L(1,2,2) &= (-5,-5,10)\\ L(2,1,1) &= (3,-2,-1) & L(2,1,2) &= (-6,-6,12)\\ L(2,2,1) &= (2,2,-4) & L(2,2,2) &= (-2,3,-1). \end{aligned} \tag{9.83}$$

书中说有两个确定性 Nash 均衡，代价分别是 \((2,-4,2)\) 和 \((3,-2,-1)\)，并且两者都可容许，所以玩家之间需要一些合作才能确保没有遗憾。用 (9.79) 逐个验证会发现：\((1,2,1)\)（代价 \((2,-4,2)\)）确实是均衡；但 \((2,1,1)\)（代价 \((3,-2,-1)\)）不是——\(\mathrm{P}_1\) 单独改选 \(u^1=1\) 时代价从 3 降到 \(L_1(1,1,1)=1\)。按印出来的数据，纯 Nash 均衡只有一个10。

9.5 审视决策论 Decision Theory Under Scrutiny

本章引入了许多决策模型，它们为 Part III 的主题——不确定性下的规划——奠定了基础。在这个基础上构建规划模型之前，有必要批判性地评估它们在应用中是否合适。读 9.1–9.4 节时你可能已经有很多疑问：代价是怎么定的？为什么相信优化期望代价是对的？没有先验分布怎么办？最坏情况分析是不是太保守？能确信博弈中的玩家都具有假设的理性吗？玩家知道彼此的代价函数现实吗？本节试图对这些问题做些说明。「大楼只和它的地基一样牢固」：因误解决策论的局限而犯的错误，最终会渗进由它构建的规划表述里。

9.5.1 效用理论与理性 Utility Theory and Rationality

这一节为在 Formulation 9.3、9.4 下使用代价函数并最小化其期望值提供一些理由。这一框架叫效用理论 utility theory，通常用回报而不是代价来表述。如 9.1.1 节所说，代价乘以 −1、再把每个最大化换成最小化，就能变成回报。所以下面谈回报 \(R\)，直觉是回报越高越好。

比较回报

想象给决策过程的各种结果赋回报值。有些应用里数值自然而然：例如回报是一笔金融投资赚的钱；机器人应用中，可以把执行任务的时间或消耗的能量取负；回报也可以是移动机器人建完地图后剩余的电量。有些应用里回报的来源可能是主观的：洗碗的回报和扫地相比是多少？每个人都会给出不同的回报，甚至每天都不一样——取决于干活时的享受或痛苦、花的时间、别人怎么看等等。如果用决策论为一个人类「客户」自动化决策过程，最好仔细咨询客户，确保知道他们的偏好；这时也许可以先把偏好排序，再赋给与排序一致的回报。

回报赋好后，考虑在不涉及自然的 Formulation 9.1 下做决策：每个结果直接对应一个动作 \(u\in U\)。若回报由 \(R:U\to\mathbb{R}\) 给出，可以对每个 \(u\) 定义代价 \(L(u)=-R(u)\)，满足客户就是选 \(u\) 最小化 \(L\)。现在考虑与自然对弈：决策要比较结果上的概率分布。所有概率分布构成的空间可能极大，但用期望把每个分布（或密度）映成一个实数，问题就简化了。要关心的是：这种往实数上的投影，会不会无法反映客户真实的偏好。下面的例子说明这一点。

例 9.22（你喜欢赌博吗？）：设你有三个选择：(1) 拿 1000 欧元；(2) 抛一枚均匀硬币，正面得 2000 欧元，否则什么也没有；(3) 以 2/3 的概率得 3000 欧元，但以 1/3 的概率你要给我 3000 欧元。三个选择的期望回报都是 1000 欧元，你真的会认为它们等价吗？期望没有考虑你对赌博的喜爱或厌恶。在与自然对弈时应该怎样考虑这件事？

为了修补，先看另一种情形。多数人会同意钱多更好（钱太多让你烦恼的话，总可以把多余的捐给慈善机构）。有趣的是，富有会降低钱的感知价值，下面的例子说明这一点。

例 9.23（真人秀）：设你幸运地参加一个真人秀，节目要考验你为了挣钱愿意出多大的丑、甚至折磨自己——比如吃蟑螂、把头长时间泡在水里等。令 \(u_1\) 表示同意做这件事，\(u_2\) 表示拒绝；奖金以美元计。想象你是一个手头拮据的穷学生，考虑下面几种情形你会怎么反应：

  1. \(u_1\) 赚 \$1，\(u_2\) 什么也没有。单纯优化回报会选 \(u_1\)，即去做那件不愉快的事。值 \$1 吗？问题在于我们没考虑完成任务的不适。也许应该把美元值减去你刚好愿意做这件事的那个金额。
  2. \(u_1\) 赚 \$10,000，\(u_2\) 什么也没有。\$10,000 被假定为一大笔钱，显然值得忍受节目的任何折磨，所以 \(u_1\) 更好。
  3. 现在想象主持人先因为你上节目给你 1000 万美元。你还愿意为了额外的 \$10,000 去做那件不愉快的事吗？大概不会。这是怎么回事？你对钱的价值感随着钱变多而降低了，对吧？如果参赛者都是富有的石油大亨，这节目就不好看了。
  4. 假设你已经完成了任务，即将领奖。为了增加戏剧性，主持人给你一次赌博的机会：选 \(u_1\) 拿 \$10,000，或者选 \(u_2\) 做赌徒——抛一枚均匀硬币，以 1/2 的概率赢 \$25,000。按期望回报显然选 \(u_2\)；但你刚做完那件不愉快的事、正等着拿钱，输光的风险可能难以承受。不同的人会有不同的偏好。
  5. 再假设你又完成了任务，这次选择是 \(u_1\) 得 \$100，或 \(u_2\) 以 1/2 的概率得 \$250（抛均匀硬币）。主持人很善良，让你玩 100 次。两种动作的期望总额分别是 \$10,000 和 \$12,500。这次似乎明显该赌：100 次独立试验之后，我们预期以极高的概率挣到超过 \$10,000（补充：概率约 97.2%，参考代码第 13 项）。所以如果允许大量独立试验，按期望情况分析的推理似乎是成立的：此时以高概率会得到接近期望回报的值。

由这些例子看来，决策系统的客户或评估者必须指出结果上的概率分布之间的偏好。有一种形式化的方法能保证一旦这些偏好给定，就能设计一个代价函数，使其期望忠实地反映对分布的偏好。这就是效用理论，它包括下面几步：

  1. 要求客户在给出偏好时是理性的 rational。这个概念由公理定义。
  2. 如果偏好与公理一致，就保证存在一个效用函数 utility function；优化期望效用时，偏好与客户的完全一致。
  3. 代价函数可以由效用函数导出。

客户必须给出结果上概率分布之间的偏好。设用的是 Formulation 9.311，方便起见设 \(U\)、\(\Theta\) 有限。令 \(X\) 为基于结果的状态空间（多数效用理论文献称之为回报空间 \(\mathcal{R}\)），\(f:U\times\Theta\to X\) 给每个结果赋一个状态。一个简单的例子是令 \(X=U\times\Theta\)、\(f\) 为恒等映射，使结果空间与状态空间重合。也可以用 \(f\) 把结果空间压缩成一个更小的集合：如果两个结果映到同一个状态，说明就回报或代价而言它们无法区分。

令 \(z\) 表示 \(X\) 上的一个概率分布，\(Z\) 为 \(X\) 上所有概率分布的集合。每个 \(z\in Z\) 表示为 \(n=|X|\) 维概率向量，看作 \(\mathbb{R}^n\) 的元素，便于「混合」两个分布：令 \(\alpha\in(0,1)\) 是常数，\(z_1\)、\(z_2\) 是任意两个分布，用标量乘法得到新分布 \(\alpha z_1+(1-\alpha)z_2\)，称为 \(z_1\) 与 \(z_2\) 的混合 blend。方便的是不需要再归一化：\(z_1\)、\(z_2\) 的「长度」都是 1，混合的长度是 \(\alpha+(1-\alpha)=1\)。

建模者必须咨询客户来表示 \(Z\) 中元素之间的偏好。\(z_1\prec z_2\) 表示 \(z_2\) 严格优于 \(z_1\)；\(z_1\approx z_2\) 表示两者偏好相当；\(z_1\preceq z_2\) 表示 \(z_1\prec z_2\) 或 \(z_1\approx z_2\)。

例 9.24（表示偏好）：设 \(U=\Theta=\{1,2\}\)，得到四个可能的结果 \((1,1)\)、\((1,2)\)、\((2,1)\)、\((2,2)\)。想象自然是一台按某个概率分布产生 1 或 2 的机器，动作是猜机器会产生哪个数：猜中就赢得那个数目的金币，猜错什么也不赢、也不输。用 \(f\) 构造状态空间 \(X\)：结果 \((2,1)\) 和 \((1,2)\) 在任何可想到的回报上都一样，应映到同一状态；另两个结果各不相同。所以状态空间只需三个元素，\(X=\{0,1,2\}\)：令 \(f(2,1)=f(1,2)=0\)、\(f(1,1)=1\)、\(f(2,2)=2\)，后两个状态表示能赢到一些金币。现在考虑 \(X\) 上的概率分布集合 \(Z\)，每个 \(z\) 是三维向量。例如 \(z_1=[1/2\ \ 1/4\ \ 1/4]\) 表示状态以概率 1/2 为 0、1/4 为 1、1/4 为 2。设 \(z_2=[1/3\ \ 1/3\ \ 1/3]\)：你更喜欢哪个？这里 \(z_2\) 似乎一致地更好，因为赢到金币的机会更大，于是声明 \(z_1\prec z_2\)。分布 \(z_3=[1\ \ 0\ \ 0]\) 似乎是能想象的最差的，于是可以放心地声明 \(z_3\prec z_1\)、\(z_1\prec z_2\)。对复杂问题，确定偏好的过程会相当繁琐。本例中 \(Z\) 是 \(\mathbb{R}^3\) 的一个二维子集，可以划分成有限个区域，让客户在其上清楚地表明偏好。这一框架的主要批评之一就是确定 \(Z\) 上偏好的不现实性。

偏好确定后，是否有办法保证存在一个 \(X\) 上的实值函数，其期望值恰好反映偏好？如果偏好的赋值满足理性公理，答案是肯定的。

理性公理 axioms of rationality

为了达到设计效用函数的目标，偏好必须遵守一些称为理性公理的规则。它们是偏好之间合理的一致性要求；只要遵守了，效用函数就保证存在（详细论证见文献；也存在别的公理体系）。决策者被认为是理性的，若定义 \(\prec\) 和 \(\approx\) 时遵守下列公理：

  1. 若 \(z_1,z_2\in Z\)，则 \(z_1\preceq z_2\) 或 \(z_2\preceq z_1\)。「你必须能拿定主意。」
  2. 若 \(z_1\preceq z_2\) 且 \(z_2\preceq z_3\)，则 \(z_1\preceq z_3\)。「偏好必须是传递的。」
  3. 若 \(z_1\prec z_2\)，则对任意 \(z_3\in Z\)、\(\alpha\in(0,1)\)，
    $$\alpha z_1 + (1-\alpha)z_3 \prec \alpha z_2 + (1-\alpha)z_3. \tag{9.84}$$
    「均匀地混入一个新分布不改变偏好。」
  4. 若 \(z_1\prec z_2\prec z_3\)，则存在 \(\alpha\in(0,1)\) 和 \(\beta\in(0,1)\) 使得
    $$\alpha z_1 + (1-\alpha)z_3 \prec z_2 \tag{9.85}$$
    $$z_2 \prec \beta z_1 + (1-\beta)z_3. \tag{9.86}$$
    「既没有天堂，也没有地狱。」

每条公理都有说得通的直观解释。第一条只是说对任何一对分布都能判断偏好方向。第二条说偏好必须传递（书中脚注：对某些合理的问题，传递性并不是想要的，见 Condorcet 悖论与 Simpson 悖论）。后两条复杂一些。第三条中 \(z_2\) 严格优于 \(z_1\)；试图通过混入第三个分布 \(z_3\) 来制造混乱，但如果混进 \(z_1\) 和 \(z_2\) 的 \(z_3\)「分量」相同，偏好就不应受影响。最后一条涉及 \(z_1\)、\(z_2\)、\(z_3\)，每个都严格好于前一个。(9.85) 说明，若 \(z_2\) 严格好于 \(z_1\)，那么可以往 \(z_1\) 里混入一丁点 \(z_3\)，\(z_2\) 仍然更好；如果 \(z_3\) 像「天堂」（无限回报），这就不可能了。类似地，(9.86) 说明可以往 \(z_3\) 里混入一丁点 \(z_1\)，结果仍好于 \(z_2\)——这意味着 \(z_1\) 不能是「地狱」（无限负回报）。（有些公理体系允许无限回报，导致取无限值的效用与代价函数，这里不考虑。）

构造效用函数

如果偏好是以与公理一致的方式确定的，就可以证明效用函数一定存在：存在函数 \(\mathcal{U}:X\to\mathbb{R}\)，使对所有 \(z_1,z_2\in Z\)，

$$z_1\prec z_2 \quad\text{当且仅当}\quad E_{z_1}[\mathcal{U}] < E_{z_2}[\mathcal{U}], \tag{9.87}$$

其中 \(E_{z_i}\) 表示把 \(\mathcal{U}\) 当作概率分布 \(z_i\) 下的随机变量时的期望。\(\mathcal{U}\) 的存在说明通过最大化期望效用来确定最好的动作是安全的。

可以用效用函数定义回报函数 \(R(u,\theta)=\mathcal{U}(f(u,\theta))\)，再转换成代价函数 \(L(u,\theta)=-R(u,\theta)=-\mathcal{U}(f(u,\theta))\)。在 \(\mathcal{U}\) 被正确地构造以保持偏好的前提下，Formulation 9.3、9.4 在概率不确定性下推荐的「最小化期望代价」现在看来是有道理的。

可惜，证明效用函数存在并不给出构造它的系统方法。多数情况下只能通过反复核对偏好的试错过程来设计 \(\mathcal{U}\)。在绝大多数应用中，人们构造效用与代价函数时并不考虑本节讨论的这些含义，所以可能得到不理想的结论——不要对最优决策规则的质量过于自信。注意如果用的是最坏情况分析，这里讨论的大多数问题本可以避免；但最坏情况分析有它自己的弱点（9.5.3 节）。

例 9.25（钱的效用）：本节最后描绘一个常用于金钱的效用函数。设状态空间 \(X=\mathbb{R}\)，表示挣到的美元数。多数人对金钱的效用表明：随着累积财富增加，新增的钱的价值下降。效用函数甚至可能有界：想象存在某个最大金额，比如 \(\$10^{100}\)，超过它之后更多的钱就没有价值了。典型的效用曲线见图 9.6——一条从原点陡升、然后逐渐变平的凹曲线。

9.5.2 对概率模型的质疑 Concerns Regarding the Probabilistic Model

9.5.1 节讨论了代价函数的来源以及取期望的合理性。这一节对 9.2 节所用概率分布的合理性提出疑问。两个主要话题是：对贝叶斯方法的一般批评，以及构造概率分布的难处。

贝叶斯派与频率派

过去一个半世纪里，统计学家之间一直在争论概率的含义。几乎所有人都满意于概率公理，但除此之外，用概率做推断时它们究竟意味着什么？两大阵营是频率派 frequentists 和贝叶斯派 Bayesians。贝叶斯规则的一种形式在 Bayes 去世后的 1763 年发表。十九世纪的大部分时间里贝叶斯分析在文献中占主导；二十世纪，频率派哲学作为对概率更严格的解释流行起来；近年来贝叶斯方法的可信度又在上升。

如前所见，贝叶斯派把概率解释为对一个假设的相信程度。在这种哲学下，完全可以从一个先验分布出发，收集几个观测，再根据用贝叶斯规则得到的后验分布做决策。从频率派的角度看，贝叶斯分析对概率的使用过于随意。频率派认为，概率只定义为独立试验次数趋于无穷时得到的极限量。例如一枚均匀硬币抛很多次，概率 1/2 表示试验次数趋于无穷时正面次数与总次数之比收敛到的值。贝叶斯派可能会说「下一次是正面的概率是 1/2」，对频率派来说，这种对概率的解释太强了。

频率派按自己的哲学发展了一套决策论。例如频率派会主张优化下面的频率学派风险 frequentist risk 来得到决策规则：

$$R(\theta,\pi) = \int_y L(\pi(y),\theta)P(y|\theta)\,dy, \tag{9.88}$$

其中 \(\pi\) 是策略 \(\pi:Y\to U\)。频率学派风险对所有数据取平均，而不是像贝叶斯派在 (9.26) 中那样基于单个观测做决策。概率 \(P(y|\theta)\) 被假定为独立数据试验次数趋于无穷时得到的极限。用 (9.88) 的主要缺点是优化依赖于 \(\theta\)：最好的决策规则必须依赖未知的 \(\theta\)。在少数情况下可以选到一个对所有 \(\theta\) 都最优的 \(\pi\)，但这很少发生。所以频率学派风险可以看成对策略可取性的一种约束，但通常不足以选出唯一一个。这让人想起 9.1.1 节讨论的 Pareto 最优。频率派方法试图更保守、更严格，结果是对决策做出的论断更弱。

先验分布从哪里来

设已经采用贝叶斯方法。所有贝叶斯分析中最普遍的担忧是先验分布的来源。在 9.2 节它表示为 \(P(\theta)\)（或 \(p(\theta)\)），是自然动作空间上的分布（或密度）。获得 \(P(\theta)\) 最好的办法是通过大量独立试验来估计——这让它的定义与频率派的观点一致。例 9.11 就做到了这一点：\(P(\theta)\) 可以从大量文本中各字母的出现频率可靠地估计出来；分布甚至可以针对特定的语言或主题调整。

但在大多数决策论应用中，做这样的实验不可能或代价太高。这时怎么办？如果先验分布只是「编出来的」，得到的后验概率就值得怀疑；事实上称它们为概率可能都不合适。这种情况下有时用主观概率 subjective probabilities 一词。尽管如此，人们常常这么做，因为别无选择。选项之一是转向频率派决策论，但如前所述，它不适用于单个观测。

幸运的是，观测越多，先验对贝叶斯后验的影响越小。如果只有一个观测，甚至像 Formulation 9.3 那样一个都没有，先验就非常有影响。如果关于 \(P(\theta)\) 几乎没有信息，就应尽可能仔细地设计这个分布；还应明白，在这个假设下得出的任何结论都受先验左右。假设把这个模型作为规划方法的基础，你可能为算出了「最优」计划而高兴，但这种最优性仍可能取决于先验赋值带来的某种任意偏差。

如果没有任何信息，让 \(P(\theta)\) 在 \(\Theta\) 上尽可能均匀似乎是合理的。Laplace 称之为「不充分理由原则 principle of insufficient reason」：如果没有理由相信一个元素比另一个更可能，就应赋予相等的值。这也可以用信息论中 Shannon 的熵来论证。离散情形下熵是

$$-\sum_{\theta\in\Theta}P(\theta)\lg P(\theta), \tag{9.89}$$

连续情形下是

$$-\int_\Theta p(\theta)\lg p(\theta)\,d\theta. \tag{9.90}$$

这个熵度量是在通信系统中提出的，用来估计通过有噪声介质传送消息所需的最少比特数；一般表示与分布相关的不确定性大小，熵越大不确定性越大。可以证明熵在 \(P(\theta)\) 均匀时最大，这似乎为不充分理由原则提供了依据，于是它可以被看作无信息先验 noninformative prior。这个想法甚至常常用于 \(\Theta=\mathbb{R}\)，得到非正常先验 improper prior：密度不可能在整个 \(\mathbb{R}\) 上保持一个非零常数，因为积分会是无穷。但 9.2 节的决策不依赖任何归一化因子，所以可以给 \(p(\theta)\) 赋一个常数值，决策不受先验非正常的影响。

用熵论证来选先验的主要困难是 \(\Theta\) 本身可能以很多任意的方式选取；对不同的 \(\Theta\) 做均匀赋值，最终会产生关于先验的不同信息。

例 9.26（无信息先验的一个问题）：考虑根据天气决定做什么活动。设完全不知道会是什么天气。一种可能的赋值是 \(\Theta=\{p,c\}\)，\(p\) 表示「降水」，\(c\) 表示「晴」。最大化 (9.89) 建议 \(P(p)=P(c)=1/2\)。仔细一想，也许想区分不同种类的降水，更好的自然动作集合是 \(\Theta=\{r,s,c\}\)：\(c\) 仍是「晴」，降水 \(p\) 被分成 \(r\)「雨」和 \(s\)「雪」。现在最大化 (9.89) 给每个自然动作赋概率 1/3，明显不同于原来的赋值：区分了降水的种类之后，降水看起来可能得多。我们想区分不同形式的降水，真的会影响天气吗？

例 9.27（连续空间的无信息先验）注：连续空间里也会出现类似的麻烦。回忆例 9.12 的参数估计问题。现在设任务是估计一条直线：一些数据点本应落在这条直线上，但因测量噪声偏离了。应该给 \(\Theta\)——所有直线的集合——赋什么初始概率密度？设直线位于 \(Z=\mathbb{R}^2\) 中，方程可以写成

$$\theta_1z_1 + \theta_2z_2 + \theta_3 = 0. \tag{9.91}$$

问题在于参数向量 \(\theta=[\theta_1\ \theta_2\ \theta_3]\) 乘以一个标量常数后得到同一条直线。所以即使 \(\theta\in\mathbb{R}^3\)，也必须加一个约束。设要求

$$\theta_1^2 + \theta_2^2 + \theta_3^2 = 1 \tag{9.92}$$

且 \(\theta_1\ge0\)12。这大体上解决了问题，保证每个参数值对应唯一一条直线（\(\theta_1=0\) 处有些重复，这里可以放心地忽略）。于是参数空间是球面 \(\mathbb{S}^2\) 的上半部分。最大熵先验建议给 \(\Theta\) 赋均匀的概率密度。这也许感觉理所当然，但这种均匀性的概念被为保证唯一性而施加的特定约束所左右。还有很多别的选择，例如可以把 (9.92) 换成强迫点落在立方体表面上半部分的约束，而不是球面；在这个新参数空间上赋的均匀概率密度当然不同于球面上的。

有些情形下参数空间有对某些变换不变的自然表示。5.1.4 节介绍过 Haar 测度的概念。如果用 Haar 测度作为无信息先验，就能得到有意义的均匀性。例如参数空间是 SO(3) 时，按例 5.14 的建议，在单位四元数空间上赋均匀的概率质量是无信息先验的绝佳选择，因为它与 Haar 测度一致——对作用于事件的群运算不变。可惜对实践中出现的大多数空间，Haar 测度并不存在（它要求局部紧的拓扑群）。

对条件分布的错误假设

最后一个担忧是：很多时候连分布 \(P(y|\theta)\) 也估计错了，因为它被任意地假定属于某个分布族。例如用高斯密度很容易，于是很想假设 \(p(y|\theta)\) 是高斯的。可以做实验估计均值和方差参数；但即使找到了最佳拟合，也不意味着高斯是好的表示。基于这个模型的结论可能是错的，尤其当真实分布形状不同时，例如尾巴更长或是多峰的。很多情况下需要非参数 nonparametric 方法来避免这种偏差：这类方法不假设特定的分布族。例如，想象对固定的 \(\theta\) 做一个直方图，记录 \(y\) 出现的频率；把直方图归一化，就得到一个不必假设初始形式的概率分布表示。

9.5.3 对非确定性模型的质疑 Concerns Regarding the Nondeterministic Model

鉴于概率建模的这些问题，很想放弃整个框架、完全使用非确定性模型。这只需指定 \(\Theta\)，不必说明各动作的相对可能性。于是 9.5.1、9.5.2 节的大部分复杂问题都消失了。可惜这个好处是以相当的代价换来的：用非确定性模型的最坏情况分析做决策有它自己的缺点。权衡之后，你可以决定哪个更适合具体的应用。

第一个困难是保证 \(\Theta\) 足够大，覆盖所有可能性。考虑自然行动两次的 Formulation 9.6：通过自然观测动作空间 \(\Psi(\theta)\)，测量过程引入干扰。设 \(\Theta=\mathbb{R}\)、\(h(\theta,\psi)=\theta+\psi\)，这时 \(\Psi(\theta)\) 可以解释为测量误差。可能出现的最大误差是多少？也许是声呐在测量机器人到墙的距离。根据传感器规格，可能可以给误差构造一个漂亮的界；但偶尔误差会比这个界大。声呐有时听不到计算距离所需的回声，这时报告的距离是 \(\infty\)；由于反射，偶尔还会出现极大的误差。虽然这样的误差不常见，但如果要有保证的表现，就必须把很大甚至无限的误差包括在 \(\Psi(\theta)\) 中。问题是，最坏情况的推理可能总是得出「传感器毫无用处」的结论——因为它可能一直报告 \(\infty\)。从传感器能获得的任何统计上有效的信息都会被忽略。在概率模型下，很容易把 \(\Psi(\theta)\) 设得很大，再给大误差赋很小的概率。非确定性不确定性的问题在于：\(\Psi(\theta)\) 需要更小才能做出合适的决策，但这样理论上的「保证」在实践中可能并不真正有保证。（9.2.3 节的「噪声传感器」互动图里可以亲眼看到这一点。）

即使建立了非确定性模型，最优决策规则给出的结果在预期应用中也可能显得荒谬。问题在于决策者不能容忍任何风险：只有结果能被保证时才采取行动，比最坏情况做得更好的希望不被考虑。考虑下面的例子：

用概率分析，也许会得出拿支票最好的结论——也许你知道这位朋友很富有、对银行账户很负责。但这种信息无法纳入（非确定性的）决策过程。用最坏情况分析，最优动作是拿 1 欧元现金。不过你可能感觉不太好：想象一下，后来得知账户其实有足够的钱兑现那张 1000 欧元的支票，该有多后悔。

所以要记住：想要绝对有保证的结果是要付出代价的。概率模型提供了纳入统计信息的灵活性。有时可以把概率模型看成非确定性模型的推广：如果假设自然在机器人之后行动，自然动作就能考虑机器人的动作，如 Formulation 9.4 那样。非确定性情形下指定 \(\Theta(u)\)，概率情形下指定 \(P(\theta|u)\)。可以把分布 \(P(\theta|u)\) 设计成自然以极高的概率选择使 \(L(u,\theta)\) 最大的那个 \(\theta\in\Theta\)。在例 9.28 中，这意味着支票跳票（毫无收益）的概率极高，比如 0.999999；这时即使在概率模型下，最优动作也是选 1 欧元现金。几乎对任何用最坏情况分析建模的决策问题，都可以反向推导出某些先验，使概率分析做出同样的决策。在例 9.28 中14，看起来决策正是基于「支票以极高概率跳票」这一假设做出的，尽管并没有概率模型。（补充：按期望收益，拿支票更好当且仅当 \(1000(1-p)>1\)，即跳票概率 \(p<0.999\)，参考代码第 15 项。）

这说明非确定性模型下的最坏情况分析可以看作概率模型的一个特例：先验分布给最坏的结果赋了很高的概率。对这种赋值的理由，可以像批评贝叶斯分析中的其它先验赋值一样提出质疑：这种特定赋值的根据是什么？

9.5.4 对博弈论的质疑 Concerns Regarding Game Theory

博弈论最基本的局限之一是每个玩家必须知道其他玩家的代价函数。9.5.1 节已经说明，即使为单个决策者确定合适的代价函数也相当困难；确定其他玩家的代价和动机就更难了。在大多数实际情境中这些信息是得不到的。一种可能是对另一个玩家代价函数的知识中的不确定性建模：可以用贝叶斯分析，根据观察到的该玩家的动作来推理他的代价——先验赋值的问题又出现了。允许代价函数中有不确定性的最大困难之一，是会出现一种「无限反射 infinite reflection」：比如我在玩一个博弈，对方知道我的代价函数吗？我可能对此不确定。再进一步，对方知道我并不完全知道他的代价函数吗？这种揣测可以无限进行下去，导致嵌套推理和先验分布赋值的噩梦。（书中脚注：看过电影《公主新娘 The Princess Bride》的读者，也许还记得 Vizzini 和恐怖海盗罗伯茨关于哪只酒杯里有致命的 Iocane 毒药的那段幽默对话。）

鞍点或 Nash 均衡的存在是通过随机化策略保证的。数学上这看起来是对一个令人沮丧的问题的干净解答，但它也代表了对模型的实质性改变。很多博弈只玩一次；要使期望情况的结果收敛，博弈必须玩无穷多次。如果只玩一次或几次，即使基于期望情况分析的理论表明遗憾已被消除，玩家也很可能会后悔。

另一个问题是，有智能的人类玩家在玩过几次之后可能会从根本上改变策略。人类很难模拟一个随机化策略（假设他们真的想这样做，而这不太可能）。甚至有经典博弈（如石头剪刀布和囚徒困境）的国际锦标赛，玩家反复参加。对一个人们设计程序反复参加囚徒困境比赛的锦标赛的有趣讨论，见书中文献。人们观察到，经过多次迭代后甚至会出现一些合作，即使玩家无法沟通，这也为双方带来了更高的回报。在这种背景下出现了一个著名策略叫 Tit-for-Tat（以牙还牙）（由 Anatol Rapoport 编写）：每一轮都重复另一个玩家上一轮的动作。这个方法简单却出奇地成功。

在非零和博弈中，可能存在多个 Nash 均衡这一点尤其令人沮丧。假设多个 Nash 均衡中只有一个可容许，对手真的会仔细思考各个 Nash 均衡、并挑出那个可容许的吗？也许有些玩家很保守，甚至会玩安全策略——这彻底破坏了最小化遗憾的假设。如果有多个可容许的 Nash 均衡，看来除非玩家之间有某种合作，否则遗憾不可避免。如果这种合作不可能，结果就令人遗憾。

常见陷阱

  1. 把 min 写成 inf / 把 inf 当成能取到：开区间、无界集合上最优值可能不存在；inf 告诉你下界，但未必有动作达到它。
  2. 以为 Pareto 最优能给出唯一答案：它只是去掉被支配的动作，剩下的可能很多（例 9.3 是整个连续统）。
  3. 混淆 \(P(E|F)\) 和 \(P(F|E)\)：检测准确率 95% 不等于阳性后有 95% 的概率患病——先验很小时后验可能很小。
  4. 把「独立」当成「互斥」：互斥的两个非空事件恰恰不独立（知道一个发生，另一个就不可能发生）。
  5. 以为随机化总能降低代价：对固定的代价函数，(9.13) 是线性的，最优总在纯策略上；随机化只在对手能学习时才有价值。
  6. 把均匀先验当成「没有假设」：均匀本身是一个假设，而且依赖于 \(\Theta\) 怎么划分、怎么参数化（例 9.26、9.27）。
  7. 行列方向搞反：本书的约定是行 = 机器人 / \(\mathrm{P}_1\)、列 = 自然 / \(\mathrm{P}_2\)，元素是 \(\mathrm{P}_1\) 的代价。找鞍点：行最大、列最小；找 Nash：A 的列最小、B 的行最小。
  8. 以为多个 Nash 均衡和多个鞍点一样无害：鞍点的值都相同、可以互换；Nash 均衡的代价可能不同、不可比，各选各的可能落到非均衡上。
  9. 把混合 Nash 均衡当成更好的结果：性别之战里混合均衡给双方的期望代价 (−2/3, −2/3) 比两个纯均衡都差。
  10. 用安全策略对付非零和博弈：它不看对方的代价，通常导致遗憾；囚徒困境是安全策略恰好等于 Nash 均衡的特例。
  11. 认为期望效用最大化等于期望金额最大化：只有效用是线性时才成立；风险厌恶的人会放弃期望更高的赌局（例 9.22、9.23）。
  12. 把「最坏情况保证」当成真的保证：保证只在 \(\Theta\)、\(\Psi(\theta)\) 足够大时成立，而足够大的集合往往让决策毫无用处（9.5.3 节）。

  9. 常和博弈：令 \(L'_2=L_2-c\)，就得到零和博弈，安全策略与鞍点不变。

  13. 可互换的 Nash 均衡：若 \((A,B)\) 的 Nash 均衡与 \((A,-A)\) 相同，后者是零和博弈，其鞍点可以互换（图 9.3 的论证）。

  17. 实现「一方最多两个动作」的随机化鞍点（实现题）：就是本页包络图左半边做的事——对 \(w_1\in[0,1]\) 求 \(n\) 条直线上包络的最低点。

脚注：原书笔误

以下每一条都对照原书 PDF 的原页核对过（页码为书中页码），能用数值核对的都在参考代码里有对应的断言。

1 第 444 页例 9.5：原书写「Using (9.11), the expected value, E[X], is 3.5」。骰子是离散的，应当用 (9.10)；(9.11) 是连续情形的积分。同一段还有「greater then 3」（应为 than）、「even though it is not contained in S」（逻辑上应为 because）两处小笔误。↩

2 第 451 页例 9.10：原书写「In this case, u* = u₁, which yields the optimal expected regret, calculated as 1」。按遗憾矩阵和均匀先验，三个动作的期望遗憾是 (2+0+2)/3 = 4/3、(0+3+0)/3 = 1、(3+0+3)/3 = 2，最优的是 \(u_2\)；「值为 1」对应的正是 \(u_2\)。另一个佐证：期望遗憾与期望代价只差一个与 \(u\) 无关的常数，均匀先验下期望代价 (0, −1/3, 2/3) 也选 \(u_2\)（参考代码第 4 项）。↩

3 第 451 页：原书说「a |Θ| × |U| regret matrix」，而代价矩阵是 \(|U|\times|\Theta|\)，例 9.10 印出来的遗憾矩阵也是行 = \(U\)、列 = \(\Theta\)。应为 \(|U|\times|\Theta|\)（小问题）。↩

4 第 453 页：原书写「for which the denominator (9.26) represents P(y)」。(9.26) 里没有分母，指的是 (9.25) 的分母（小问题）。↩

5 第 454 页 Formulation 9.6 之后：原书写「A strategy still takes the form π : Θ → U」。机器人看不到 \(\theta\)，策略只能依赖观测，应为 \(\pi : Y\to U\)（与 Formulation 9.5 之后的定义一致）。↩
