Part II · 第 8 章

反馈运动规划 Feedback Motion Planning

到目前为止，Part II 一直假设「算出一条连续路径」就解决了运动规划问题。在动画、虚拟样机里这没问题——虚拟世界里的模型会照着设计的样子运动。可一旦和物理世界打交道，未来的位形可能无法预测。这一章把反馈 feedback引入运动规划：计划不再是一条路径，而是告诉机器人「无论你现在在哪里，都该往哪里走」。

本章导读

机器人学里传统的做法是图 1.19 那样的精化方案：先规划一条路径，再设计一个反馈控制律尽量跟住它。有时这就够用，但它是高度解耦的——规划路径时既不管反馈也不管动力学，算出来的路径执行起来可能根本没法用。本章换一种思路：把反馈直接放进规划里，但仍然忽略微分约束（动力学留给 Part IV）。

8.1 动机 Motivation

只要和物理世界打交道，就需要某种形式的反馈：计划的动作要依赖执行过程中收集到的信息。需要反馈的根本原因是未来状态不可预测。本章的状态空间要么是离散的，要么就是第 4 章的配置空间 \(X = \mathcal{C}\)。对「未来状态不可预测」有两种建模方式：

  1. 显式 Explicitly：建立明确描述「实际未来状态可能如何偏离计划」的模型，规划算法直接把这种不确定性考虑进去。这是 Part III 的主题。
  2. 隐式 Implicitly：状态转移模型声称没有不确定性；但我们构造一个反馈计划，保证机器人万一处在某个意想不到的状态，也知道该做什么。这一章用的是这种方式。

隐式方式乍看奇怪，书中给了理由：Part III 会看到显式建模不确定性极具挑战——可靠模型的要求高得多，问题复杂度上升，算法更难设计，也给建模错误留下更多空间。而隐式处理在控制理论里早有传统：人们早就知道要用反馈控制律才能获得可靠的性能，可大多数场合下动力学的表述并不显式考虑不确定性；只有在随机控制 stochastic control、鲁棒控制 robust control 这些较新的分支里才显式建模。既然「用状态反馈隐式应对不可预测」在上个世纪的控制应用中如此成功，在运动规划里也值得借用。（书中还加了一句：如果你还是不喜欢，就直接跳到第 10 章。）

由于历史原因，反馈和动力学常被看成密不可分——控制理论本来就是为了可靠地改变动力系统的行为而发展的。传统运动规划两者都不考虑：解路径是开环 open loop 的，执行时没有信息反馈回来去闭合 close 这个环；动力学也不考虑，因为微分约束和更高维的相空间会带来额外麻烦（Part IV）。把两件事拆开，就得到图 8.1 的四种组合：

  • 开环 + 动力学：近年来越来越受关注，是 Part IV 大部分内容。熟悉经典控制理论的人可能会批评它不考虑反馈，但这种开环轨迹（相空间里的路径）在仿真等应用里很有用；而且「考虑了动力学的轨迹」比「忽略动力学的路径」更有价值——后者却被接受了几十年。
  • 反馈 + 无微分约束：本章。既然忽略微分约束来解经典运动规划可以接受，那么设计同样忽略微分约束的反馈运动计划也不该更内疚。（8.4.4 节会考虑加速度界这类简单的微分约束；完整处理见 Part IV。）

反馈计划的另一个重要用途：即使没有不可预测的问题，初始状态也可能未知。反馈计划指明了从每个状态该采取的动作，所以初始条件无关紧要。图算法里的对应物是单终点最短路问题 single-destination shortest-path problem：从任何其它顶点最优地到达某个顶点。作为机器人学里解耦方法的一个模块，反馈运动计划至少和一条路径一样有用；而在开环路径不可靠的场合，可以期待反馈计划更可靠。

8.2 离散状态空间 Discrete State Spaces

这一节主要是为后面几节作铺垫：只讨论离散空间，表述和理解都简单得多；之后再推广到配置空间和其它连续状态空间。书中说这里的讨论也是第 8.4.1 节反馈规划概念的背景，并称「那时会显式建模不确定性」1。

8.2.1 定义反馈计划 Defining a Feedback Plan

考虑类似 Formulation 2.1、2.3 的离散规划问题，只是不给初始状态。于是代价泛函不能再只写成计划的函数，而要用状态历史 state history 和动作历史 action history 定义。在第 \(k\) 阶段：

$$\tilde x_k = (x_1, x_2, \ldots, x_k) \tag{8.1}$$
$$\tilde u_k = (u_1, u_2, \ldots, u_k). \tag{8.2}$$

有时也把 \(\tilde x_k\) 称为状态轨迹 state trajectory。

Formulation 8.1（离散最优反馈规划 Discrete Optimal Feedback Planning）
  1. 有限、非空的状态空间 \(X\)。
  2. 对每个状态 \(x\in X\)，有限的动作空间 \(U(x)\)。
  3. 状态转移函数 \(f\)：对每个 \(x\in X\)、\(u\in U(x)\) 给出状态 \(f(x,u)\in X\)。记 \(U\) 为所有 \(U(x)\) 的并。
  4. 一组阶段，记为 \(k\)，从 \(k = 1\) 开始无限地继续下去。
  5. 目标集 \(X_G\subset X\)。
  6. 阶段可加的代价泛函 \(L\)：
    $$L(\tilde x_F, \tilde u_K) = \sum_{k=1}^{K} l(x_k, u_k) + l_F(x_F), \tag{8.3}$$
    其中 \(F = K + 1\)。

与第 2 章相比还有一个区别：这里假设状态空间有限，这方便构造反馈计划，但一般并非必需。

怎样定义解决 Formulation 8.1 的计划？若给了初始条件，可以像第 2 章那样指定一个动作序列。没有初始条件时，一种办法是为每个可能的初始状态 \(x_1\in X\) 各存一个动作序列——但这很浪费。设从 \(x\) 出发、施加第一个动作后到达 \(x'\)：在 \(x'\) 该做什么？可以用 \(x\) 的序列里的第二个动作，但也可以把 \(x'\) 看成新的初始状态，用它自己序列的第一个动作。所以每个状态只需存第一个动作：执行时从某个状态出发，施加那里存的动作，到达下一个状态，再施加那里存的动作……直到到达目标。

定义：反馈计划 feedback plan

函数 \(\pi : X \to U\)，对每个状态 \(x\) 指出该施加的动作。若到达目标就施加终止动作：\(\pi(x) = u_T\)，\(x \in X_G\)。若从每个能到达目标的状态出发执行 \(\pi\) 都能到达目标，则称 \(\pi\) 是问题的解 solution。

给定初始状态 \(x_1\) 和计划 \(\pi\)，状态历史和动作历史就都确定了，于是执行代价 (8.3) 也可写成 \(L(\pi, x_1)\)。这依赖于未来状态总是可预测的；第 10 章由于不确定性，就做不到这种直接对应（10.1.3 节）。

可行性与最优性 Feasibility and optimality

因为没有给初始状态，可行与最优都要重新定义。若从每个能到达 \(X_G\) 的 \(x\) 执行 \(\pi\) 确实到达 \(X_G\)，就称 \(\pi\) 是可行 feasible 规划问题的解（此时忽略代价泛函，也可以定义一个去掉代价泛函的 Formulation 8.1）。简便起见，称这样的 \(\pi\) 为可行反馈计划。

再看最优性。对给定的 \(x\)，用 2.3 节的概念显然存在最优计划。问题是：会不会不同的 \(x\) 需要不同的最优计划？答案是不需要，一个计划就够编码从每个初态到 \(X_G\) 的最优路径。理由：用 Dijkstra 或值迭代（2.3 节）在 \(X\) 上算出最优 cost-to-go。每个 \(x\) 处的 cost-to-go 值就是从 \(x\) 出发执行最优开环计划的代价；最优计划的第一步由 (2.19) 决定，到达 \(x' = f(x,u)\)。在 \(x'\) 再用一次 (2.19) 得到下一个最优动作。\(x'\) 处的代价既是以 \(x'\) 为初态的最优 cost-to-go，也是从 \(x\) 出发的最优路径继续走下去的代价——由动态规划原理两者必然相等。既然所有这些代价都一致，一个反馈计划就能给出所有初态的最优 cost-to-go。于是：若对每个 \(x\in X\)，执行 \(\pi\) 得到的总代价 \(L(\pi,x)\) 都是所有计划中最低的，就称 \(\pi\) 为最优 optimal 反馈计划。

8.2.2 反馈计划即导航函数 Feedback Plans as Navigation Functions

巧的是，计算反馈计划的工具第 2 章已经给过了：Dijkstra 和值迭代的副产品就能表示反馈计划。为此，把反馈计划改写成状态空间上的势函数 potential function（回忆 5.4.3 节）。规划算法算出势值，执行时用它恢复出合适的动作；有时甚至可以用势函数表示最优反馈计划。

导航函数 Navigation functions

考虑一个（离散）势函数 \(\phi : X\to[0,\infty]\)。它通过局部算子 local operator 定义反馈计划：在 \(x\) 处选择让势下降最多的动作。先看可行规划问题：

$$u^* = \operatorname*{argmin}_{u\in U(x)} \Big\{\phi(f(x,u))\Big\}, \tag{8.4}$$

即选 \(u^*\in U(x)\) 让 \(\phi\) 尽量下降——一种贪心的下降，\(u^*\) 不一定唯一。连续空间里对应的局部算子就是沿负梯度下降，常称梯度下降 gradient descent。最优规划时，局部算子定义为

$$u^* = \operatorname*{argmin}_{u\in U(x)} \Big\{l(x,u) + \phi(f(x,u))\Big\}, \tag{8.5}$$

它很像动态规划条件 (2.19)：若把 \(\phi\) 理解为最优 cost-to-go，两者就完全相同。若规划问题是各向同性 isotropic 的——每个方向代价一样：对所有 \(u,u'\in U(x)\setminus\{u_T\}\) 有 \(l(x,u) = l(x,u')\)——那么 \(l(x,u)\) 不影响 (8.5) 的最小化，(8.5) 化简回 (8.4)。典型例子是代价泛函数「到目标的阶段数」：沿途选哪个动作的代价都无所谓。

势函数什么时候有用？很多势函数是无用的：到不了目标，或者让状态无限循环。最理想的是：从任何能到达 \(X_G\) 的初态出发都能到达 \(X_G\)。满足这一点只需要几条简单性质。设代价泛函是各向同性的，\(x' = f(x,u^*)\) 是施加 (8.4) 选出的 \(u^*\) 后到达的状态。

定义：（可行）导航函数 navigation function2
  1. 对所有 \(x\in X_G\)，\(\phi(x) = 0\)。
  2. \(\phi(x) = \infty\) 当且仅当从 \(x\) 到达不了 \(X_G\) 中的任何点。
  3. 对每个可达的 \(x\in X\setminus X_G\)，局部算子给出的 \(x'\) 满足 \(\phi(x') < \phi(x)\)。

第一条要求目标处势为零（其实不必要，只为方便）；第二条用 \(\infty\) 作为「到不了目标」的特殊标记；第三条说除目标外没有局部极小——执行结果计划时不会循环，最终一定到达目标。最优导航函数 optimal navigation function 定义为最优 cost-to-go \(G^*\)：除了上面三条，还要满足最优性原理

$$\phi(x) = \min_{u\in U(x)} \Big\{l(x,u) + \phi(f(x,u))\Big\}, \tag{8.6}$$

这就是把 (2.18) 里的 \(G^*\) 换成 \(\phi\)（更多联系见 15.2.1 节）。

例 8.2（2D 网格上的导航函数）：回到例 8.1，用各向同性代价：\(u\ne u_T\) 时 \(l(x,u) = 1\)。图 8.3 是一个导航函数，格子里的数就是 \(\phi\)；可以验证它满足三条性质。在任何状态施加一个让势下降的动作，对应于用 (8.4) 选动作；从任何状态重复下去，直到到达 \(X_G\)。这个例子清楚地说明了导航函数怎样作为反馈计划的另一种定义。

计算导航函数 Computing navigation functions

算导航函数的办法很多。从 \(X_G\) 反向运行 Dijkstra 得到的 cost-to-go 就是最优导航函数；在各向异性情形，导航函数的第三条性质恰好就是平稳动态规划方程 (2.18)（\(\phi\) 取作 \(G^*\)）。前面说过可以只用 cost-to-go 恢复最优动作——这其实就是在用导航函数，那个过程也可以看成一个反馈计划。

如果不在乎最优性，2.2 节的几乎任何反向搜索算法都行，只要记下每个到达状态到目标的距离——不必最优，只要等于「从当前顶点沿搜索树回溯到根（或到 \(X_G\) 中任意顶点）」的代价。若问题本来就没有代价泛函（Formulation 2.1），也可以为构造导航函数发明一个：对每个能到达 \(X_G\) 的 \(x\)，记下从 \(x\) 到 \(X_G\) 要经过的搜索图边数；用 Dijkstra 构造时，执行结果计划的阶段数最少。

导航函数本身就是反馈计划的一种表示——由局部算子恢复动作。所以 \(\pi\) 可以由 \(\phi\) 得到；反过来也能由 \(\pi\) 构造 \(\phi\)。\(\pi\) 与 \(\phi\) 是可以互换的反馈计划表示。

8.2.3 网格上的导航函数用于运动规划 Grid-Based Navigation Functions for Motion Planning

Wavefront 传播算法 Wavefront propagation algorithms

近似做好以后，8.2.2 节的任何方法都能算导航函数。最优导航函数用从目标出发的 Dijkstra 很容易算。若每个动作都是单位代价，还能简化：图 8.4 的 wavefront 传播算法算出最优导航函数，它是 Dijkstra 的特例，不需要显式的优先队列。Dijkstra 执行过程中，队列里最小的代价单调不减；单位代价时队列里很多状态代价相同，可以把所有同为最小值 \(i\) 的状态并行移出——它们组成一个波前 wavefront \(W_i\)。初始波前 \(W_0\) 就是 \(X_G\)；从 \(W_0\) 一步能到的状态立即得到最优 cost-to-go 1（不可能有别的代价），组成 \(W_1\)；\(W_1\) 的未探索邻居得到 2，也一定最优……如此归纳下去直到所有可达状态。最终最优 cost-to-go 在 \(O(n)\) 时间内算出（\(n\) 为可达网格状态数），没到达的状态赋 \(\phi(x) = \infty\)。图 8.3 的导航函数就可以用 wavefront 算出来（参考代码第 1 项逐格核对过）。

最大间隙 Maximum clearance

移动机器人里常见的问题是：最优运动计划让机器人离障碍太近。回忆 6.2.4 节：多边形环境里的欧氏最短路径必须允许碰到障碍顶点，这正是 6.2.3 节最大间隙路线图的动机。可以做一个网格近似版的最大间隙路线图，并定义一个导航函数：先把机器人引到路线图上，沿路线图走，最后送到目标。[63] 称它为 NF2。设只有一个目标状态 \(x_G\in X\)，计算最大间隙导航函数的步骤：

  1. 不用 \(X_G\)，而让 \(W_0\) 是所有「至少一个方向的运动被挡住」的状态——离散化自由空间的边界。
  2. 做 wavefront 迭代，让代价从障碍边界向外一波一波地传播。
  3. 波前传播时，大约会在原连续问题的最大间隙路线图处相遇。把两个波前从相反方向到达的状态标为骨架状态 skeleton state；也可能两个波前只是相接而没有到达同一状态，这时取两个相接状态之一。记 \(S\) 为所有骨架状态。
  4. wavefront 结束后，把 \(x_G\) 连到骨架：把 \(x_G\) 和它到骨架的路径上的所有状态加进 \(S\)（任何搜索算法都可以找这条路径）。
  5. 在 \(S\) 上算导航函数 \(\phi_1\)：把其它状态都当成障碍，用 wavefront。它把 \(S\) 上任一点引到目标。
  6. 把 \(S\) 当成目标区域，用 wavefront 算导航函数 \(\phi_2\)，它把状态引到骨架上最近的点。
  7. 合并：对 \(x\in S\)，\(\phi(x) = \phi_1(x)\)；其余状态 \(\phi(x) = \phi_1(x') + \phi_2(x)\)，\(x'\) 是离 \(x\) 最近的 \(S\) 中的状态（算 \(\phi_2\) 时顺便记下即可）。

若 \(\mathcal{C}_{free}\) 是多连通的，到 \(x_G\) 可能有好几条绕过不同障碍的路线（不同伦）。上面的方法不考虑「某条路线间隙更窄」的问题：它只优化沿骨架走的距离，有多条路线时并不最大化最近接近距离（习题 3）。

Dial 算法 Dial's algorithm

wavefront 传播可以用于任何 \(l(x,u) = 1\)（\(u\ne u_T\)）的离散规划问题，在状态转移图稀疏时最有用（想想用邻接矩阵表示转移图会多浪费）——网格问题就是典型。更一般地，若代价取整数值，就得到 Dial 算法 [33]：它是 wavefront 传播的推广、Dijkstra 的特化。思想是用一组对应不同 cost-to-go 值的桶 bucket 代替优先队列，活着的顶点放进对应的桶。wavefront 的情形任何时候最多只需要两个桶。Dial 算法让最小代价桶里的所有状态并行处理；[88] 进一步改进成线性时间算法。

其它扩展 Other extensions

前面方法的一个缺点是会产生不受欢迎的楼梯状运动 staircase motions（图 7.40）。若用 (5.38) 的 2-邻域定义动作空间，运动一般会更短；这时 Dial 算法可以高效地算出最优导航函数。网格近似也可以推广到高维配置空间，但因为需要高分辨率，只对少数几维（如 3 或 4）实用；用 1-邻域时 wavefront 很容易套用，Dial 算法可以推广到一般的 \(k\)-邻域。

在网格上构造导航函数在很多应用中可能就够了；但有时楼梯运动无法接受，有时甚至来不及算出导航函数。影响因素有：1) 需要非常高的精度，因而要高分辨率网格；2) 配置空间维数高；3) 环境频繁变化，需要实时响应。为了解决这些问题，自然想放弃网格近似，直接在配置空间上定义势函数和速度——下一节给出所需的数学背景。

8.3 向量场与积分曲线 Vector Fields and Integral Curves

要在连续状态空间（包括配置空间）上考虑反馈运动计划，需要定义向量场 vector field，以及从初始点对向量场积分得到的轨迹。向量场最适合刻画连续状态空间上的反馈计划，它是图 8.2b 网格反馈计划的连续类比。

本节给出背景数学的两种表述：8.3.1 节假设 \(X = \mathbb{R}^n\)，定义看起来和微积分、微分方程课上学的很像；8.3.2 节讲流形上的向量场，需要更多技术概念，建立在 4.1.2 节流形定义之上。第一次接触微分流形可能难以一次读懂。书中建议：先学章末推荐的背景材料；或者在后面各节里假装 \(X = \mathcal{C} = \mathbb{R}^n\)——几乎所有内容不用额外的技术细节也说得通。可以把流形想成某些面被粘合的立方体 \([0,1]^n\)（4.1.2 节）：\(\mathbb{R}^n\) 的概念在立方体内部处处适用，只有边界上要小心。例如 \(\mathbb{S}^1 = [0,1]/\sim\)，函数 \(f\) 定义在 \(\mathbb{S}^1\) 上，在 \(f(0)\) 处的导数怎么定义？8.3.2 节的技术定义解决了这个问题；实践中有时可以巧妙处理粘合点来回避。

8.3.1 ℝⁿ 上的向量场 Vector Fields on ℝⁿ

向量空间 Vector spaces

定义向量场之前，先弄清「向量」是什么。向量空间 vector space（或线性空间 linear space）是一个集合 \(V\)，对两种代数运算——向量加法 \(+\) 和数乘 \(\cdot\)——封闭，并满足若干公理。本节用的向量空间是 \(\mathbb{R}^n\)，标量是实数，向量是 \(n\) 个实数的序列；数乘把每个分量乘以标量，向量加法把对应分量相加。一般地，向量空间可以定义在任何域 field \(\mathbb{F}\) 上（4.4.1 节），\(\mathbb{F}\) 表示标量、\(V\) 表示向量；对 \(\mathbb{R}^n\) 取 \(V=\mathbb{R}^n\)、\(\mathbb{F}=\mathbb{R}\)。公理如下（不妨验证 \(\mathbb{R}^n\) 满足它们）：

  1. 向量加法构成交换群：\(V\) 对 \(+\) 是交换群。
  2. 数乘结合律：对任何 \(v\in V\)、\(\alpha,\beta\in\mathbb{F}\)，\(\alpha(\beta v) = (\alpha\beta)v\)。
  3. 标量和的分配律：\((\alpha+\beta)v = \alpha v + \beta v\)。
  4. 向量和的分配律：对任何 \(v,w\in V\)、\(\alpha\in\mathbb{F}\)，\(\alpha(v+w) = \alpha v + \alpha w\)。
  5. 数乘单位元：对任何 \(v\in V\)，\(1v = v\)，\(1\) 是 \(\mathbb{F}\) 的乘法单位元。

向量空间 \(V\) 的基 basis 是一组向量 \(v_1,\ldots,v_n\)，使每个 \(v\in V\) 都能唯一写成线性组合 linear combination

$$v = \alpha_1 v_1 + \alpha_2 v_2 + \cdots + \alpha_n v_n, \tag{8.7}$$

\(\alpha_1,\ldots,\alpha_n\in\mathbb{F}\)。\(\mathbb{R}^3\) 中熟悉的基是 \([0\ 0\ 1]\)、\([0\ 1\ 0]\)、\([1\ 0\ 0]\)。基不唯一（任何三个线性无关的向量都是 \(\mathbb{R}^3\) 的基），但同一个向量空间的任何基所含向量个数相同，这个数 \(n\) 叫维数 dimension。例 8.4（\(\mathbb{R}\) 上的向量空间 \(\mathbb{R}^n\)）：自然的基是 \(n\) 个单位向量（第 \(i\) 个只有 \(x_i = 1\)）；任何 \(n\) 个线性无关的向量都可以作基，基之间用非奇异 \(n\times n\) 矩阵变换。

例 8.5（函数构成的向量空间）：所有连续实值函数 \(f:[0,1]\to\mathbb{R}\)，只要

$$\int_0^1 f(x)\,dx \tag{8.8}$$

有限，就构成 \(\mathbb{R}\) 上的向量空间：两个函数相加积分仍有限，\(f_1+f_2 = f_2+f_1\)，数乘后积分仍有限。这个向量空间是无穷维的：只看 Taylor 级数存在且收敛的那些函数（解析函数 analytic functions），每个都可以写成可能有无穷多项的多项式，单项式 \(x, x^2, x^3,\ldots\) 构成一组基——每个函数都是一个无穷长的系数「向量」。这是函数空间 function space 的简单例子；再加些定义就得到泛函分析中至关重要的 Hilbert 空间 [82, 83]。本章其余部分只考虑 \(\mathbb{R}\) 上的有限维向量空间，但要记住向量空间的这些基本性质。

向量场 Vector fields

向量场看起来就是 \(\mathbb{R}^n\) 上的「针状图 needle diagram」（图 8.5）：在每个点 \(p\in\mathbb{R}^n\) 指定一个方向。用来表示反馈计划时，它告诉机器人：如果发现自己在 \(p\)，该往哪个方向走。对每个 \(p\in\mathbb{R}^n\)，关联一个 \(n\) 维向量空间，叫 \(p\) 处的切空间 tangent space，记作 \(T_p(\mathbb{R}^n)\)。为什么叫「切」？这来自对流形的推广——那时切空间真的与流形上的点相切。

\(\mathbb{R}^n\) 上的向量场 \(\vec V\)4是一个函数，给每个 \(p\in\mathbb{R}^n\) 指定一个 \(v\in T_p(\mathbb{R}^n)\)。它的值域是什么？每个 \(p\) 处的向量 \(\vec V(p)\) 属于不同的切空间，所以值域是并集

$$T(\mathbb{R}^n) = \bigcup_{p\in\mathbb{R}^n} T_p(\mathbb{R}^n), \tag{8.9}$$

称为 \(\mathbb{R}^n\) 上的切丛 tangent bundle。虽然来自不同 \(T_p(\mathbb{R}^n)\) 的向量写出来一样，每个切空间被认为产生不同的向量；为了区分，切丛中的点可以用 \(2n\) 个坐标表示，把 \(p\) 和 \(v\) 放在一起——这对 Part IV 定义相空间很重要。目前只要把 \(\vec V\) 的值域看成 \(\mathbb{R}^n\) 就够了，因为对每个 \(p\)，\(T_p(\mathbb{R}^n) = \mathbb{R}^n\)。于是向量场可以用 \(\mathbb{R}^n\) 上的 \(n\) 个实值函数 \(f_i(x_1,\ldots,x_n)\) 表示：

$$f(x) = [f_1(x_1,\ldots,x_n)\ \ f_2(x_1,\ldots,x_n)\ \ \cdots\ \ f_n(x_1,\ldots,x_n)]. \tag{8.10}$$

这样看，向量场就是一个从 \(\mathbb{R}^n\) 到 \(\mathbb{R}^n\) 的函数 \(f\)，此后就用普通的函数记号。在 \(\mathbb{R}^2\) 上记点为 \(p = (x,y)\)，向量场常写作 \([f_1(x,y)\ \ f_2(x,y)]\)。

  • 例 8.6（常值向量场）：图 8.5a 是常值向量场 constant vector field，给每个 \((x,y)\in\mathbb{R}^2\) 同一个向量。图注写的是 \(f(x,y) = [1\ \ 1]\)，正文写的是 \([1\ \ 2]\)5。
  • 例 8.7（向内流 Inward Flow）：图 8.5b 给每个 \((x,y)\) 指定 \([-x\ \ -y]\)，所有向量都指向原点。
  • 例 8.8（漩涡 Swirl）：图 8.6 给每个 \((x,y)\) 指定 \([(y-x)\ \ (-x-y)]\)。

由于规划问题里有障碍，有时方便把向量场的定义域限制在 \(\mathbb{R}^n\) 的一个开子集 \(O\) 上：\(f: O\to\mathbb{R}^n\)。

光滑性 Smoothness

从 \(\mathbb{R}^n\) 的子集到 \(\mathbb{R}\) 的函数 \(f_i\)，若在定义域每一点对任意变量都能求任意阶导数，就称为光滑函数 smooth function；若定义向量场的 \(n\) 个函数都光滑，向量场就是光滑的。光滑函数也叫 \(C^\infty\) 函数，上标表示可以求导的阶数；\(C^k\) 函数至少能求到 \(k\) 阶导数，\(C^0\) 就是连续函数。同胚的概念可以推广成微分同胚 diffeomorphism：本身光滑的同胚。两个拓扑空间之间若存在微分同胚，就称它们微分同胚 diffeomorphic。

把向量场看成速度场 Vector fields as velocity fields

给向量场一个具体的解释。用 (8.10) 表示的向量场可以定义一组一阶微分方程：

$$\frac{dx_1}{dt} = f_1(x_1,\ldots,x_n),\quad \frac{dx_2}{dt} = f_2(x_1,\ldots,x_n),\quad \ldots,\quad \frac{dx_n}{dt} = f_n(x_1,\ldots,x_n). \tag{8.11}$$

每个方程表示一个坐标对时间的导数。对任何点 \(x\in\mathbb{R}^n\)，速度向量 velocity vector 定义为

$$\frac{dx}{dt} = \left[\frac{dx_1}{dt}\ \ \frac{dx_2}{dt}\ \ \cdots\ \ \frac{dx_n}{dt}\right], \tag{8.12}$$

于是 \(f\) 可以解释为速度场 velocity field。习惯上简写 \(\dot x = dx/dt\)，\(\dot x_i = dx_i/dt\)；用 \(f\) 表示 \(f_1,\ldots,f_n\) 构成的向量，(8.11) 简写成

$$\dot x = f(x). \tag{8.13}$$

这里的 \(f\) 有意和状态转移函数用同一个字母：Part IV 会让向量场由动作参数化，得到连续时间状态转移方程 \(\dot x = f(x,u)\)，和第 2 章离散阶段上的状态转移方程很像。(8.11) 这样的方程常称为自治的 autonomous 或平稳的 stationary，因为 \(f\) 不依赖时间；也可以定义时变向量场 \(\dot x = f(x(t),t)\)，但本章不讨论。

积分曲线 An integral curve

给定向量场 \(f\)，每点都有速度向量。设一个点在 \(t=0\) 时从 \(x_0\in\mathbb{R}^n\) 出发，按 \(f\) 给的速度运动——它该怎么走？从 \(x_0\) 出发的轨迹 trajectory 可以写成函数 \(\tau:[0,\infty)\to\mathbb{R}^n\)。若对每个 \(t\in[0,\infty)\)

$$\frac{d\tau}{dt}(t) = f(\tau(t)), \tag{8.14}$$

就称这条轨迹是微分方程在初始条件 \(\tau(0) = x_0\) 下的积分曲线 integral curve（或解轨迹 solution trajectory）。它有时也写成积分形式

$$\tau(t) = x_0 + \int_0^t f(\tau(s))\,ds, \tag{8.15}$$

称为 Carathéodory 意义下的解。直观上，积分曲线从 \(x_0\) 出发，顺着速度向量指的方向流动——这就是图 8.2b「顺着箭头走」的连续版本。

例 8.9（常值速度场的积分曲线）：最简单的情形是常值向量场。设 \(\mathbb{R}^2\) 上定义了常值场 \(\dot x_1 = 1\)、\(\dot x_2 = 2\)6，从 \((0,0)\) 出发的积分曲线是 \(\tau(t) = (t, 2t)\)，显然对所有 \(t\ge 0\) 满足 (8.14)。

例 8.10（线性速度场的积分曲线）：\(\mathbb{R}^2\) 上 \(\dot x_1 = -2x_1\)、\(\dot x_2 = -x_2\)。函数 \(\tau(t) = (e^{-2t}, e^{-t})\) 是从 \((1,1)\) 出发的积分曲线：\(t=0\) 时 \(\tau(0) = (1,1)\)，对所有 \(t > 0\) 满足 (8.14)。这是线性速度场的简单例子：每个 \(f_i\) 都是坐标的线性函数。一般地，把速度场写成 \(\dot x = Ax\) 后，积分曲线通常通过求矩阵 \(A\) 的特征值得到（见 [23]）。

微分方程的一个基本结论：若 \(f\) 光滑，\(\dot x = f(x)\) 存在唯一的积分曲线。另一个保证唯一解的条件是 \(f\) 满足 Lipschitz 条件：存在常数 \(c\in(0,\infty)\) 使

$$\|f(x) - f(x')\| \le c\,\|x - x'\| \tag{8.16}$$

对所有 \(x, x'\in X\) 成立，\(\|\cdot\|\) 是欧氏范数。常数 \(c\) 称为 Lipschitz 常数。满足 Lipschitz 条件的 \(f\) 一定连续；若 \(f\) 的所有偏导数在整个 \(X\) 上有界，\(f\) 就是 Lipschitz 的。(8.16) 更一般——它甚至不要求 \(f\) 处处可微。

分段光滑向量场与 Filippov 解 Piecewise-smooth vector fields

以后要允许只在有限个片 patch 上光滑的向量场：两片之间的切换边界 switching boundary 上可能发生不连续的跳变。例如定义 \((n-1)\) 维切换边界 \(S\subset\mathbb{R}^n\)：

$$S = \{x\in\mathbb{R}^n \mid s(x) = 0\}, \tag{8.17}$$

\(s:\mathbb{R}^n\to\mathbb{R}\)。若 \(\mathbb{R}^n\) 维数为 \(n\) 且 \(s\) 非奇异，\(S\) 的维数为 \(n-1\)。再定义

$$S_+ = \{x\in\mathbb{R}^n \mid s(x) > 0\} \tag{8.18}$$
$$S_- = \{x\in\mathbb{R}^n \mid s(x) < 0\}. \tag{8.19}$$

这和 3.1.2 节用几何基元构造隐式模型类似。设 \(f\) 在 \(S_+\)、\(S_-\) 上光滑，但在 \(S\) 处跳变。这样的微分方程描述混合系统 hybrid systems [18, 47, 65]，相应的任务是设计混合控制系统 hybrid control system。这时还能定义解轨迹吗？在一定条件下可以得到 Filippov 意义下的解（书中拼作 Filipov）[45, 84]。

记 \(B(x,\delta)\) 为以 \(x\) 为中心、半径 \(\delta\) 的开球，

$$f(B(x,\delta)) = \{x'\in X \mid \exists x''\in B(x,\delta) \text{ 使 } x' = f(x'')\}. \tag{8.20}$$

记 \(X_0\) 为 \(\mathbb{R}^n\) 中任意零测子集（\(\mu(X_0) = 0\)），\(\mathrm{hull}(A)\) 为点集 \(A\) 的凸包。路径 \(\tau:[0,t_f]\to\mathbb{R}^n\) 若对几乎所有 \(t\in[0,t_f]\) 满足

$$\frac{d\tau}{dt}(t) \in \bigcap_{\delta>0}\left\{\bigcap_{X_0}\mathrm{hull}\big(f(B(\tau(t),\delta)\setminus X_0)\big)\right\}, \tag{8.21}$$

就称为 Filippov 意义下的解，交集取遍所有 \(\delta>0\) 和所有零测集 \(X_0\)。(8.21) 实际上是一个微分包含 differential inclusion [7]，因为 \(\dot x\) 可以有一组选择。「几乎所有」允许条件在 \([0,t_f]\) 的一个零测集上不成立。直观地说：\(\tau\) 产生的几乎所有速度向量必须指在 \(\tau(t)\) 附近 \(f\) 给出的那些向量「之间」——「之间」来自凸包。Filippov 的解概念是 Carathéodory 解的惊人推广：后者要求每个速度向量都与 \(f(x(t))\) 一致 (8.14)，而 (8.21) 允许各种「马虎」，甚至允许 \(f\) 不连续。

很多奇怪的向量场都有 Filippov 意义下的解，切换边界模型在其中算相对简单的。图 8.7 列出切换边界处可能出现的几种情形：

  • 一致流 consistent flow：解和直觉一致。(8.21) 要求在 \(S\) 上速度在穿越前后的两个向量之间（例如两个方向的平均），大小也在两者之间。
  • 向内流 inward flow：设 \(S\) 上的向量（在凸包意义下）与两侧向量方向一致，积分曲线就沿 \(S\) 运动。物理系统里这可能造成在 \(S\) 附近来回振荡；可以通过正则化 regularization——把边界加厚 [84]——来缓解（这是滑模控制 sliding-mode control 的主题 [40]）。
  • 向外流 outward flow：若初态在 \(S\) 上可能导致解不唯一；但从 \(S\) 外出发的轨迹不会穿过 \(S\)，就没有麻烦。
  • 切向流 tangent flow：两侧都平行于边界，会出现其它形式的不唯一。本章避免这种情形。

8.3.2 光滑流形 Smooth Manifolds

4.1.2 节的流形定义常被称为拓扑流形 topological manifold，它的公理不一定足以支持微分、积分等微积分运算。我们想讨论配置空间 \(\mathcal{C}\)（或一般连续状态空间 \(X\)）上的速度；第 4 章说过 \(\mathcal{C}\) 可能是 \(\mathbb{RP}^3\) 这样的流形，所以流形还要有更多性质才能做微积分——这引出光滑流形 smooth manifold。

设 \(M\) 是拓扑流形，例如表示 \(\mathbb{R}^3\) 中所有旋转矩阵的 \(SO(3)\)；更简单好记的例子是 \(M = \mathbb{S}^2\)。要把 8.3.1 节的概念从 \(\mathbb{R}^n\) 推广到流形，首先要定义点 \(p\in M\) 处的切空间 \(T_p(M)\)：直觉上切向量与曲面相切（图 8.8：切空间是流形在 \(p\) 邻域内的线性近似），表示从 \(p\) 出发沿流形运动的可能速度。这比 \(\mathbb{R}^n\) 难：\(\mathbb{R}^n\) 的任何点都能用 \(n\) 个坐标表示，所有切空间的局部坐标系完全对齐；而对 \(\mathbb{S}^2\) 这样的流形，切空间的定义必须与坐标无关，并且处理「绕 \(\mathbb{S}^2\) 走一圈时切平面跟着转」的事实。

先仔细想想给流形赋坐标是什么意思。设 \(M\) 的维数为 \(n\)、嵌在 \(\mathbb{R}^m\) 中：\(SO(3)\) 有 \(n = 3\)、\(m = 9\)；\(\mathbb{S}^2\) 有 \(n=2\)、\(m=3\)。坐标个数应该是 \(n\)，但嵌在 \(\mathbb{R}^m\) 中的流形常表示为满足若干等式约束的 \(\mathbb{R}^m\) 子集。我们想用 \(\mathbb{R}^n\) 的坐标表示 \(M\) 的一部分。

坐标与参数化 Coordinates and parameterizations

对任何开集 \(U\subseteq M\) 和函数 \(\phi: U\to\mathbb{R}^n\)，若 \(\phi\) 是到 \(\mathbb{R}^n\) 某子集的同胚，则称 \((U,\phi)\) 为坐标邻域 coordinate neighborhood（有些文献叫图 chart）。值 \(\phi(p)\) 称为 \(p\in U\) 的坐标 coordinates。

例 8.11（\(\mathbb{S}^1\) 上的坐标邻域）：把 \(M = \mathbb{S}^1\) 表示为嵌在 \(\mathbb{R}^2\) 中的单位圆（\(x^2+y^2=1\) 的解集）。令 \(U\) 为 \(\mathbb{S}^1\) 中 \(x>0\) 的子集，坐标函数 \(\phi: U\to(-\pi/2,\pi/2)\) 定义为 \(\phi(x,y) = \tan^{-1}(y/x)\)。记 \(W = \phi(U)\)。因为 \(U\) 与 \(W\) 经 \(\phi\) 同胚，也能定义逆函数 \(\phi^{-1}\)——它就是熟悉的参数化 parameterization：\(\theta\mapsto(\cos\theta,\sin\theta)\)，只是限制在 \(\theta\in(-\pi/2,\pi/2)\)。

要在点 \(p\in M\) 处求导，需要定义在包含 \(p\) 的开子集上的坐标邻域——因为在一点定义函数的导数需要它周围有一个开集；坐标看起来没有边界时就没问题。可惜，除非 \(M = \mathbb{R}^n\)（或至少与 \(\mathbb{R}^n\) 同胚），一个坐标邻域盖不住整个 \(M\)。于是要定义多个邻域，让它们的定义域覆盖 \(M\)；每个定义域都是开集，所以有些必然重叠。这时同一个点可能有两组或更多坐标，从一组换到另一组就是微积分里熟悉的坐标变换 change of coordinates。设 \((U,\phi)\)、\((V,\psi)\) 是某个流形上的坐标邻域，\(U\cap V\neq\emptyset\)。图 8.9 说明了从 \(\phi\) 换到 \(\psi\)：用函数复合 \(\psi\circ\phi^{-1}:\mathbb{R}^n\to\mathbb{R}^n\)（\(\phi^{-1}\) 从 \(\mathbb{R}^n\) 映到 \(M\)，\(\psi\) 从 \(M\) 的子集映到 \(\mathbb{R}^n\)）。

例 8.12（坐标变换）：在 \(M = SO(3)\) 上从欧拉角换到四元数。\(SO(3)\) 是 3 维流形，坐标邻域要把 \(SO(3)\) 的点映到 \(\mathbb{R}^3\)。可以由旋转矩阵算欧拉角，构造坐标函数 \(\phi:SO(3)\to\mathbb{R}^3\)，具体见 (3.47)–(3.49)；要成为坐标邻域，还得指定 \(M\) 的开子集 \(U\)。另一个坐标函数 \(\psi:SO(3)\to\mathbb{R}^3\) 用四元数：四元数有四个分量，看似是问题，但第四个可以由另外三个决定，用 (4.24)–(4.26) 求出 \(a,b,c\)。在重叠区域 \(U\cap V\) 上从欧拉角换到四元数：先在 \(U\) 上求 \(\phi\) 的逆，即用欧拉角参数化 \(M\)，由 (3.42) 给出旋转矩阵 \(\phi^{-1}(\alpha,\beta,\gamma)\in SO(3)\)；再对它施加 \(\psi\) 得到四元数参数——这样就得到三个实值函数 \(a = f_1(\alpha,\beta,\gamma)\)、\(b = f_2(\alpha,\beta,\gamma)\)、\(c = f_3(\alpha,\beta,\gamma)\)，合起来就是 \(\psi\circ\phi^{-1}\)。

做坐标变换的理由很多。例 8.12 来自运动规划里常见的情形：图形软件用四元数显示物体，碰撞检测却用欧拉角，于是要频繁换坐标；微积分里也常换元来简化积分。光滑流形的定义里还有另一个动机：坐标邻域基于开集上的同胚，可能需要好几个才能覆盖 \(M\)；即使 \(SO(3)\) 决定用四元数，也可能需要好几个映到四元数的坐标邻域，在它们定义域的交上就需要坐标变换。

定义：光滑结构 smooth structure 与光滑流形

（拓扑）流形 \(M\) 上的光滑结构（也叫 differentiable structure、\(C^\infty\) structure）是一族（也叫 atlas）坐标邻域 \(\mathcal{U} = \{U_\alpha,\phi_\alpha\}\)，满足：

  1. 所有 \(U_\alpha\) 的并包含 \(M\)：\(M\) 中任何点都能在 \(\mathbb{R}^n\) 中取得坐标。
  2. 对 \(\mathcal{U}\) 中任意 \((U,\phi)\)、\((V,\psi)\)，若 \(U\cap V\neq\emptyset\)，则坐标变换 \(\psi\circ\phi^{-1}\) 和 \(\phi\circ\psi^{-1}\) 都是 \(U\cap V\) 上的光滑函数（在交上给出微分同胚）。此时称这些坐标邻域相容 compatible。
  3. \(\mathcal{U}\) 是极大的：若某个 \((U,\phi)\) 与 \(\mathcal{U}\) 中每个坐标邻域都相容，它就必须属于 \(\mathcal{U}\)。

一个著名定理（[17] 第 54 页）：若一组相容的坐标邻域覆盖了整个 \(M\)，则存在唯一包含它们的光滑结构（假设 \(M\) 是 Hausdorff 的且有可数基——这里考虑的流形都满足）。所以光滑结构常常只需少数几个邻域来指定，其余都是隐含的。4.1.2 节定义的流形加上光滑结构，称为光滑流形 smooth manifold（也叫 differentiable manifold、\(C^\infty\) manifold）。

例 8.13（\(\mathbb{R}^n\) 作为光滑流形）：前面的概念理应适用于最直接的一族流形 \(\mathbb{R}^n\)：用单个坐标邻域 \(\mathbb{R}^n\to\mathbb{R}^n\)（恒等映射）即可。对整数 \(n\in\{1,2,3\}\) 和 \(n>4\)，这是 \(\mathbb{R}^n\) 上唯一的光滑结构。真正令人惊讶的是，\(\mathbb{R}^4\) 上有不可数多个互不相容的光滑结构，称为奇异 \(\mathbb{R}^4\) exotic \(\mathbb{R}^4\) [38]。不过不用担心，用恒等映射给出的那个就好。

例 8.14（\(\mathbb{S}^n\) 作为光滑流形）：把 \(\mathbb{S}^n\) 定义成光滑流形的一种办法用 \(2(n+1)\) 个坐标邻域，表达式很简单。设

$$\mathbb{S}^n = \{(x_1,\ldots,x_{n+1})\in\mathbb{R}^{n+1} \mid x_1^2+\cdots+x_{n+1}^2 = 1\}. \tag{8.22}$$

对每个 \(i\) 从 1 到 \(n+1\)，有两个邻域：

$$U_i^+ = \{(x_1,\ldots,x_{n+1})\in\mathbb{R}^{n+1} \mid x_i > 0\} \tag{8.23}$$
$$U_i^- = \{(x_1,\ldots,x_{n+1})\in\mathbb{R}^{n+1} \mid x_i < 0\}. \tag{8.24}$$

每个邻域都是覆盖半个 \(\mathbb{S}^n\) 的开集，漏掉 \(x_i = 0\) 的大圆。坐标函数是向包含该大圆的超平面作投影：去掉第 \(i\) 个坐标，

$$\phi_i^+(x_1,\ldots,x_{n+1}) = (x_1,\ldots,x_{i-1},x_{i+1},\ldots,x_{n+1}) \tag{8.25}$$

定义在 \(U_i^+\) 上；\(\phi_i^-\) 同样定义，只是在 \(U_i^-\) 上。每个坐标函数都是从 \(\mathbb{S}^n\) 的开子集到 \(\mathbb{R}^n\) 的开子集的同胚。在邻域重叠的子集上，坐标变换是光滑的。例如从 \(\phi_i^+\) 换到 \(\phi_j^-\)（\(i\ne j\)），坐标变换是 \(\phi_j^-\circ(\phi_i^+)^{-1}\)，其中

$$\begin{aligned}&(\phi_i^+)^{-1}(x_1,\ldots,x_{i-1},x_{i+1},\ldots,x_{n+1}) = \\ &\qquad\Big(x_1,\ldots,x_{i-1},\sqrt{1-x_1^2-\cdots-x_{i-1}^2-x_{i+1}^2-\cdots-x_{n+1}^2},\,x_{i+1},\ldots,x_{n+1}\Big).\end{aligned} \tag{8.26}$$

再与 \(\phi_j^-\) 复合就去掉第 \(j\) 个坐标：

$$\begin{aligned}&\phi_j^-\circ(\phi_i^+)^{-1}(x_1,\ldots,x_{i-1},x_{i+1},\ldots,x_{n+1}) = \\ &\qquad\Big(x_1,\ldots,x_{i-1},\sqrt{1-x_1^2-\cdots-x_{i-1}^2-x_{i+1}^2-\cdots-x_{n+1}^2},\\ &\qquad\ \ x_{i+1},\ldots,x_{j-1},x_{j+1},\ldots,x_{n+1}\Big),\end{aligned} \tag{8.27}$$

它在 \(U_i^+\)（与 \(U_j^-\) 的交）上光滑。上面三个式子按改正后的写法给出，原书 (8.25)–(8.27) 有几处笔误：根号前多了「\(1-\)」、\(\phi_k^-\) 应为 \(\phi_j^-\)、下标 \(x_n\) 应到 \(x_{n+1}\)7。不妨想象一下圆 \(\mathbb{S}^1\) 和球面 \(\mathbb{S}^2\) 上的坐标变换（下面的互动图就是 \(\mathbb{S}^1\) 的情形）。也可以只用两个坐标邻域定义光滑结构——球极投影 stereographic projection：对 \(\mathbb{S}^2\)，一个坐标函数从北极向 \(x\) 画射线，把 \(x\) 映到射线穿过 \(x_3 = 0\) 平面的那一点，只排除北极本身；从南极可以构造类似的映射。

例 8.15（\(\mathbb{RP}^n\) 作为光滑流形）：这个例子特别重要，因为 \(\mathbb{RP}^3\) 与 \(SO(3)\) 是同一个流形（4.2.2 节）。回忆 \(\mathbb{RP}^n\) 是 \(\mathbb{R}^{n+1}\) 中所有过原点的直线：对任何 \(\alpha\ne 0\) 和 \(x\in\mathbb{R}^{n+1}\)，\(x\) 与 \(\alpha x\) 被等同——投影空间里尺度无关紧要。只需 \(n+1\) 个坐标邻域：对 \(i\) 从 1 到 \(n+1\)，在 \(x_i\ne 0\) 的开集上

$$\phi_i(x_1,\ldots,x_{n+1}) = (x_1/x_i,\ldots,x_{i-1}/x_i,x_{i+1}/x_i,\ldots,x_{n+1}/x_i), \tag{8.28}$$
$$\phi_i^{-1}(z_1,\ldots,z_n) = (z_1,\ldots,z_{i-1},1,z_i,\ldots,z_n). \tag{8.29}$$

（原书两式最后一项的下标也有同样的笔误，见脚注 7。）不难验证这些简单变换在重叠的邻域上光滑。\(SO(3)\) 上的光滑结构可以作为特例：\(SO(3)\) 与 \(\mathbb{RP}^3\) 拓扑等价。用单位四元数表示 \(SO(3)\) 的元素，每个 \((a,b,c,d)\) 看成 \(\mathbb{S}^3\) 上一点；有四个坐标邻域，例如

$$\phi_b(a,b,c,d) = (a/b,\ c/b,\ d/b), \tag{8.30}$$

定义在 \(\mathbb{R}^4\) 中 \(b\ne 0\) 的子集上。\(\phi_b\) 的逆要定义成把 \(SO(3)\) 中的点映到 \(\mathbb{R}^4\) 中单位长度的点。

流形上的切空间 Tangent spaces on manifolds

直观上，\(n\) 维流形 \(M\) 在 \(p\) 处的切空间 \(T_p(M)\)，是 \(\mathbb{R}^m\) 中在 \(p\) 附近最好地近似 \(M\) 的 \(n\) 维超平面（把超平面的原点平移到 \(p\)，图 8.8）。7.4.1 节描述闭链的局部运动时就用过切线的概念（图 7.22）。

要在流形上定义切空间，先比 8.3.1 节更复杂地定义 \(\mathbb{R}^n\) 中一点的切空间。设 \(M = \mathbb{R}^2\)，考虑光滑函数 \(f:\mathbb{R}^2\to\mathbb{R}\) 在 \(p\in\mathbb{R}^2\) 处的方向导数。对某个（未归一化的）方向向量 \(v\in\mathbb{R}^2\)，\(f\) 在 \(p\) 处的方向导数是

$$\nabla_v(f)\Big|_p = v_1\frac{\partial f}{\partial x_1}\Big|_p + v_2\frac{\partial f}{\partial x_2}\Big|_p. \tag{8.31}$$

这里的方向导数不归一化方向向量（与基础微积分不同），所以 \(\nabla_v(f) = \nabla(f)\cdot v\)，\(\cdot\) 是内积，\(\nabla(f)\) 是梯度。所有能用来构造方向导数的方向向量构成一个二维向量空间，恰好就是前面定义的切空间 \(T_p(\mathbb{R}^2)\)。推广到 \(n\) 维：

$$\nabla_v(f)\Big|_p = \sum_{i=1}^n v_i\frac{\partial f}{\partial x_i}\Big|_p, \tag{8.32}$$

所有可能的方向向量构成切空间 \(T_p(\mathbb{R}^n)\)；就我们的目的，方向的集合可以理解为可能的速度向量的集合。

现在考虑流形上光滑函数 \(f:M\to\mathbb{R}\) 的（未归一化）方向导数。对 \(n\) 维流形，\(p\in M\) 处的切空间 \(T_p(M)\) 同样可以看成所有未归一化方向的集合——直觉上这些方向必须与流形相切（图 8.8）。有一个巧妙的办法可以不借助具体坐标邻域来定义它们，得到流形内蕴的 \(T_p(M)\) 定义。你可以只接受「\(T_p(M)\) 是附着在 \(p\) 处、如图 8.8 那样定向的 \(n\) 维向量空间」；为了完整，书中给出微分几何的技术定义（细节见 [17, 86]）：它刻画所有可能的方向导数算子。记 \(C^\infty(p)\) 为定义域包含 \(p\) 的所有光滑函数，并作等同：若存在开集 \(U\subset M\) 使对任何 \(p\in U\) 有 \(f(p) = g(p)\)，就称 \(f,g\in C^\infty(p)\) 等价（等价函数的导数在 \(p\) 处必然相同，不必区分）。记等同后的集合为 \(\tilde C^\infty(p)\)。\(p\) 处的方向导数算子可以看成从 \(\tilde C^\infty(p)\) 到 \(\mathbb{R}\) 的函数（对 \(\mathbb{R}^n\) 就是 \(\nabla_v\)）。设 \(\nabla_v\) 是 \(p\in M\) 处的方向导数算子（小心：这里 \(v\) 并没有显式表示，因为没有坐标），它必须满足两条公理：

  1. 线性：对任何 \(\alpha,\beta\in\mathbb{R}\)、\(f,g\in\tilde C^\infty(p)\)，
    $$\nabla_v(\alpha f + \beta g) = \alpha\nabla_v f + \beta\nabla_v g. \tag{8.33}$$
  2. Leibniz 法则（导子 Derivation）：对任何 \(f,g\in\tilde C^\infty(p)\)，
    $$\nabla_v(fg) = \nabla_v f\, g(p) + f(p)\,\nabla_v g. \tag{8.34}$$

这些公理在标准向量微积分里就是方向导数的性质。可以证明，满足这些公理的所有算子构成一个 \(n\) 维向量空间 [17]，它就是 \(p\) 处的切空间 \(T_p(M)\)——一个不引用坐标的定义。

不过显式表示 \(T_p(M)\) 中的向量还是有用的：用坐标邻域可以得到切空间的基。微分几何的一个重要定理：若 \(F: M\to N\) 是到开集 \(U\subset N\) 的微分同胚，则切空间 \(T_p(M)\) 与 \(T_{F(p)}(N)\) 同构。这意味着通过参数化（坐标邻域的逆），\(T_p(M)\) 中的速度向量与 \(T_{F(p)}(N)\) 中的速度向量一一对应：参数的微小扰动造成流形 \(N\) 上沿切向的运动。比如想象对表示 \(SO(3)\) 的三个四元数参数做微小扰动：扰动足够小时，得到的运动与 \(SO(3)\) 相切——扰动后的矩阵非常接近 \(SO(3)\)（它们不在 \(SO(3)\) 里，因为 \(SO(3)\) 由 \(\mathbb{R}^9\) 中的非线性约束定义，见 4.1.2 节）。

例 8.16（\(\mathbb{S}^2\) 的切空间）：把 \(\mathbb{S}^2\) 嵌在 \(\mathbb{R}^3\) 中，为满足 \(x^2+y^2+z^2=1\) 的点。用标准球坐标可以定义覆盖 \(\mathbb{S}^2\) 大部分的坐标邻域：坐标函数 \(f\) 把 \((x,y,z)\) 映到角度 \((\theta,\phi)\)，定义域是 \(\theta\in(0,2\pi)\)、\(\phi\in(0,\pi)\) 的开集（不含两极）。标准公式是 \(\theta = \mathrm{atan2}(y,x)\)、\(\phi = \cos^{-1} z\)；逆 \(f^{-1}\) 给出参数化 \(x = \cos\theta\sin\phi\)、\(y = \sin\theta\sin\phi\)、\(z = \cos\phi\)。考虑在 \(\mathbb{S}^2\) 上除两极以外的某点 \(p\) 表达切空间的不同方式（两极需要换坐标才能覆盖）。用坐标 \((\theta,\phi)\)，速度就是 \(\mathbb{R}^2\) 中的向量：可以想象在 \(\theta\)、\(\phi\) 定义的平面里运动，只要遵守 \(\theta\in(0,2\pi)\)、\(\phi\in(0,\pi)\) 的限制。也可以用参数化推出切空间在 \(\mathbb{R}^3\) 中的基向量：切空间只有两维，必须得到一个与球在 \(p\) 处「相切」的平面，对参数化求导即可。把 \(f^{-1}\) 记为 \(x(\theta,\phi)\)、\(y(\theta,\phi)\)、\(z(\theta,\phi)\)，\(p\) 处切平面的两个基向量是

$$\left[\frac{dx(\theta,\phi)}{d\theta}\ \ \frac{dy(\theta,\phi)}{d\theta}\ \ \frac{dz(\theta,\phi)}{d\theta}\right] \tag{8.35}$$
$$\left[\frac{dx(\theta,\phi)}{d\phi}\ \ \frac{dy(\theta,\phi)}{d\phi}\ \ \frac{dz(\theta,\phi)}{d\phi}\right]. \tag{8.36}$$

求导并归一化得到 \([-\sin\theta\ \ \cos\theta\ \ 0]\) 和 \([\cos\theta\cos\phi\ \ \sin\theta\cos\phi\ \ -\sin\phi]\)，可以想象成在 \(p\) 处对 \(\theta\) 和 \(\phi\) 做微小扰动的结果。它们所有线性组合构成的向量空间就是 \(p\) 处的切空间8。注意基向量的方向随 \(p\in\mathbb{S}^2\) 变化，这正如所料。切向量可以想象成位于与曲面相切的平面内（图 8.8）。由 \(g(x,y,z) = 0\) 给出的曲面的法向量是 \(\nabla g\)，归一化后得到 \([x\ \ y\ \ z]\)；也可以对上面两个向量作叉积，再用参数化 \(f^{-1}\) 用 \(x,y,z\) 表示出来。对点 \(p = (x_0,y_0,z_0)\)，切平面方程为

$$x_0(x-x_0) + y_0(y-y_0) + z_0(z-z_0) = 0. \tag{8.37}$$

流形上的向量场与速度场 Vector fields and velocity fields on manifolds

流形上切空间的记号与 \(\mathbb{R}^n\) 的一样，于是向量场的定义和记号可以自然地从 \(\mathbb{R}^n\) 推广到光滑流形：流形 \(M\) 上的向量场给每个 \(p\in M\) 指定一个 \(T_p(M)\) 中的向量。它仍然可以想象成针状图，只不过现在针状图铺在流形上，而不是 \(\mathbb{R}^n\) 中。速度场的解释也能推广到光滑流形：\(\dot x = f(x)\) 现在定义 \(M\) 上的 \(n\) 个微分方程，通常用光滑结构的某个坐标邻域来表达。若 \(f\) 是光滑向量场，就能从任何 \(x_0\in M\) 出发定义解轨迹 \(\tau:[0,\infty)\to M\)；对分段光滑向量场，也能定义 Filippov 意义下的解轨迹。

8.4.1 反馈运动规划的定义 Feedback Motion Planning Definitions

用 8.3 节的概念，现在可以在配置空间或其它连续状态空间上定义反馈运动规划了。回忆 Formulation 4.1 用配置空间定义了基本运动规划问题；这里的区别是没有初始条件，而且「解路径」换成了「解向量场」。这里的表述可以看成 Formulation 8.1 的连续时间版本。

Formulation 8.2（反馈运动规划 Feedback Motion Planning）
  1. 状态空间 \(X\)，是一个光滑流形，最常见的是 4.3.1 节定义的 \(\mathcal{C}_{free}\)（\(X\) 已经去掉了障碍区域；Part IV 的某些问题里状态空间是包含障碍区域的 \(X = \mathcal{C}\)）。
  2. 对每个状态 \(x\in X\)，动作空间 \(U(x) = T_x(X)\)。零速度 \(0\in T_x(X)\) 被指定为终止动作 \(u_T\)。按这个模型，机器人能在任何状态选择自己的速度（这允许速度不连续地变化，在很多应用中不现实；后面会讨论加速度界等额外约束，完整的微分约束见 Part IV）。
  3. 无界的时间区间 \(T = [0,\infty)\)。
  4. 状态转移（微分）方程
    $$\dot x = u, \tag{8.38}$$
    用某个坐标邻域表达，给出由动作 \(u\) 直接指定的速度 \(\dot x\)。\(u_T\) 产生的速度是 \(0\in T_x(X)\)（意思是「停下」）。
  5. 目标集 \(X_G\subset X\)。

Formulation 8.2 的反馈计划 \(\pi\) 是一个函数，对每个 \(x\in X\) 给出一个动作 \(u\in U(x)\)。由于每个 \(u\in U(x)\) 指定 \(T_x(X)\) 中的一个速度向量（\(u_T\) 指定零速度），反馈计划也可以等价地看成 \(X\) 上的向量场。因为初态不固定，说清楚「计划是问题的解」就稍微复杂一点。记 \(X_r\subset X\) 为能到达 \(X_G\) 的所有状态：\(x_I\in X_r\) 当且仅当存在连续路径 \(\tau:[0,1]\to X\) 使 \(\tau(0) = x_I\)、\(\tau(1) = x_G\) 对某个 \(x_G\in X_G\) 成立——也就是第 4 章「开环」运动规划问题从 \(x_I\) 有解。

解的概念 Solution concepts

若从所有 \(x_I\in X_r\) 出发，\(\pi\)（看作向量场）的积分曲线都到达 \(X_G\)，并在那里施加终止动作，就称 \(\pi\) 为 Formulation 8.2 的解。「到达」\(X_G\) 是什么意思要小心。控制理论的稳定性概念 [51, 84] 可以区分各种情形（15.1 节）。若 \(X_G\) 是以 \(x_G\) 为中心的小球，用图 8.5b 的向内场，有限时间内就能到达这个球。但若 \(X_G\) 是单点 \(x_G\)：向内场让状态越来越近，可什么时候真正到达？这种情形下收敛到原点只是渐近的 asymptotic——时间趋于无穷时在极限意义下到达。光滑向量场常产生这种稳定性；若向量场光滑而目标是一个点，这是不可避免的。我们可以允许这种渐近收敛：若积分曲线只是渐近收敛到 \(X_G\)，就称为渐近解计划 asymptotic solution plan。注意一般不可能要求 \(\pi\) 是光滑（甚至连续）的非零向量场——例如由毛球定理 hairy ball theorem [81]，对任何偶数 \(n\)，\(\mathbb{S}^n\) 上不存在这样的向量场。所以最强的可能要求是 \(\pi\) 除零测集外光滑（见 8.4.4 节）。也可以允许几乎所有积分曲线到达 \(X_G\) 的 \(\pi\)。

不过本章默认解计划在有限时间内收敛到 \(x_G\)。例如把向内场归一化，使除原点外速度处处为 1，原点就能在有限时间内到达。可以对允许的向量场集合加一个约束而不影响解的存在性：和基本运动规划一样，沿路径的速率并不重要。称向量场为归一化向量场 normalized vector field：若对所有 \(x\in X\)，\(\|f(x)\| = 1\) 或 \(f(x) = 0\)——所有速度向量要么是单位向量要么是零，速率不再是因素，归一化向量场给出的只是运动方向或「不动」。任何向量场 \(f\) 都可以把每个 \(f(x)\) 除以它的模长（模长为零时除外）来归一化。

很多时候单位速率在物理意义上并不意味着恒速。例如机器人是浮动刚体时，位置和姿态有很多种参数化方式，刚体的速度对参数化很敏感。所以有时别的约束比 \(\|f(x)\| = 1\) 更好；但要记住，施加这个约束是为了让 \(f(x)\) 在 \(x\) 处给出一个方向，具体大小被认为不重要。

以上只考虑了可行反馈运动规划问题。引入代价泛函就可以定义最优反馈运动规划问题。记 \(\tilde x_t\) 为函数 \(\tilde x_t:[0,t]\to X\)，称为状态轨迹（或状态历史），是前面离散阶段状态历史的连续时间版本；类似地记 \(\tilde u_t:[0,t]\to U\) 为动作轨迹（或动作历史）。代价泛函 \(L\) 可以从任何 \(x_I\) 出发计算：

$$L(\tilde x_{t_F}, \tilde u_{t_F}) = \int_0^{t_F} l(x(t),u(t))\,dt + l_F(x(t_F)), \tag{8.39}$$

\(t_F\) 是施加终止动作的时刻。用状态转移方程 (8.38)，\(l(x(t),u(t))\) 也可以写成 \(l(x(t),\dot x(t))\)。对所有能到达目标的初态都优化 (8.39) 的归一化向量场，称为最优反馈运动计划。

注意：状态轨迹可以由动作历史和初态确定。其实第 4 章本可以用动作轨迹来定义运动规划问题的解路径；当时把解定义为路径 \(\tau:[0,1]\to\mathcal{C}_{free}\)，是为了避免引入光滑流形上的速度场。书中说：那是全书唯一一处「动作空间好像消失了」的地方，现在可以看出，它只是为了避免不必要的记号而藏了起来。

导航函数 Navigation functions

和 8.2.2 节一样，只要给连续状态空间配一个局部算子，势函数就能表示反馈计划。离散情形下局部算子选一个让势下降的动作；连续情形下，局部算子要把势函数转成向量场——每个状态都要定义一个速度向量。默认假设由导航函数导出的向量场不一定归一化。设对所有 \(x\in X_G\)，不管势函数是什么都定义 \(\pi(x) = u_T\)。设势函数 \(\phi:X\to\mathbb{R}\) 的梯度

$$\nabla\phi = \left[\frac{\partial\phi}{\partial x_1}\ \ \frac{\partial\phi}{\partial x_2}\ \ \cdots\ \ \frac{\partial\phi}{\partial x_n}\right] \tag{8.40}$$

在整个 \(X\setminus X_G\) 上存在。相应的反馈计划定义为 \(\pi(x) = -\nabla\phi|_x\)——这就是局部算子：速度取 \(\phi\) 最速下降的方向。用势函数做机器人规划的想法由 Khatib [52, 53] 提出，可以看成梯度下降这种一般优化技术的一种形式。

也可以使用梯度不是处处存在的势函数。这时对一个小的固定 \(\Delta t\)，定义 (8.4) 的连续版本：

$$u^* = \operatorname*{argmin}_{u\in U(x)}\Big\{\phi(x')\Big\}, \tag{8.41}$$

\(x'\) 是从 \(x\) 以速度 \(u\) 积分 \(\Delta t\) 时间得到的状态。一个问题是 \(\Delta t\) 应选得只用 \(\phi\) 尽可能小的邻域。最好只允许这样的势函数：在每个 \(x\) 处，\(\Delta t\) 可以任意小而不影响 (8.41) 的决策。精确地说：取一列收敛到 0 的 \(\Delta t\) 值，得到一列 \(u^*\)；势函数应保证从序列某一点之后，存在同一个 \(u^*\) 在 \(\Delta t\to 0\) 时满足 (8.41)。梯度存在是一个特例，此时这个序列收敛到负梯度。

若由势函数 \(\phi\) 导出的向量场是一个解计划，就称 \(\phi\) 为导航函数；最优 cost-to-go 是最优导航函数。若同一个 \(\phi\) 能导出多个向量场，每个都必须是解反馈计划。设计得当的话，势函数可以看成把状态引向 \(X_G\) 的「滑雪坡 ski slope」：若有多余的局部极小把状态困住，就到不了 \(X_G\)；作为导航函数，\(X_G\) 外不允许这样的局部极小。此外还可能有额外要求，以保证导出的向量场满足有界加速度等约束。

例 8.17（二次势函数）：设 \(X = \mathbb{R}^2\)，无障碍，\(q_{goal} = (0,0)\)。二次函数 \(\phi(x_1,x_2) = \frac12 x_1^2 + \frac12 x_2^2\)（书中写作 \(\phi(x,y)\)）是把状态引到目标的好势函数；反馈运动策略定义为 \(f = -\nabla\phi = [-x_1\ \ -x_2]\)，正是图 8.5b 的向内向量场。若目标改为 \((x'_1,x'_2)\in\mathbb{R}^2\)，引导状态到目标的势函数是 \(\phi(x_1,x_2) = (x_1-x'_1)^2 + (x_2-x'_2)^2\)。

设状态空间是含点障碍的配置空间。上面的 \(\phi\) 可以看成吸引势 attractive potential——位形被吸引向目标；也可以构造把位形推离障碍的排斥势 repulsive potential。记 \(\phi_a\) 为吸引分量、\(\phi_r\) 为排斥势，形如 \(\phi = \phi_a + \phi_r\) 的势函数把两种作用合在一起：机器人在避开障碍的同时被引向目标。问题在于，一般很难保证这样的势函数没有多个局部极小——位形可能被困在不在目标区域的局部极小里。5.4.3 节的规划器就有这个问题。

8.4.2 单元复形上的向量场 Vector Fields Over Cell Complexes

这一节说明怎样在单元复形上构造分段光滑的向量场，只考虑归一化向量场。假设复形中每个单元形状简单，容易在上面定义一片向量场。很多情况下，第 6 章为运动规划介绍的单元分解技术都可以用来构造反馈计划。

设 \(n\) 维状态空间 \(X\) 已分解成单元复形，例如 6.3.1 节定义的单纯复形或奇异复形；目标集是单点 \(x_G\)。在 \(X\) 上定义反馈计划 \(\pi\)，就是在 \(X\) 上放一个向量场，使所有积分曲线都通向 \(x_G\)（若 \(x_G\) 可达）。办法是在每个 \(n\)-单元上定义光滑向量场；每个 \((n-1)\)-单元是 8.3.1 节意义下的切换边界，于是直接得到 Filippov 意义下的解轨迹。若允许 \(\pi\) 不连续，那么维数 \(\le n-1\) 的单元上的值其实无关紧要。构造 \(\pi\) 采用分层方法：

  1. 在 \(n\)-单元上定义离散规划问题：含 \(x_G\) 的单元是目标，在单元上定义离散导航函数。
  2. 在每个 \(n\)-单元上定义向量场：让单元中所有状态按离散导航函数的规定流入下一个单元。

应用中还有一点很重要：尽量减小跨边界不连续的影响；也许能消除不连续，甚至在 \(n\)-单元之间构造光滑过渡。这里不讨论，但它在实际中相当重要 [26, 66]。

形式化一下。设连续状态空间 \(X\) 上已定义单元复形，记 \(\check X\) 为 \(n\)-单元的集合，可以解释为有限状态空间。为避免与原连续问题混淆，离散规划的各组成部分都加前缀「超 super」：每个超状态 \(\check x\in\check X\) 对应一个 \(n\)-单元；对每个相邻的 \(n\)-单元（两单元必须共享一个 \((n-1)\) 维边界），\(\check x\) 有一个超动作 \(\check u\in\check U(\check x)\)。目标超状态 \(\check x_g\) 是含 \(x_G\) 的 \(n\)-单元。设离散问题的代价泛函让每个动作（\(u_T\) 除外）代价为 1。于是 8.2 节的概念都可以用于离散问题：用 Dijkstra（或别的算法，特别是不要求最优时）算离散导航函数 \(\check\phi:\check X\to\mathbb{R}\)，用 8.2.2 节的离散局部算子得到离散反馈计划 \(\check\pi:\check X\to\check U\)。

按照离散反馈计划，\(n\)-单元分两类。第一类是目标单元 \(\check x_g\)：需要在其上定义向量场，使所有积分曲线在有限时间内到达 \(X_g\)（即使 \(X_g\) 是单点也能有限时间到达，因为向量场不连续；否则只可能渐近收敛）；真正到达 \(x_G\) 时施加终止动作。其余都是第二类：对每个单元 \(\check x\)，它与施加 \(\check u = \check\pi(\check x)\) 后到达的单元共享的边界称为出口面 exit face；单元 \(\check x\) 上的向量场必须让所有积分曲线通向出口面。到达出口面时进入下一个 \(n\)-单元。若 \(n\)-单元是凸的，定义这种过渡很直接（除非对场有额外要求，如边界处光滑）；对更复杂的单元，一种可能是定义一个把所有点收缩到单元内某条曲线上的向量场。

书中用 \(X = \mathcal{C}_{free}\subset\mathbb{R}^2\)、\(\mathcal{C}_{free}\) 边界为多边形的情形说明（6.2 节考虑过这个问题，但没有反馈）。设已按 6.3.2 节算出 \(X\) 的三角剖分（例子见图 6.16）。图 8.10 为某个目标给出离散反馈计划：每个 2-单元（三角形）标一个指向下一个单元的箭头。含 \(x_G\) 的单元：把图 8.5b 的向内向量场的每个非零向量除以模长得到归一化版本，再平移使原点落在 \(x_G\)。其余每个三角形都要构造流入相应相邻单元的向量场，图 8.11 给出一个简单办法：把图 8.5b 的场取负得到向外的场 \(f = [x\ \ y]\)，归一化后平移，让原点落在三角形中不与出口边相接的那个顶点——图 8.11 称它为排斥顶点 repulsive vertex。它把三角形里所有点推向出口边。若每个三角形都这样构造，全局向量场就是问题的一个解反馈计划，（Filippov 意义下的）积分曲线在有限时间内到达 \(x_G\)。

8.4.3 最优导航函数 Optimal Navigation Functions

上一节的向量场给出可行轨迹，但除非初态和目标在同一个凸 \(n\)-单元里，一般不是最优的。若 \(X = \mathbb{R}^2\)，可以做 Dijkstra 的连续版本 [74]：在 \(X\) 上得到基于到目标 \(x_G\) 的欧氏最短路的精确 cost-to-go 函数。这个 cost-to-go 函数就是导航函数，由局部最速下降定义反馈计划。

设 \(X\) 由一个简单多边形（无洞）围成，只允许归一化向量场，代价泛函是沿状态轨迹走过的欧氏距离。回忆 6.2.4 节：最优路径规划必须用 \(X = \mathrm{cl}(\mathcal{C}_{free})\)。假设 \(\mathcal{C}_{free}\) 与 \(\mathrm{cl}(\mathcal{C}_{free})\) 连通性相同（这排除了「加上边界点后能走出一条不同伦路径」的 \(\mathcal{C}_{free}\)，例如 \(\mathbb{R}^2\) 中两个方形障碍只在一对角点上接触）。这在技术上与 8.3 节切空间的定义冲突——\(X\) 的每个点都必须含于一个开邻域；不过我们允许沿边界的向量，只要它们「指向」与边界相切的方向。形式上可以把边界区域看成单独的流形。

考虑为图 8.12a 那样的问题计算到点 \(x_G\) 的最优 cost-to-go。对任何 \(x\in X\)，记 \(V(x)\) 为从 \(x\) 可见的所有点构成的可见多边形 visibility polygon（图 8.12b）：\(x'\in V(x)\) 当且仅当线段 \(x'x\) 含于 \(X\)。这意味着从 \(x'\) 到 \(x\) 的 cost-to-go 就是欧氏距离。于是可以立即在 \(V(x_G)\) 上定义最优导航函数：

$$\phi(x) = \|x - x_G\|. \tag{8.42}$$

图 8.13a 画出了它在等间距取值上的等值线。\(X\setminus V(x_G)\) 中的点怎么办？对任何 \(x\in X\)，\(V(x)\) 边界上的线段有的在 \(X\) 的边界上，有的穿过 \(X\) 的内部；图 8.12b 中有两条边穿过内部。对每条穿过内部的线段，把两个端点中离 \(x\) 较近的那个称为路点 way point。图 8.12b 标出了两个路点。\(V(x_G)\) 的路点是某些最优路径必须经过的地方。对任何 \(x\in X\)，记 \(W(x)\) 为 \(V(x)\) 的路点集合。

一个直接的算法：记 \(Z_i\) 为第 \(i\) 次迭代时 \(\phi\) 已定义的点集。第一次迭代 \(Z_1 = V(x_G)\)（图 8.13a）。把 \(V(x_G)\) 的路点放进队列 \(Q\)。之后每次迭代，从 \(Q\) 取出一个路点 \(x\)；\(Z_i\) 是至今的定义域，把 \(\phi\) 的定义域扩展到从 \(x\) 可见的所有新点 \(V(x)\setminus Z_i\)，于是 \(Z_{i+1} = Z_i\cup V(x)\)。对 \(x'\in Z_{i+1}\setminus Z_i\)，

$$\phi(x') = \phi(x) + \|x' - x\|, \tag{8.43}$$

其中 \(x\) 是从 \(Q\) 取出的路点（它的最优 cost-to-go 已经算好）。\(V(x)\) 中不在 \(Z_{i+1}\) 里的路点加入 \(Q\)，每个都会揭示 \(X\) 中还没见过的新部分。\(Q\) 为空时算法结束，此时对某个 \(k\) 有 \(Z_k = X\)。图 8.13 演示了算法的执行（四次迭代，每次从一个新路点扩展）。

若 \(X\) 由 \(n\) 条边描述，可见多边形可以在 \(O(n\lg n)\) 时间内算出：用径向扫描 radial sweep——6.2.2 节竖直单元分解方法的改编，区别在于以 \(x\) 为锚的射线像雷达一样径向扫过，与射线相交的线段按到 \(x\) 的距离排序。构造导航函数的算法最多算 \(O(n)\) 个可见多边形（每个来自一个不同的路点），总运行时间 \(O(n^2\lg n)\)。可惜这不能推广到高维：回忆 7.7.1 节，在 3D 环境中计算最短路是 NP-难的 [22]。

这里的算法容易描述，但既不是最一般的，也不是最高效的。若 \(X\) 有洞，绕障碍从不同方向到达时，等值线会相撞。上面的队列 \(Q\) 可以像 Dijkstra 那样排序，还需要特殊的数据结构识别 cost-to-go 向外传播时的关键事件。[48] 证明了这可以在 \(O(n\lg n)\) 时间、\(O(n\lg n)\) 空间内完成。

8.4.4 迈向动力学的一步 A Step Toward Considering Dynamics

若动力学很重要，前面考虑的不连续向量场就不可取了：由于动量，机械系统不能瞬间改变速度（13.3 节）。这时可能要求向量场满足光滑性或有界加速度等额外约束。这只是迈向考虑动力学的一步；完整的处理在 Part IV，那里动力系统的精确运动方程是模型的一部分。本节的思路是让向量场「为动力学做好准备 dynamics-ready」，而不是仔细考虑具体的运动方程。

已有一个框架：先在简单区域（如圆盘 [79]）上定义满足某些期望约束的导航函数，再设计一组被证明能保持这些约束的变换，把导航函数适配到更复杂的环境；对给定问题，从某个起始形状施加适当的变换序列，就得到构造导航函数的完备算法。本节主要关注这个变换框架下保持的约束。8.4.2、8.4.3 节用的是归一化向量场；在这个约束下几乎任何向量场都可以定义，只要所得算法构造的场有 Filippov 意义下的积分曲线。本节去掉归一化约束，转而考虑别的约束：向量场给出的速度现在被认为是作为反馈计划执行时必须真正执行的速度。

加约束的一个后果是最优解可能不再满足它们：例如 8.4.3 节的最优导航函数导出不连续的向量场，违反本节要考虑的约束。所需的约束限制了允许的向量场集合，最优性必须在受限集合上定义；有时最优解甚至不存在（见 9.1.1 节关于开集与最优性的讨论）。所以本节只关注可行解。

基于加速度的控制模型 An acceleration-based control model

为引出约束，考虑 [26, 80] 提出的控制模型。Formulation 8.2 中动作空间 \(U(x) = T_x(X)\) 给每个动作 \(u\in U(x)\) 产生一个速度：\(\dot x = u\)。现在改为每个动作产生加速度：\(\ddot x = u\)，\(\ddot x\) 是加速度向量

$$\ddot x = \frac{d\dot x}{dt} = \left[\frac{d^2x_1}{dt^2}\ \ \frac{d^2x_2}{dt^2}\ \ \cdots\ \ \frac{d^2x_n}{dt^2}\right]. \tag{8.44}$$

速度 \(\dot x\) 由对时间积分得到，状态轨迹 \(\tilde x: T\to X\) 由对 (8.44) 积分两次得到。设给了向量场 \(\dot x = f(x)\)，怎样得到反馈计划？考虑 \(x\) 变化时 \(f(x)\) 给出的速度向量如何变化。设 \(f(x)\) 光滑（至少 \(C^1\)），令

$$\nabla_{\dot x} f(x) = \big[\nabla_{\dot x}f_1(x)\ \ \nabla_{\dot x}f_2(x)\ \ \cdots\ \ \nabla_{\dot x}f_n(x)\big], \tag{8.45}$$

\(\nabla_{\dot x}\) 表示 \(\dot x\) 方向上未归一化的方向导数：\(\nabla f_i\cdot\dot x\)。设给定初态 \(x_I\)，初速度 \(\dot x = f(x_I)\)，反馈计划可以定义为

$$u = \nabla_{\dot x} f(x). \tag{8.46}$$

这与 8.4.1 节的反馈计划定义等价；唯一区别是现在需要两次积分（需要 \(x\) 和 \(\dot x = f(x_I)\) 两个初始条件），并且向量场必须满足可微条件。

现在重新定义 \(\dot x\) 与 \(f(x)\) 的关系：设 \(\dot x\) 是执行中真实测到的速度，\(f(x)\) 是由向量场规定的速度。执行时假设 \(\dot x\) 与 \(f(x)\) 不一定相同，任务是让它们尽量接近。两者的差异可能来自没建模的动力学：例如场 \(f(x)\) 要求速度突然改变，移动机器人可能由于动量转不了急弯。按新解释，差 \(f(x) - \dot x\) 可以看成误差。设向量场 \(f\) 已算好，反馈计划变为基于加速度的控制 acceleration-based control 模型

$$u = K(f(x) - \dot x) + \nabla_{\dot x} f(x), \tag{8.47}$$

\(K\) 是标量增益常数 gain constant。\(K\) 越大，控制系统越激进地减小误差；\(K\) 太大则可能违反加速度或能量约束。注意若 \(\dot x = f(x)\)，则 \(u = \nabla_{\dot x}f(x)\)，与前面的表述等价。

速度与加速度约束 Velocity and acceleration constraints

在基于加速度的控制模型下，可以对允许的向量场施加一些约束。有界速度模型 bounded-velocity model：\(\|\dot x\| < v_{max}\)，正实数 \(v_{max}\) 称为最大速率，比如出于安全考虑限制机器人速度；也可以分别限制速度向量的各分量，例如飞机的最大角速度和线速度。直觉上，速度界意味着定义向量场的函数 \(f_i\) 不能取大值。

有界加速度模型 bounded-acceleration model：\(\|\ddot x\|\le a_{max}\)，正实数 \(a_{max}\) 称为最大加速度。直觉上，加速度界意味着沿积分曲线运动时速度不能变化太快。由控制模型 \(\ddot x = u\)，这就是 \(\|u\|\le a_{max}\)；它也对向量场施加了约束：对所有 \(\dot x\) 和 \(x\in X\)，\(\|\nabla_{\dot x}f(x)\|\le a_{max}\)。\(\|u\|\le a_{max}\) 在实际中非常重要：更大的加速度通常更昂贵（要更大的电机、消耗更多燃料等）；动作 \(u\) 可能直接对应施加到电机上的力矩，而每个电机都有上限。

前面已经看到，给速度设上界一般不影响解的存在：机器人总可以选择走得更慢。若还有加速度上界，机器人也可以通过走得更慢来满足——想象开车急转弯前先减速。想开得快就更难满足加速度约束；不过大多数情况下更快更好。不连续的向量场不满足任何加速度界：在不连续处让速度向量跳变，本质上需要无穷大的加速度。若向量场以某个常数 \(C\) 满足 Lipschitz 条件 (8.16)，则当 \(C < a_{max}\) 时它满足加速度界9。第 13 章会在每个 \(x\in X\) 处精确指定 \(U(x)\)，这比简单的速度、加速度界一般得多，几乎能建模任何物理系统。

Rimon–Koditschek 意义下的导航函数 Navigation function in the sense of Rimon-Koditschek

现在考虑构造这样的导航函数：由它导出的向量场满足基于加速度的控制模型 (8.47) 所要求的约束。和往常一样，导航函数的定义从势函数 \(\phi: X\to\mathbb{R}\) 开始。势函数要有哪些性质，才既能成为 8.4.1 节意义下的导航函数、又导出满足加速度界的向量场？下面给出充分条件。

为了给出这些条件，先要刻画多元函数的极值。回忆基础微积分：\(f:\mathbb{R}\to\mathbb{R}\) 在一阶导数为零处有临界点 critical point，二阶导数的符号指出它是极小还是极大。推广到高维：\(\phi\) 的临界点是 \(\nabla\phi = 0\) 的点；\(\phi\) 的 Hessian 定义为矩阵

$$H(\phi) = \begin{pmatrix} \dfrac{\partial^2\phi}{\partial x_1^2} & \dfrac{\partial^2\phi}{\partial x_1\partial x_2} & \cdots & \dfrac{\partial^2\phi}{\partial x_1\partial x_n} \\[2mm] \dfrac{\partial^2\phi}{\partial x_2\partial x_1} & \dfrac{\partial^2\phi}{\partial x_2^2} & \cdots & \dfrac{\partial^2\phi}{\partial x_2\partial x_n} \\ \vdots & \vdots & & \vdots \\ \dfrac{\partial^2\phi}{\partial x_n\partial x_1} & \dfrac{\partial^2\phi}{\partial x_n\partial x_2} & \cdots & \dfrac{\partial^2\phi}{\partial x_n^2} \end{pmatrix}. \tag{8.48}$$

在每个临界点，Hessian 提供关于极值的信息10。若 \(H(\phi)\) 在 \(x\) 处秩为 \(n\)，它就能指出极值的类型：若 (8.48) 正定（对所有 \(x\ne 0\)，\(x^TAx > 0\)；对称矩阵——Hessian 就是——等价于特征值全正），\(\phi\) 在 \(x\) 处取局部极小；若负定（特征值全负），取局部极大；其余情形 \(x\) 是鞍点 saddle point。若 \(H(\phi)\) 在 \(x\) 处秩小于 \(n\)，Hessian 是退化的 degenerate，无法判断极值类型——例如 \(x\) 位于一块平台上（没有任何方向让 \(\phi\) 增或减）。这种行为对势函数显然不好，局部算子选不出方向。

设要求导航函数光滑，以保证每点都有梯度，从而能做梯度下降。若 \(X\) 不可缩 not contractible，那么除 \(x_G\) 外必然存在一些临界点 \(\nabla\phi(x) = 0\)；临界点甚至可以用来推断 \(X\) 的拓扑——这是 Morse 理论 的基本思想 [73, 25]。可惜这意味着这样的空间上不存在（8.4.1 节意义下的）解导航函数：那个定义要求从任何能到达 \(x_G\) 的状态出发，用导航函数导出的向量场都要到达 \(x_G\)；若初态恰是临界点，积分曲线就停在原地。所以在光滑约束下，导航函数的定义要修改：允许在少数地方有临界点（只在零测集上）；还要求积分曲线会到达各临界点的那些状态（各临界点的吸引域）测度为零。这样，除一个零测集外，从所有可能的初态出发，积分曲线都要到达 \(x_G\)（若可达）。这由下面的定义保证。

定义：Rimon–Koditschek 意义下的导航函数 [79]

函数 \(\phi: X\to\mathbb{R}\) 若满足以下四条，就称为 Rimon–Koditschek 意义下的导航函数：

  1. 光滑（或至少 \(C^2\)）。
  2. 在含 \(x_G\) 的 \(\mathcal{C}_{free}\) 连通分量上的所有值中，只有一个局部极小，就在 \(x_G\)（有些作者不把全局极小算作局部极小，那样就说「没有局部极小」）。
  3. 在 \(\partial\mathcal{C}_{free}\)（\(\mathcal{C}_{free}\) 的边界）上取最大值且为常数。
  4. 是 Morse 函数 [73]：在每个临界点 \(x\)（\(\nabla\phi|_x = 0\)），\(\phi\) 的 Hessian 非退化（严格说 Morse 函数还要求各临界点处的函数值互不相同）。任何光滑流形上都存在这样的函数。

若 \(\phi\) 在 \(C^\infty\) 意义下光滑，则由 Sard 定理 [25]，临界点集测度为零。[79] 给出了为 \(\mathcal{C}_{free}\) 有半代数描述的一大类问题构造导航函数的方法：从容易定义导航函数的简单形状开始——例如 \(\mathbb{R}^n\) 中含球形障碍的球形子集（球形世界 sphere world）；再开发一组扭曲变换，把导航函数适配到其它形状，同时保持上面四条性质。一种变换把球扩展成任意的可见区域（8.4.3 节的意义）：把球光滑地拉伸成可见区域的形状（这种区域有时称为星形 star-shaped）。[79] 的变换可以组合起来，为一大类配置空间定义导航函数。主要问题是：配置空间障碍和 \(\mathcal{C}_{free}\) 的连通性都只是隐式表示的，难以把方法正确用于复杂的高维问题。这一方法的优点之一是收敛到目标的证明变得简单，很多情形下可以做 Lyapunov 稳定性分析（15.1.1 节）。

调和势函数 Harmonic potential functions

另一类重要的导航函数由调和函数 harmonic functions 构造 [27, 28, 29, 49, 54]。若函数 \(\phi\) 满足微分方程

$$\nabla^2\phi = \sum_{i=1}^n\frac{\partial^2\phi}{\partial x_i^2} = 0, \tag{8.49}$$

就称为调和函数。依赖于 \(\phi\) 定义域边界上的条件，方程有很多可能的解；[26] 给出一个有解析解的简单圆盘例子。复杂的导航函数一般通过对 \(\phi\) 在 \(\mathcal{C}_{free}\) 边界上施加约束来定义。Dirichlet 边界条件要求边界保持常值：用这个条件可以构造一个调和导航函数，在单连通状态空间里从任何地方把状态引到目标区域。若有内部障碍，Neumann 边界条件迫使速度向量与障碍边界相切。在两种边界条件的组合下解 (8.49)，可以构造一个调和导航函数：平行于障碍边界运动以避开障碍，最终落入目标。已经证明在一般条件下能产生导航函数 [29, 28]；但主要问题是 \(\mathcal{C}_{free}\) 的边界通常没有被显式构造（回忆第 5 章为什么要回避它），而且数值求解 (8.49) 代价很高。可以用 Gauss–Seidel 迭代求解（如 [29]），它与值迭代有关（两者的区别见 [11]）。[16] 给出了通过调和函数构造导航函数的采样方法。8.5.2 节会用值迭代产生近似最优的导航函数。

8.5.1 计算漏斗的组合 Computing a Composition of Funnels

Mason 提出用漏斗 funnel 作为隐喻，描述不论初始位置如何都收敛到状态空间同一小区域的运动 [70]：就像漏斗里的沙粒沿漏斗壁滑到底部的开口。导航函数可以想象成把状态引入目标的漏斗；例如图 8.13d 的 cost-to-go 函数可以看成一个复杂的漏斗，把每粒沙沿最优路径送到目标。

图 8.14 的重画：导航函数和对应的向量场可以设计成漏斗的组合。左：漏斗 1 的出口落进漏斗 2，再落进漏斗 3；右：每个重叠区域上的场把状态送进下一个区域。

与其设计一个大漏斗，不如把状态空间分解成一组简单的、彼此重叠的区域，在每个区域上设计一个把状态引入另一个漏斗的漏斗（图 8.14）。例如 [20] 在每个漏斗上放一个 Lyapunov 函数（15.1.2 节）来保证收敛到下一个漏斗。组合若干个漏斗就构造出反馈计划：从 \(X\) 中某个初态出发，依次访问一串漏斗直到到达目标；每个漏斗本质上解决「到达下一个漏斗」这个子目标；最终到达含目标的漏斗，其上的导航函数让状态到达目标。在感知不确定的情形下（漏斗隐喻正是为此提出的），漏斗的组合成为原像规划框架 preimage planning framework [69]，见 12.5.1 节。本节假设当前状态总是已知的。

近似覆盖 An approximate cover

图 8.15 说明了近似覆盖的概念，后面用它表示漏斗的定义域。记 \(\tilde X\) 为状态空间 \(X\) 的子集。\(\tilde X\) 的覆盖 cover 是一族集合 \(\mathcal{O}\)，满足：

  1. 对每个 \(O\in\mathcal{O}\)，\(O\subseteq X\)。
  2. \(\tilde X\) 是覆盖中所有集合的并的子集：
    $$\tilde X\subseteq\bigcup_{O\in\mathcal{O}} O. \tag{8.50}$$

每个 \(O\in\mathcal{O}\) 称为一个邻域 neighborhood。8.3.2 节用坐标邻域的覆盖定义光滑流形，用的就是覆盖的概念。一般地，覆盖允许：1) 任意多个邻域重叠（交集非空）；2) 邻域包含 \(\tilde X\) 以外的点。6.3.1 节的单元分解是一种特殊的覆盖：邻域构成 \(\tilde X\) 的一个划分，而且必须拼合得很好（回忆图 6.15）。

到目前为止还没对邻域加任何约束。实际上应选择它们，让在每个邻域上设计导航函数变得大大简化。对原运动规划问题，单元分解的设计使得在每个单元里找无碰路径变得平凡；这里思想相同，只是现在要构造反馈计划。所以通常假设单元形状简单。若 \(\tilde X\) 是 \(X\) 的真子集，覆盖称为近似的 approximate。理想情况是精确覆盖 exact cover：\(\tilde X = X\)，且每个邻域有好的性质，如凸——这只在低维或有特殊结构的状态空间里才可行（第 6 章的单元分解就是这样）。

考虑为 \(X\) 构造近似覆盖。目标应是覆盖尽可能多的 \(X\)：\(\mu(X\setminus\tilde X)\) 尽可能小，\(\mu\) 是 5.1.3 节定义的 Lebesgue 测度。还希望 \(\tilde X\) 保持 \(X\) 的连通性：若 \(X\) 中两点间存在路径，那么 \(\tilde X\) 中也应存在。

在覆盖上定义反馈计划 Defining a feedback plan over a cover

8.4.2 节的思想可以改编来在 \(\tilde X\) 上用覆盖定义反馈计划。记 \(\check X\) 为离散状态空间，每个超状态是一个邻域；相应离散规划问题的大部分组成和 8.4.2 节一样，唯一区别在于超动作的定义——覆盖中的邻域可以重叠。对每个邻域 \(O\in\mathcal{O}\)，对每个满足 \(O\cap O'\neq\emptyset\)（通常是内部重叠 \(\mathrm{int}(O)\cap\mathrm{int}(O')\neq\emptyset\)）的其它邻域 \(O'\in\mathcal{O}\)，存在一个超动作。注意单元分解中这不会产生超动作，因为它是划分。按照漏斗组合的隐喻，有些漏斗的定义域应该重叠（图 8.14）。从邻域 \(O\) 到 \(O'\) 的转移，靠在 \(O\) 上定义一个把 \(O\setminus O'\) 中所有状态送进 \(O\cap O'\) 的向量场实现（图 8.16：所有积分曲线都通向 \(O\cap O'\)）。一旦到达 \(O'\)，就不再跟随 \(O\) 的场，改用 \(O'\) 的场；用 \(O'\) 的场又可以转移到另一个邻域。注意从 \(O\) 的场跳到 \(O'\) 的场，可能使反馈计划在 \(\tilde X\) 上成为不连续的向量场；若覆盖设计得让 \(O\cap O'\) 很大（若它们相交），就有可能通过混合 \(O\) 与 \(O'\) 的场实现渐变。

离散问题定义好以后，可以按 8.2 节在 \(\check X\) 上算离散反馈计划，再转成 \(X\) 上的反馈计划：在每个邻域上定义导致相应转移的向量场。每个 \(\check x\in\check X\) 既可以解释为超状态，也可以解释为邻域。对每个 \(\check x\)，离散反馈计划给出超动作 \(\check u = \check\pi(\check x)\)，得到新邻域 \(\check x'\)；于是把 \(\check x = O\) 上的向量场设计成把所有状态送进 \(\check x' = O'\)。

如果需要，还能由离散导航函数 \(\check\phi\) 得到 \(X\) 上的导航函数 \(\phi\)。设 \(\check\phi\) 的构造使每个 \(\check x\in\check X\) 的 \(\check\phi(\check x)\) 都不同（\(\check X\) 有限，任何导航函数都能轻易变换成满足此约束）。记 \(\phi_O\) 为某个 \(O\in\mathcal{O}\) 上的导航函数。设 \(X_G\) 是单点 \(x_G\)（可以推广到更一般的情形）。对每个 \(x_G\notin O\) 的邻域，\(\phi_O\) 的定义使梯度下降通向 \(\check\phi(\check x)\) 最小的那个重叠邻域；若 \(O\) 含 \(x_G\)，\(\phi_O\) 直接把状态引到 \(x_G\)。各邻域上的导航函数可以很容易地拼成整个 \(X\) 上的导航函数：多个邻域重叠的地方，\(\phi\) 定义为 \(\check\phi(\check x)\) 最小的那个邻域的导航函数。这可以通过给每个 \(\phi_O\) 加一个大常数实现。记 \(c\) 为一个常数，使对所有 \(O\in\mathcal{O}\)、\(x\in O\) 都有 \(\phi_O(x) < c\)（假设每个 \(\phi_O\) 有界），并设 \(\check\phi\) 只取整数值；记 \(\mathcal{O}(x)\) 为所有满足 \(x\in O\) 的 \(O\in\mathcal{O}\)。\(X\) 上的导航函数定义为

$$\phi(x) = \min_{O\in\mathcal{O}(x)}\Big\{\phi_O(x) + c\,\check\phi(O)\Big\}. \tag{8.51}$$

一种采样方法 A sampling-based approach

构造覆盖的方法很多。为说明思路，这里介绍称为基于采样的邻域图 sampling-based neighborhood graph 的方法 [91]。设 \(X = \mathcal{C}_{free}\)，是某个配置空间的子集。如 5.4 节，记 \(\alpha\) 为 \(X\) 中稠密的无穷样本序列；设有一个碰撞检测算法能返回机器人与世界中障碍的距离 (5.28)（这类算法见 5.3 节）。图 8.17 给出一个增量算法。开始时 \(\mathcal{O}\) 为空；每次迭代，若 \(\alpha(i)\in\mathcal{C}_{free}\) 且它不在任何已有邻域里，就往 \(\mathcal{O}\) 加一个新邻域。两个主要问题是：1) 怎样定义新邻域 \(O\) 使 \(O\subset\mathcal{C}_{free}\)；2) 何时终止。任何时候覆盖都是近似的；所有邻域的并是 \(\tilde X\)，它是 \(X\) 的真子集。与图 8.15 相比，这里的覆盖是邻域不超出 \(\tilde X\) 的特例。

$$B(x,r) = \{x'\in X \mid \rho(x,x') < r\}, \tag{8.52}$$

\(\rho\) 是 \(\mathcal{C}\) 上的度量。在所有邻域都是球的假设下，有判断「是否存在 \(O\in\mathcal{O}\) 使 \(x\in O\)」的高效算法 [72]；实践中基于 Kd 树的方法表现很好 [5, 6]（回忆 5.5.2 节）。第 3 步可以为 \(x = \alpha(i)\) 构造新球 \(B(x,r)\)，但半径取多大？对在 \(\mathbb{R}^2\) 或 \(\mathbb{R}^3\) 中平移的点机器人，机器人与 \(\mathcal{W}\) 中障碍的 Hausdorff 距离 \(d\) 恰好就是到 \(\mathcal{C}_{obs}\) 的距离，于是可以取 \(r = d\)，\(B(x,r)\) 保证无碰。

一般的配置空间里，可以找到 \(r\) 使 \(B(x,r)\subseteq\mathcal{C}_{free}\)，但一般 \(r < d\)。这个问题在 5.3.4 节检查路径段时出现过，3.2、3.3 节的变换在确定 \(r\) 时很重要。为说明，设 \(\mathcal{C} = \mathbb{R}^2\times\mathbb{S}^1\)，对应在 \(\mathcal{W} = \mathbb{R}^2\) 中平移和旋转的刚体机器人 \(\mathcal{A}\)，每个点 \(a\in\mathcal{A}\) 用 (3.35) 变换。想象从某个位形 \(q = (x,y,\theta)\) 出发，给每个坐标加扰动 \(\Delta x\)、\(\Delta y\)、\(\Delta\theta\)：\(\mathcal{A}\) 上的点最多能移动多远？平移对 \(\mathcal{A}\) 上所有点的影响相同，旋转则不同。回忆 5.3.4 节的图 5.12：记 \(a_r\in\mathcal{A}\) 为离原点 \((0,0)\) 最远的点，\(r\) 为它到原点的距离。若旋转扰动 \(\Delta\theta\)，任何 \(a\in\mathcal{A}\) 的位移不超过 \(r\Delta\theta\)。书中说，若三个位形参数都被扰动，则

$$(\Delta x)^2 + (\Delta y)^2 + (r\Delta\theta)^2 < d^2 \tag{8.53}$$

就是保证所得球在 \(\mathcal{C}_{free}\) 中必须满足的约束12。这其实是一个实心椭球的方程，\(r = 1\) 时就是球。重新参数化 \(SE(2)\)，让 \(\Delta\theta\) 与 \(\Delta x\)、\(\Delta y\) 效果相同，就能把它变成球：变换 \(h:\theta\mapsto r\theta\) 把 \(\theta\) 映到新的定义域 \(Z = [0, 2\pi r)\)。在这个新空间里，球的方程是

$$(\Delta x)^2 + (\Delta y)^2 + (\Delta z)^2 < d^2, \tag{8.54}$$

\(\Delta z\) 表示 \(z\in Z\) 的变化。(3.35) 的重新参数化版本是

$$T = \begin{pmatrix}\cos(\theta/r) & -\sin(\theta/r) & x_t\\ \sin(\theta/r) & \cos(\theta/r) & y_t\\ 0 & 0 & 1\end{pmatrix}. \tag{8.55}$$

对 3D 刚体，可以对欧拉角或四元数做类似的重新参数化，得到六维的球；也可以推广到多个物体构成的链 [91]。主要困难之一是这些球不是最大可能的球。高维中问题更严重：需要大量的球，而按上面方法构造的半径往往比可能的值小得多。允许轴对齐的柱体可以减少球的数目，但在超过六维时仍难以覆盖 \(\mathcal{C}_{free}\) 的大部分。

8.5.2 带插值的动态规划 Dynamic Programming with Interpolation

Part II 以用 2.3 节的值迭代解运动规划问题收尾。8.2 节已经用值迭代得到离散反馈计划；现在先允许在连续状态空间上插值，再允许在连续动作空间上插值，把它推广到连续空间。这给出计算最优导航函数和反馈计划的数值方法。重点放在后向值迭代，但插值的概念也可以用于前向。这里把最优反馈运动规划看成离散时间最优控制问题 [3, 8, 19, 62]。

在连续状态空间上插值 Using interpolation for continuous state spaces

考虑一个和 Formulation 8.1 一样的问题，只是 \(X\) 可以是连续的。设 \(X\) 有界，并暂时设对所有 \(x\in X\)，动作空间 \(U(x)\) 有限。后向值迭代可用，动态规划的论证和推导与 2.3 节相同，得到的递推与 (2.11) 相同：

$$G^*_k(x_k) = \min_{u_k\in U(x_k)}\Big\{l(x_k,u_k) + G^*_{k+1}(x_{k+1})\Big\}. \tag{8.56}$$

唯一的困难是 \(G^*_k(x_k)\) 不能对每个 \(x_k\in X\) 都存下来，因为 \(X\) 是连续的。有两类一般做法：一是用参数化曲面族近似 \(G^*_k\)，如多项式或神经网络导出的非线性基函数 [12]；二是只在有限个样本点上存 \(G^*_k\)，其它点的值用插值得到 [61, 62]。设用有限样本集 \(S\subset X\) 表示 \(X\) 上的 cost-to-go 函数。图 8.19 描绘了用插值评估 (8.56)：即使 \(x_k\) 是样本点，下一个状态 \(x_{k+1} = f(x_k,u_k)\) 也可能落在样本点之间，对每个 \(u_k\in U(x_k)\) 都可能需要插值。一般地，样本应选得让分散度（5.2.3 节）尽量小，以免在大片没有样本点的区域上近似 cost-to-go 函数。收敛速度最终取决于分散度 [10]（结合状态转移方程和代价泛函上的 Lipschitz 条件）。为简化记号，设 \(S\) 是 \(\mathbb{R}^n\) 中规则间隔的网格。

先看 \(X = [0,1]\subset\mathbb{R}\)。令 \(S = \{s_0,s_1,\ldots,s_r\}\)，\(s_i = i/r\)；例如 \(r = 3\) 时 \(S = \{0, 1/3, 2/3, 1\}\)。这样总会在 \(X\) 的边界上有样本，保证 \((0,1)\) 中任何点上下都有样本。令 \(i\) 为满足 \(s_i < x\) 的最大整数，于是 \(s_{i+1} > x\)；样本 \(s_i\)、\(s_{i+1}\) 称为 \(x\) 的插值邻居 interpolation neighbors。\(G^*_{k+1}\) 在任意 \(x\in[0,1]\) 处的值可以由线性插值得到：

$$G^*_{k+1}(x) \approx \alpha\,G^*_{k+1}(s_i) + (1-\alpha)\,G^*_{k+1}(s_{i+1}), \tag{8.57}$$

系数 \(\alpha\in[0,1]\) 为

$$\alpha = 1 - r(x - s_i) = 1 - \frac{x - s_i}{1/r}. \tag{8.58}$$

若 \(x = s_i\)，则 \(\alpha = 1\)，(8.57) 化为 \(G^*_{k+1}(s_i)\)，正如所料；若 \(x = s_{i+1}\)，则 \(\alpha = 0\)，化为 \(G^*_{k+1}(s_{i+1})\)。在两者之间的所有点，(8.57) 用 \(\alpha\) 混合 \(s_i\)、\(s_{i+1}\) 处的 cost-to-go 值，给出合适的权重。（这里写的是改正后的 (8.58)；原书写作 \(\alpha = 1 - (x-s_i)/r\)13。）

插值的思想可以自然推广到多维。设 \(X\) 是 \(\mathbb{R}^n\) 的有界子集，\(S\) 是 \(\mathbb{R}^n\) 中的 \(n\) 维网格点，每个样本记作 \(s(i_1,i_2,\ldots,i_n)\)。对某个 \(x\in X\)，有 \(2^n\) 个「包围」它的插值邻居——包含 \(x\) 的 \(n\) 维立方体的角点。设 \(x = (x_1,\ldots,x_n)\)，令 \(i_j\) 为使 \(s(i_1,\ldots,i_n)\) 的第 \(j\) 个坐标小于 \(x_j\) 的最大整数，那么 \(2^n\) 个样本就是对每个 \(j\)、\(s(\cdot,\ldots,\cdot)\) 的第 \(j\) 个下标取 \(i_j\) 或 \(i_j+1\) 的那些——这要求所有这些样本都在 \(S\) 中。注意 \(X\) 可以是 \(\mathbb{R}^n\) 的复杂子集，只要对任何 \(x\in X\)，所需的 \(2^n\) 个插值邻居都在 \(S\) 中。用这 \(2^n\) 个插值邻居，(8.56) 中 \(G^*_{k+1}\) 在任意 \(x\in X\) 处的值可以通过多线性插值 multi-linear interpolation 得到。\(n=2\) 时为

$$\begin{aligned} G^*_{k+1}(x) \approx\ & \alpha_1\alpha_2\,G^*_{k+1}(s(i_1,i_2)) + \alpha_1(1-\alpha_2)\,G^*_{k+1}(s(i_1,i_2+1)) \\ &+ (1-\alpha_1)\alpha_2\,G^*_{k+1}(s(i_1+1,i_2)) + (1-\alpha_1)(1-\alpha_2)\,G^*_{k+1}(s(i_1+1,i_2+1)), \end{aligned} \tag{8.59}$$

\(\alpha_1\)、\(\alpha_2\) 的定义类似 (8.58)，只是分别基于沿 \(x_1\)、\(x_2\) 方向的距离。更高维的多线性插值表达式类似但写起来更麻烦；也可以用二次插值等更高阶的插值 [62]。

可惜插值邻居的个数随维数 \(n\) 指数增长。一个改进是把 \(2^n\) 个样本定义的立方体分解成单纯形，每个单纯形只有 \(n+1\) 个样本作顶点，只把含 \(x\) 的单纯形的顶点作为 \(x\) 的插值邻居——计算 \(G^*_{k+1}(x)\) 的代价降到 \(O(n)\)。问题在于确定哪个单纯形包含 \(x\) 可能是个有挑战的点定位问题 point-location problem（计算几何的常见问题 [32]）。若用重心细分 barycentric subdivision（用所有面的中点分解立方体），点定位问题可以在 \(O(n\lg n)\) 时间内解决 [31, 64, 75]，比上面的 \(O(2^n)\) 好。图 8.20 给出了二维和三维的例子；这有时称为 Coxeter–Freudenthal–Kuhn 三角剖分。实际中由于性能考虑 \(n\) 不会太大（通常 \(n\le 6\)），即使 \(n = 3\)，实现中也能显著节省。

连续动作空间 Continuous action spaces

现在设除了 \(X\)，\(U(x)\) 也是连续的，并设 \(U(x)\) 是 \(\mathbb{R}^n\) 的闭有界子集。动态规划递推 (8.56) 不变；麻烦在于 min 现在是在不可数无穷多个选择上的优化问题。一种可能是用非线性优化技术选最优的 \(u\in U(x)\)，效果很依赖 \(U(x)\)、\(X\) 和代价泛函。另一种办法是在从 \(U(x)\) 中抽取的有限样本上评估 (8.56)，样本同样最好能尽量减小分散度。某些情形下，还可以仔细利用 cost-to-go 函数及其插值表示的性质，从考虑中排除一些动作。

与反馈运动规划的联系 The connection to feedback motion planning

现在已经有了用值迭代解运动规划问题的工具。配置空间是连续状态空间，令 \(X = \mathcal{C}_{free}\)；动作空间也是连续的，\(U(x) = T_x(X)\)。对运动规划问题，\(0\in T_x(X)\) 只在施加 \(u_T\) 时才会得到，因此不需要单独表示。为计算运动规划的最优 cost-to-go 函数，主要关注点如下：

  1. 动作空间必须有界。
  2. 必须做离散时间近似，得到跨阶段的状态转移方程。
  3. 代价泛函必须离散化。
  4. 必须考虑障碍区域 \(\mathcal{C}_{obs}\)。
  5. 至少有某个插值区域必须给出 \(G^*(x) = 0\)，表示目标区域。

限制动作空间：用归一化向量场不改变解的存在性。这很方便，因为要用有限个样本近似 \(U(x)\)，它必须有界。把动作集限制为

$$U(x) = \{u\in\mathbb{R}^n \mid \|u\|\le 1\} \tag{8.60}$$

很有用。为提高性能，有时可以只用 \(\|u\| = 1\) 或 \(u = 0\) 的 \(u\)，但可能出现数值不稳定（习题 13）。\(U(x)\) 的有限样本应有低分散度，并且总包含 \(u = 0\)。

得到状态转移方程：值迭代在离散阶段上进行，而反馈计划的积分曲线发生在连续时间里，所以要对时间区间 \(T\) 采样。令 \(\Delta t\) 为表示固定时间间隔的小正常数，阶段下标 \(k\) 对应时间 \((k-1)\Delta t\)。考虑在 \(\mathbb{R}^n\) 上表示速度场 \(\dot x\)。按定义，

$$\frac{dx}{dt} = \lim_{\Delta t\to 0}\frac{x(t+\Delta t) - x(t)}{\Delta t}. \tag{8.61}$$

8.3.1 节中速度场的定义是给每个 \(x\in X\) 指定某个 \(u\in U(x)\)。把速度向量 \(u\) 从 \(x(t)\) 出发积分一小段 \(\Delta t\)，得到新状态 \(x(t+\Delta t)\)。若 \(u\) 保持不变，则

$$x(t+\Delta t) = x(t) + \Delta t\,u, \tag{8.62}$$

称为 Euler 近似。执行反馈计划时，\(u\) 由 \(x\) 通过 \(u = \pi(x(t))\) 决定，一般意味着状态向前积分时 \(u\) 可能变化，这时 (8.62) 只是近似：

$$x(t+\Delta t) \approx x(t) + \Delta t\,\pi(x(t)). \tag{8.63}$$

(8.62) 可以看成跨阶段的状态转移方程。令 \(x_{k+1} = x(t+\Delta t)\)、\(x_k = x(t)\)，转移可以写成

$$x_{k+1} = f(x_k,u) = x_k + \Delta t\,u. \tag{8.64}$$

\(\Delta t\) 越小近似越好；沿时间用更多样本点能得到更好的近似，最著名的是 Runge–Kutta 一族。对最优运动规划来说，结果是方向向量沿积分曲线几乎总是保持不变：例如图 8.13d 中，对最优导航函数做梯度下降得到分段线性的路径，方向向量在所得积分曲线的大部分上是常数（只在碰到障碍时改变）。所以近似问题在运动规划里往往不严重。近似动力系统（如第 13 章的那些）时需要更好的近似，见 14.3.2 节。一个重要问题是 \(\Delta t\) 要与网格分辨率相容：若 \(\Delta t\) 小到动作改变状态不足以产生新的插值邻居，插值得到的 cost-to-go 值就保持不变。这意味着 \(\Delta t\) 必须选得让 \(x(t+\Delta t)\) 的插值邻居集合与 \(x(t)\) 的不同。

这与 7.7 节的近似运动规划问题有一个有趣的联系：Formulation 7.4 恰好对应这里定义的近似，只是用 \(\epsilon\) 代替 \(\Delta t\)，因为那时还没考虑速度（而且因为没有反馈，初始条件是给定的）。回忆图 7.41 的各种动作空间：如 7.7 节所说，若用曼哈顿或独立关节模型，位形保持在网格点上，就能做离散值迭代，也能算出 8.2.3 节那样的离散反馈计划和导航函数。若用更自然的欧氏运动模型，转移就允许连续的位形，最终可以用本节的在配置空间上插值来处理。

近似代价泛函：离散代价泛函要由连续代价泛函 (8.39) 推出。末项直接取 \(l_F(x_F) = l_F(x(t_f))\)，每个阶段的代价为

$$l_d(x_k,u_k) = \int_0^{\Delta t} l(x(t),u(t))\,dt, \tag{8.65}$$

在 (8.56) 中用 \(l_d(x_k,u_k)\) 代替 \(l(x_k,u_k)\)。很多问题不需要反复计算这个积分。要得到欧氏最短路，可以放心地对所有 \(x_k\in X\)、\(u_k\in U(x_k)\) 取 \(l_d(x_k,u_k) = \|u_k\|\)（补充：严格地说是 \(\Delta t\|u_k\|\)，常数因子不影响最优动作；互动图用的是 \(\Delta t\|u_k\|\)）。\(\Delta t\) 很小时，(8.65) 的一个合理近似是 \(l(x(t),u(t))\Delta t\)。

处理障碍：一个简单办法是值迭代前先对每个 \(x\in S\) 判断 \(x\in\mathcal{C}_{obs}\) 并存成数组；对刚体机器人可以用快速 Fourier 变换高效计算 [50]。对每个 \(x\in\mathcal{C}_{obs}\)，\(G^*(x) = \infty\)，这些样本上不做值迭代，值必须保持无穷。评估 (8.59)（或更高维版本）时会尝试不同的动作；对每个动作，要求 \(x_{k+1}\) 的所有插值邻居都在 \(\mathcal{C}_{free}\) 中，任何一个在 \(\mathcal{C}_{obs}\) 中，该动作的代价就是无穷。这自动把插值区域 \(R(S)\) 缩小为所有顶点都在 \(\mathcal{C}_{free}\) 中的立方体（图 8.21b）。本节其余部分假设 \(\mathcal{C}_{obs}\) 中的样本都从 \(S\) 中删去；但插值仍用完整的网格，让无穷值表示障碍区域。注意按目前的说法，\(\mathcal{C}_{obs}\) 中的点有可能落在 \(R(S)\) 里，因为只在样本上做了碰撞检测。实践中，要么网格分辨率足够细以减小这种错误的机会，要么利用碰撞检测算法的距离信息推断每个样本周围足够大的球无碰。若不能保证插值区域在 \(\mathcal{C}_{free}\) 中，就可能需要（至少局部地）提高分辨率。

处理目标区域：回忆后向值迭代从最终的 cost-to-go 函数开始向后迭代。开始时，最终 cost-to-go 除目标中的状态外都设为无穷。为正确初始化，\(X\) 必须有某个子集能通过插值得到零值。令 \(G = S\cap X_G\)，要求是插值区域 \(R(G)\) 必须非空；不满足就要提高网格分辨率或扩大目标集。若 \(X_g\) 是单点，不管分辨率多高都必须扩大它（除非开发了在目标点附近插值的其它办法）。在图 8.21c 的插值区域里，\(x_G\) 附近所有状态插值得到的 cost-to-go 值为零；若不存在这样的区域，评估 (8.59) 时从任何状态出发的代价都保持无穷。注意 \(\Delta t\) 必须选得足够大，以保证新样本能到达 \(G\)。

把 \(G^*\) 当作导航函数：cost-to-go 值稳定后，得到的 cost-to-go 函数 \(G^*\) 可以用作导航函数。虽然 \(G^*\) 只定义在 \(S\subset X\) 上，但用插值可以得到 \(R(S)\) 中任意点处导航函数的值。最优动作选为满足 (8.6) 中 min 的那个。这意味着状态轨迹不必像曼哈顿模型那样访问网格点；轨迹可以访问 \(R(S)\) 中的任意点，使轨迹在 \(\Delta t\) 和网格间距趋于零时收敛到真正的最优解。

拓扑上的考虑：到目前为止没有显式考虑 \(\mathcal{C}\) 的拓扑。设 \(\mathcal{C}\) 是流形，上面讨论的概念可以用于任何定义了坐标的开集。实践中常用 4.1.2 节的流形表示：流形表示为某些面被粘合的立方体 \([0,1]^n/\sim\)。在立方体内部，本节的所有概念都不用修改；在边界上，插值用到的样本要考虑粘合，动作 \(u_k\) 和下一状态 \(x_{k+1}\) 也必须在边界上正确工作。但宣称某个解最优时要小心：欧氏最短路依赖于流形的参数化。这种歧义通常通过用时间或能量等物理量表述代价来解决，这往往需要建模动力学（Part IV）。

带插值的值迭代极其通用。它是近似求解最优控制问题的一种通用算法：限制 \(U(x)\) 以考虑复杂的微分约束，就能解 Part IV 的许多问题；还能推广到预测中有显式不确定性的问题（10.6 节）。

得到类 Dijkstra 算法 Obtaining Dijkstra-like algorithms

对运动规划问题，由 (8.62) 算出的 \(x(t+\Delta t)\) 相对 \(X\) 的尺寸总是接近 \(x(t)\)。这提示可以用类 Dijkstra 算法更高效地计算最优反馈计划。如 2.3.3 节对有限情形的讨论，值迭代过程中很多值保持不变（例 2.5）；Dijkstra 算法维护一个数据结构，把计算集中在状态空间中值在变化的部分。连续情形下仔细考虑样本点，也可以这样做 [64]。值迭代过程中有三类样本点，和离散情形一样（回忆 2.3.3 节）：

  1. Dead：cost-to-go 已稳定到最优值。
  2. Alive：当前 cost-to-go 有限，但还不知道是否最优。
  3. Unvisited：cost-to-go 仍是无穷，因为样本还没被到达。

由于样本集 \(S\) 与插值区域 \(R(S)\) 之间的相互作用，在连续状态空间里维护这些集合要难一些。想象第一次值迭代：开始时 \(G\) 中所有点设为零值。\(S\) 中有多少样本一步能到达 \(R(G)\)？离 \(G\) 很远的样本到不了 \(R(G)\)，值保持无穷；离 \(G\) 近的应该能到。若能把离 \(G\) 太远的样本都剪掉就方便了：每次迭代都去掉离已到达样本太远的样本，也不必在 dead 样本上迭代，因为它们的值不再改变。

为了跟踪可达的样本，引入反向投影 backprojection 的概念（10.1 节会进一步研究）。对单个状态 \(x\in X\)，它的反向投影定义为

$$\mathrm{B}(x) = \{x'\in X \mid \exists u'\in U(x') \text{ 使 } x = f(x',u')\}. \tag{8.66}$$

点集 \(X'\subseteq X\) 的反向投影就是各点反向投影的并：

$$\mathrm{B}(X') = \bigcup_{x\in X'}\mathrm{B}(x). \tag{8.67}$$

考虑一种用反向投影把「值已知不会改变」的状态排除在外的值迭代。令 \(i\) 为当前值迭代考虑的阶段数；第一次迭代 \(i = 1\)，考虑所有一阶段轨迹。令 \(S\) 为样本集（假设都不在 \(\mathcal{C}_{obs}\) 中），\(D_i\)、\(A_i\) 分别表示 dead 和 alive 样本。开始时 \(D_1 = G\)，即目标集中的样本；第一个 alive 集 \(A_1\) 用前沿 frontier 的概念得到：样本点集 \(S'\subseteq S\) 的前沿为

$$\mathrm{Front}(S') = \big(\mathrm{B}(R(S'))\setminus S'\big)\cap S. \tag{8.68}$$

这是一步能到达 \(R(S')\) 的样本点集，排除已在 \(S'\) 中的。图 8.22 说明了前沿：(a) 阴影圆盘表示从左边样本一步可达的所有点，它一步到不了右边代表 \(R(S')\) 的阴影区域；(b) 前沿是能到达 \(R(S')\) 的样本集合，把前沿加进来，插值区域就扩展到 \(R(S')\) 之外。用 (8.68)，\(A_1 = \mathrm{Front}(D_1)\)。

第 \(i\) 次迭代：在 \(A_i\) 的所有点上计算 cost-to-go 更新 (8.56)。若对某个 \(s\in A_i\) 有 \(G^*_{k+1}(s) = G^*_k(s)\)，\(s\) 就被宣布为 dead，移入 \(D_{i+1}\)。样本永远不会从 dead 集合中移除，所以 \(D_i\) 中所有点也加入 \(D_{i+1}\)。下一个 alive 集 \(A_{i+1}\) 包括 \(A_i\) 中没有移入 dead 集的样本；此外 \(\mathrm{Front}(A_i)\) 中的所有样本也加入 \(A_{i+1}\)，因为它们在下一次迭代中会产生有限的 cost-to-go 值。迭代照常进行，直到某个阶段 \(m\) 时 \(A_m\) 为空，\(D_m\) 包含所有能到达目标的样本（在本节的近似假设下）。为提高效率，可以用 Front 的近似，只要真正的前沿是近似前沿的真子集：例如前沿可以加入 \(S'\) 中各点指定半径内的所有新样本。这时 \(s\in A_i\) 更新后的 cost-to-go 可能仍是无穷，那它当然不加入 \(D_{i+1}\)，并且在计算下一个前沿时从 \(A_i\) 中删去（前沿只应对 cost-to-go 有限的样本计算）。

上面的做法通过不在不必要的样本上评估 (8.56)，可望减少每次值迭代的计算量；每次迭代得到的 cost-to-go 值与原来相同，因为只排除了值不会变的样本。但这还不像 Dijkstra 算法——每个阶段仍要对整个 \(A_i\) 做值迭代。要做一个像 Dijkstra 那样运行的版本，引入队列 \(Q\)，每次迭代移出最小元素。插值版本先对每个 \(s\in G\) 赋 \(G^*(s) = 0\)，并维护初始为 \(D = G\) 的 dead 样本集合 \(D\)。对每个 \(s\in\mathrm{Front}(G)\) 计算 cost-to-go 更新 (8.56)；优先队列 \(Q\) 初始化为 \(\mathrm{Front}(G)\)，元素按当前 cost-to-go 值（可能不是最优的）排序。算法反复移出 \(Q\) 中最小的元素（因为它的最优 cost-to-go 已知就是当前值），\(Q\) 为空时终止。每次移出最小元素 \(s_s\in Q\)，就把它插入 \(D\)，并执行两个过程：1) 队列中有些元素要用 (8.56) 重算 cost-to-go，因为 \(G^*(s_s)\) 已知是最优的，它们的值可能依赖它——这些就是 \(Q\) 中位于 \(\mathrm{Front}(D)\)（\(D\) 刚加入了 \(s_s\)）里的样本；2) \(\mathrm{B}(R(D))\) 中不在 \(Q\) 里的样本，用 (8.56) 算出 cost-to-go 后插入 \(Q\)。这让 alive 样本集随 dead 样本集一起增长。带插值的 Dijkstra 算法算出的值与值迭代并不相同，因为算 \(G^*_k\) 时并没有显式存储 \(G^*_{k+1}\)。每个算出的值都是某个 cost-to-go，但只有当样本被放进 \(D\) 时才知道它是最优的。不过可以证明方法是收敛的，因为算出的值不高于值迭代会算出的值。这也是用 Gauss–Seidel 迭代做动态规划的基础 [11]。

对「找出以最少阶段数到达目标的解」这一特殊情形，可以做一个专门的 wavefront 传播版本，与图 8.4 的算法类似：从初始波前 \(W_0 = G\) 开始（对每个 \(s\in G\) 有 \(G^*(s) = 0\)）；每次迭代最优 cost-to-go 值 \(i\) 加一，波前 \(W_{i+1}\) 由 \(W_i\) 算出：\(W_{i+1} = \mathrm{Front}(W_i)\)。算法在第一个波前为空的迭代处终止。

常见陷阱

  1. 把势函数当成导航函数：随便一个「越靠近目标越小」的势函数（如无视障碍的距离）通常有局部极小，不满足性质 3。最优 cost-to-go 才保证是导航函数。
  2. 忘了性质 2：到不了目标的状态必须是 ∞；否则局部算子会让机器人在被隔开的区域里白忙。
  3. 用 wavefront 处理非单位代价：wavefront 只对单位代价最优；斜走代价 √2 时要用 Dijkstra，或用整数近似（如 5/7）配 Dial 算法。
  4. 以为反馈计划一定是连续向量场：8.4.2、8.4.3 节的计划都不连续，积分曲线要用 Filippov 意义理解；需要有界加速度时这就不行了（8.4.4 节）。
  5. 目标是单点时期望有限时间到达：光滑向量场只能渐近收敛；归一化或不连续的场才能有限时间到达。
  6. 在不可缩空间里要求光滑导航函数没有其它临界点：做不到（Morse 理论），只能让多余的临界点是鞍点，吸引域测度为零。
  7. 坐标邻域只用一个：除了 \(\mathbb{R}^n\)（及与之同胚的空间），一个坐标邻域覆盖不了整个流形；在极点等处坐标会退化（例 8.16）。
  8. (8.53) 当作充分条件：平移和旋转的位移可以同向相加，应该用 \(\sqrt{\Delta x^2+\Delta y^2}+r|\Delta\theta| < d\)（或 5.3.4 节的 (5.31)）。
  9. \(\Delta t\) 比网格间距还小：插值邻居不变、值一直是 ∞；目标太小使 \(R(G)\) 为空也一样。
  10. 把类 Dijkstra 的值当成值迭代的不动点：插值打破了「只依赖更小的值」，有些样本的值会偏高。

习题导引

只给思路，不给完整解答。标「互动」的可以先在本页对应的图里做实验。

  1. 用很快的路径规划器模拟反馈：每隔一小段时间从当前状态重新规划（滚动规划），只执行开头一小段。权衡：在线计算的延迟与可靠性、离线反馈计划的存储与对环境变化的适应性。（互动：「开环 vs 反馈」里想象每一步都重新规划。）
  2. 带「离障碍太近」惩罚的网格导航函数：把每个格子的代价设为 1 + λ·g(到障碍的距离)，用 Dijkstra（或整数化后用 Dial）。λ 越大路径越远离障碍、越长。（互动：「wavefront 与 Dial」。）
  3. 修正 NF2 的多路线问题：先算每条（同伦类不同的）骨架路线上的最小间隙，在骨架图上用「瓶颈最短路」（最大化最小间隙，再按长度打破平局）来定 \(\phi_1\)。（互动：「NF2」。）
  4. 切空间的基：(a) 单位四元数构成 \(\mathbb{S}^3\)，在 \(h\) 处切空间是与 \(h\) 正交的三维子空间，例如 \(h\) 左乘纯虚四元数 \(\mathbf{i},\mathbf{j},\mathbf{k}\) 得到的三个向量；(b) 对 (4.20) 的旋转矩阵分别关于 \(a,b,c,d\) 求导，再投影到约束 \(a^2+b^2+c^2+d^2=1\) 的切向。（互动：「S² 上的切空间」是低一维的版本。）
  5. 带洞多边形的最优导航函数：把所有洞的顶点都当作候选路点，按 \(\phi\) 从小到大（Dijkstra 顺序）处理，并对能被多个路点看见的点取 (8.43) 的最小值14。（互动：「平面多边形里的最优导航函数」勾「加一个洞」。）
  6. 用竖直单元分解构造反馈计划：单元是梯形（凸）；在单元邻接图上 BFS，每个梯形里从出口边对面的点往外推（或直接指向出口边中点）。
  7. 开圆环上流入 \(X_G\) 的连续向量场：提示——在圆环上围绕内洞的方向，一个连续场能否在「绕洞的两侧」都指向 \(X_G\)？考虑沿着包围内洞的一个圆走一圈，向量场方向的转动（或用临界点 / Morse 论证）。
  8. 最大间隙的单元分解与反馈计划：用 6.2.3 节的广义 Voronoi 图把自由空间分成「以 Voronoi 边为界」的单元，先把状态推到 Voronoi 边，再沿它走。
  9. 多边形 C-space 的精确覆盖：从凸分解出发，把相邻凸块向彼此「膨胀」一点，使相交部分有二维内部；注意膨胀后仍要在 \(\mathcal{C}_{free}\) 里。
  10. 欧拉角下的无碰球：对每个旋转轴，取垂直于该轴的平面里离轴最远的点，得到三个半径 \(r_1,r_2,r_3\)；保守的条件是 \(\|\Delta t\| + r_1|\Delta\alpha| + r_2|\Delta\beta| + r_3|\Delta\gamma| < d\)（注意不是平方和，见脚注 12）。
  11. 四元数下的无碰球：用 \(\|h - h'\|\) 界定旋转角的变化，再乘以离转轴最远的距离（与第 5 章习题 14 类似）。
  12. 把 (8.59) 推广到 \(n\) 维：权重是 \(\prod_j w_j\)，第 \(j\) 维取 \(\alpha_j\) 或 \(1-\alpha_j\)，对应下标取 \(i_j\) 或 \(i_j+1\)；共 \(2^n\) 项。（互动：「在样本之间插值」右图是 \(n = 2\)。）
  13. 只用 \(\|u\| = 1\) 的问题：目标附近无法「停下」，状态在目标周围来回跳，cost-to-go 可能不收敛或出现震荡；包含 \(u = 0\) 才能在到达后保持不动。
  14. –20. 实现题：14 → 「调和势函数」（试试别的边界条件和更大的网格）；15 → 「带插值的值迭代」换成 \(\mathbb{R}^2\times\mathbb{S}^1\)，θ 方向用加权的欧氏度量并处理 \(0\sim 2\pi\) 的粘合；16 → 比较「在样本之间插值」里两种插值的代价；17 → 「三角剖分上的向量场」；18 → 「平面多边形里的最优导航函数」；19 → 在「带插值的值迭代」基础上把目标换成随时间移动的 target，代价里加「看不见目标」的惩罚；20 → 「势函数与梯度下降」。

延伸阅读（据原书 Further Reading）

与前几章相比，本章相关的文献要少得多；如 8.1 节所说，由于历史原因，反馈通常与运动规划分开。导航函数 [58, 79] 是把反馈带入运动规划最有影响的思想之一，所以它贯穿全章。其它使用或开发导航函数的工作见 [24, 34, 77]。进展度量 progress measures [41]、Lyapunov 函数（15.1.1 节）和 cost-to-go 函数都密切相关；基于 Lyapunov 的反馈控制律设计见 [35]。在运动规划的语境里，误差检测与恢复（EDR）框架也包含反馈思想 [37]。[42] 通过「覆盖 \(\mathcal{C}\times\mathcal{C}\)、在每块区域上定义连续路径函数所需的最少区域数」研究 C-space 的拓扑复杂度，这给出了能构造的导航函数的极限（假设 \(q_I\)、\(q_G\) 都是变量；本章 \(q_G\) 是固定的），后续工作见 [43, 44]。

要更好地直观理解向量场，[4] 是很有用的参考，有许多有启发的插图；适合控制理论概念的光滑流形入门见 [17]；2D、3D 曲线曲面的基本直觉见 [78]；光滑流形与微分几何的其它来源有 [1, 13, 25, 36, 86, 87, 90]；分段光滑向量场见 [2, 65, 84, 92]。8.4.2、8.4.3 节分别受 [26, 66] 和 [74] 启发；这些方法允许不连续的向量场，从而避开了许多困难，要求连续或光滑就得到 8.4.4 节，它主要基于 [79, 80]；其它导航函数工作有 [30, 67, 68]。8.5.1 节主要受 [20, 70] 启发，基于邻域图的方法来自 [91]。

8.5.2 节的带插值值迭代在运动规划里有时被遗忘，因为它被提出时计算机还不够强大 [8, 9, 61, 62]；如今对几维（如 3 或 4）的有挑战问题已经能算出解。离散值迭代收敛到最优连续问题的解，最先由 [10] 在状态转移方程和代价泛函的 Lipschitz 条件下建立；考虑插值的分析和一般的离散化问题见 [21, 39, 46, 59, 60]；多分辨率变体见 [76]；类 Dijkstra 版本的讨论基于 [64, 89]；level-set 方法也密切相关 [55, 57, 56, 85]。
